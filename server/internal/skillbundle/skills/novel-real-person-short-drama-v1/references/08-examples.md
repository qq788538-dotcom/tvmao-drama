## 小说 → 漫解剧本（内部交接示例）

**小说原文：**

```text
林砚冒雨回到村口，发现父亲被村民围住。父亲低声说：“别回来，他们在等你。”人群里有人冷笑：“一个丫头也想翻天？”林砚攥紧湿透的信封，决定这次谁也别想再欺负家里人。
```

**阶段 0 内部漫解剧本：**

```text
《雨夜回村》一行一句剧本版

人物：林砚、父亲、村民

【第01场】雨夜村口｜村口泥路｜夜｜外

林砚（旁白）：林砚攥紧湿透的信封，决定这次谁也别想再欺负家里人。
```

该文本只在本 skill 内部交接；它的旁白和对白进入语音账本后，继续按阶段 02–07 生成资产与 JSON。最终交付仍只有校验通过的 JSON 对象。

> 本 skill 内置 1.8x 加速规则；`__{{DURATION_SEC}}__` 保持为调用时参数。

## 不同剧本格式的归一化对照

| 维度 | script_01/02（标准场次） | script_03（第一人称OV） | script_04（markdown） | 统一处理 |
|---|---|---|---|---|
| 场景头 | `1-1 日 外 地点` | `诊室，日，内` | `### 日外 山中` | 识别为「一场」，再切功能节拍 → storyboard 元素 |
| 叙述 | `△动作` | `OV：我…` / `▲+OV` | `△动作` | 第三人称可视画面，写进 `prompt` 描述 |
| 对白 | `角色（情绪）：` | `角色（情绪）：` | `角色（情绪）：` | `@[角色-名称]（情绪）：“台词”`（说话人 token） |
| 心理 | `OS` | OV 心理句 | `（疑惑）` 等 | `@[角色-名称](内心OS)` |
| 特殊 | 系统音【叮】 | —— | 笔记/快闪 | `机械的电子音女声`（不加 token） / 快切镜头 |

> 结论：无论输入格式如何，输出**恒为**同一个 JSON 对象——顶层 `character/scene/item`（带生图提示词）+ `storyboard[]`；每个 `storyboard.prompt` 内是同一套「固定风格串 + cNN 子镜头 + `@[类型-名称]` token + 收尾标签」结构；每个 `duration` 都是 `4~__{{DURATION_SEC}}__`，优先接近主切割时长，子镜头个数随实际 `duration` 缩放（≈ duration÷1.7~duration÷1.4）。
