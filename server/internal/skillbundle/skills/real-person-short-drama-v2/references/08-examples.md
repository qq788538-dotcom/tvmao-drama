**映射要点**：顶层 = 整集去重资产 + 生图提示词；storyboard 每项 = 一个 `4~__{{DURATION_SEC}}__`s 分镜，优先接近 `__{{DURATION_SEC}}__`s；`prompt` 就是 md 版分镜代码块（固定风格串 + cNN 行，`\n` 连接），token/台词/节奏规则全沿用；`name` ≤15 字；`duration` = cNN 秒和；三数组与 prompt 里的 `@[类型-名称]` 引用闭环。

## 不同剧本格式的归一化对照

| 维度 | script_01/02（标准场次） | script_03（第一人称OV） | script_04（markdown） | 统一处理 |
|---|---|---|---|---|
| 场景头 | `1-1 日 外 地点` | `诊室，日，内` | `### 日外 山中` | 识别为「一场」，再切功能节拍 → storyboard 元素 |
| 叙述 | `△动作` | `OV：我…` / `▲+OV` | `△动作` | 动作写成第三人称可视画面；OV 原文同时保留为 `旁白（画外音）` |
| 对白 | `角色（情绪）：` | `角色（情绪）：` | `角色（情绪）：` | `@[角色-名称]（情绪）：“台词”`（说话人 token） |
| 心理 | `OS` | OV 心理句 | `（疑惑）` 等 | 明确角色的 OS 写 `@[角色-名称](内心OS)`；匿名 OV 仍保留为 `旁白（画外音）` |
| 特殊 | 系统音【叮】 | —— | 笔记/快闪 | `机械的电子音女声`（不加 token） / 快切镜头 |

> 结论：无论输入格式如何，输出**恒为**同一个 JSON 对象——顶层 `character/scene/item`（带生图提示词）+ `storyboard[]`；每个 `storyboard.prompt` 内是同一套「固定风格串 + cNN 子镜头 + `@[类型-名称]` token + 收尾标签」结构；每个 `duration` 都是 `4~__{{DURATION_SEC}}__`，优先接近主切割时长，子镜头个数随实际 `duration` 缩放（≈ duration÷3~duration÷2）。
