# 阶段 05：台词与声音处理

把语音账本中的对白、OS、OV、VO、旁白、画外音、系统语音以及其他带文本声音放入已经规划好的子镜头，严格执行原文保留、顺序一致和声音格式。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 六、台词 / 声音处理

1. **声音格式统一（最高优先级）**：所有有文本语音都用中文引号。身份明确的角色声音使用 `@[角色-名称]` token：`@[角色-名称]（情绪/语气）：“台词”。`。示例 `@[角色-王志]（冷声）：“…”`、`@[角色-王志](内心OS)：“…”`、`@[角色-王志](VO)：“…”`、`@[角色-徐开来]（画外音）：“…”`。匿名或非角色声源不加 token、不创建角色资产：`旁白（画外音）：“…”`、`机械的电子音女声：“…”`、`广播声（画外音）：“…”`、`电话声（画外音）：“…”`、`录音声（画外音）：“…”`。禁裸台词 `角色：台词`、`@[角色-名称]：台词`，冒号后必须是 `“...”`。
   - **⚠️ 引号内台词正文不 token 化**：只有冒号前说话人带 token；引号 `“…”` 里台词原文照抄，**即使提到人名/物名也纯文字**。正确 `@[角色-林砚]（怒）：“张三，把笔记本给我！”`；错误 `…：“@[角色-张三]，把@[物品-笔记本]给我！”`。
   - **对白收尾标点（硬约束）**：贴右引号 `”` 的最后一字必须是 `。/？/！/……`，**严禁 `，/、/；` 结尾**；拆句时贴 `”` 的逗号改句号（疑问改 `？`、强烈改 `！`）。错误 `“这秦岭山上猛兽多，”`；正确 `“这秦岭山上猛兽多。”`。
2. **情绪/语气括注保留（硬约束）**：剧本写 `角色（提高音量/愤怒/哽咽/压低声音）：台词` 时，名前**原样保留括号**；长台词拆多镜**每段都带同一括注**。无括注按语境补简短情绪（`（冷声）`），不空成裸引号。括号是肢体动作时（`苏晚晴（咬了咬下唇）`），动作写进画面/姿态、台词另补语气（`（声音很低）`）。
3. **内心独白**：`@[角色-名称](内心OS)：“…”`。
4. **旁白 / VO / 画外音处理（三种情形）**：
   - `OV：…` / `▲+OV：…`（无具体角色前缀）→ **原文保留为 `旁白（画外音）：“原文。”`**，不加 token、不创建角色资产。可以把叙述内容同步视觉化为第三人称画面，但视觉画面不能替代原始声音。
   - `王志(VO)：…` / `角色VO：…`（剧本明确标注画外音身份）→ **保留为 `@[角色-名称](VO)：“台词原文”`**，配以对应场景画面（镜头 3~5s，描述环境/人物神情），**不得删除或视觉化替换**。
   - **知识讲解 / 旁白推进段的画外音技法**：当剧本中角色台词属于知识性解释、背景旁白或情感独白，且对应画面应为**物体特写 / 空镜 / 环境镜头**时，使用 `@[角色-名称]（画外音）：“台词”` 格式，**人物不出现在画面内**，画面描述填对应物体或环境。这类镜头可 3~5s。示例：
     ```
     c02,4s,(空间:@[场景-秦岭隧道]石壁特写)(姿态:无人物) 大特写，静止。石壁上刻满古代纹样，镜头缓慢横移。@[角色-徐开来]（画外音）：“这些符号不是装饰，是古人对磁场异常的记录方式。”【不出现任何文字字幕】
     ```
5. **系统/电子音**：`机械的电子音女声：“…”`；**阿拉伯数字一律改中文**（1100→一千一百，1982→一九八二）。
6. **其他带文本声源**：广播、电话、录音有明确角色身份时使用该角色 token 和对应模式；身份不明时分别使用 `广播声／电话声／录音声（画外音）：“原文。”`，不加 token、不创建角色资产。凡剧本明确为可听语音的文本都必须保留；不得因其具有叙述性而删除。
7. **台词零改写（⚠️ 最高优先级）**：每句台词正文**逐字还原原文**，不增删/换词/概括；情绪括注保留或补足；正文包中文引号。过长拆连续子镜头（每段还原对应片段），不同角色台词不合并同镜。**严禁凭空新增剧本不存在的台词/事件/动作**；**最终不得出现 `[台词待调整]` 占位符**。关键肢体动作（"单膝跪地""一把甩开他的手"）原样保留。
8. **回忆/倒叙/闪回**：剧本用 OV/旁白讲过去时，优先作当前分镜内 1~3 个 1~2s 闪回快切子镜头；仅当倒叙自成完整独立场景才单独成闪回分镜。描述标"氛围:回忆/闪回"（泛黄/柔焦/慢动作），不跳过倒叙。

### 语音账本映射与对账

- 按语音账本顺序映射声音，不得交换、跳过或合并不同账本项。
- 一项长语音可以拆成连续多个 `cNN`；将拆分文本按顺序拼接后必须还原该账本项。
- **正向对账**：账本每一项必须在输出中恰好出现一次，或恰好映射为一组连续拆分。
- **反向对账**：输出中每段对白、OS、VO、旁白、画外音、系统语音、广播声、电话声或录音声都必须能回溯到一个账本项，禁止新增声音文本。
- 允许的正文变化仅限拆句边界的逗号改句号，以及系统电子音的阿拉伯数字转中文；除此之外不得增删或换词。
- `【音效】` 和其他无台词声音不进入语音账本，不参与上述对账。
