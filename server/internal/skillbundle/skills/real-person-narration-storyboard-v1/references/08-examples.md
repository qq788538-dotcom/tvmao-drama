# 阶段 08：输入输出示例

## 小说输入

```text
邻居家盖房子，不留出路。
我好心提醒他，别忘了留出路。
他却说：“关你屁事！”
```

对应计划片段：

```json
{
  "narrationMode":"fast_recap",
  "baseSpeechCharsPerSec":3,
  "playbackRate":1.6,
  "genreProfile":"comeback",
  "id":"N001",
  "speaker":"解说",
  "mode":"narration",
  "text":"邻居盖房时，一点出路都没留。",
  "sourceUnitIds":["S001"],
  "targetSec":3.0,
  "pauseAfterSec":0,
  "hookRole":"primary",
  "visualMode":"evidence",
  "visualIntent":"先让观众看懂道路被侵占",
  "visualEvidence":"新房地基压到宅基地边界，通道被挤成窄缝",
  "spoilerBoundary":"不出现后来挖鱼塘的反制结果",
  "scene":"两家宅基地通道｜白天｜外"
}
```

对应模型镜头：

```text
镜头1：中远景，平视，固定机位。画面中@[角色-杨明]站在@[场景-空间母版-两家宅基地通道]自家院门一侧，前景地界桩与新砌墙脚几乎贴合，后景通道只剩一人宽；午后日光从巷口斜照墙脚，人物脸和地界证据保持清楚。他沿地界线看向被挤窄的出口，停在原地。解说（画外音，电影解说式快速清晰、连续无拖腔）：“邻居盖房时，一点出路都没留。”砖刀刮灰声和村巷底噪，无配乐。
```

画面主语是“被侵占的通道证据”，不是单纯让人物走路或生气。

## 已有解说剧本输入

已有解说词逐字进入 `narrationUnits.text`。动作行只建立 `visualEvidence`，不擅自改成新解说。若一条解说过长，只按自然意群拆分，拼接后必须逐字还原。

## 普通剧本输入

保留人物原对白，把场景切换、动作结果和不说会看不懂的因果改成解说。能够清楚演出的即时动作不必重复口播，避免“解说说一遍、画面再机械演一遍”的信息浪费。

## 有文本声音格式总表

- 角色对白：`@[角色-林砚]（冷声）：“别让任何人进来。”`
- 内心独白：`@[角色-林砚](内心OS)：“我必须撑到天亮。”`
- 具名 VO：`@[角色-林砚](VO)：“那天之后，我再也没回过这里。”`
- 每段首个匿名旁白：`旁白（画外音，电影解说式快速清晰、连续无拖腔）：“午夜十二点，整栋楼陷入黑暗。”`
- 同段后续匿名旁白：`旁白（画外音）：“走廊尽头却亮起一盏灯。”`
- 系统／广播／电话／录音声：`广播声（画外音）：“请所有人立即离开。”`

这些声音都进入 narration plan 并进行正反向对账；`【音效】`、雨声、门响等无文本声音不进入语音账本。示例计划中的 `playbackRate` 仍用于 `targetSec` 预算，不会原样编译到模型提示词。
