# 阶段 07：JSON 组装与质量闸门

## 零、双层编译契约

- **内部导演层**维护语音与时长账本、镜头衔接账本、导演弧线、场级视觉基线、逐镜意图／起落幅／人物动线／摄影机物理和风险—约束账本。
- **Seedance 模型层**只接收固定风格串和自然语言 `镜头N：`；每镜编译一个景别、一个机位、一个主运镜、空间层画面、动作结果和必要声音。内部 cNN、时间码、分析字段和边界编号不得泄漏。

## 一、输出 schema

只输出以下精确结构，不增加 narration、negativePrompt 或内部映射字段：

```json
{
  "character":[{"name":"角色名","prompt":"角色生图提示词"}],
  "scene":[{"name":"场景名","prompt":"场景生图提示词"}],
  "item":[{"name":"物品名","prompt":"物品生图提示词"}],
  "storyboard":[{
    "name":"分镜简述",
    "duration":9,
    "prompt":"9:16竖屏投放素材，真人写实质感，主体与背景明暗分离，暗部保留可辨细节，高光不过曝，画面不要出现任何文字，生成视频无BGM；\n镜头1：……",
    "character":["角色名"],
    "scene":["空间母版-场景名"],
    "item":["物品名"]
  }]
}
```

字段顺序固定。分镜名称全篇唯一且不超过 15 字。资产引用数组与 prompt 中 `@[类型-名称]` 完全闭环。
示例中的 `9` 只是一次内容计算结果，不是默认值；每段都必须重新按阶段 03 公式计算。

空间母版不新增顶层字段，仍作为 `scene` 资产。基础场景由母版 prompt 通过 token 引用；跨多个 storyboard 的视频 prompt 与 `scene` 数组只引用母版，不重复发送基础空景。项目会把母版放在参考图首位，角色与确需形态约束的物件随后进入参考链。

## 二、模型镜头格式

```text
镜头N：起始景别，机位，唯一主运镜[至结束景别]。画面中主体位于@[场景-名称]的具体区域，写清世界锚点、前后景或主体关系。可见动作、事实证据和结果。解说／对白、环境声、关键音效。
```

首行固定为：

```text
9:16竖屏投放素材，真人写实质感，主体与背景明暗分离，暗部保留可辨细节，高光不过曝，画面不要出现任何文字，生成视频无BGM；
```

末镜写明保持半秒并包含 `【不出现任何文字字幕】`。

## 三、解说画面质量闸门

逐条语音检查：

- [ ] 声音开始时，`visualEvidence` 已经进入画面。
- [ ] `N001` 从 `storyboard[0]` 镜头1开始，第一幅就是小屏可读的冲突、证据或动作结果，不用空景或普通走路暖场。
- [ ] 画面出现可验证的地点、人物行为、物件、关系或结果，不是泛动作填充。
- [ ] 同一段相邻镜头各自增加新信息，不重复同一构图和动作。
- [ ] 心理与态度已转成可见行为，不只写“愤怒、得意、紧张”。
- [ ] 当前画面没有提前出现 `spoilerBoundary` 禁止的事件。
- [ ] 解说和关键人物对白没有重叠发声。
- [ ] 匿名解说 `targetSec` 已按 `ceil((语义字符数÷(3×playbackRate))×10)÷10` 计算；这里的 `playbackRate` 只用于规划。其他声音按基础 3 字／秒。每个 storyboard 的 `duration=max(4,ceil(ΣtargetSec+ΣpauseAfterSec+1))`，画面切镜没有重复加时，超过上限时已拆段。
- [ ] prompt 没有 `1.6倍速` 等数值音频指令；每段首个匿名解说使用 `解说（画外音，电影解说式快速清晰、连续无拖腔）`，后续只写 `解说（画外音）`。
- [ ] `DURATION_SEC>=12` 时已贪心装载同场连续语音；包含解说的 12～15 秒片段集中约 45～60 个有声语义字符。普通连续解说无停顿，只有反转／结果／对白交接／时空切换使用 0.5 秒。
- [ ] 视觉镜头数为 `ceil(duration÷3)..floor(duration÷2)`，声音可以跨内部切镜持续，不因语音单元边界机械换画面。

## 四、投放画面闸门

- [ ] 固定首行保持原文一字不差；比例、分辨率和时长没有在镜头正文重复堆叠。
- [ ] 每个 storyboard 首镜写出可解释主光来源、方向和冷暖，暗部仍能辨认空间、服装或关键物，高光未吞掉脸和证据。
- [ ] 全片只使用 `genreProfile` 对应的一组主对比色；同场光源、色彩和天气相位连续。
- [ ] 主体通过曝光、色温、景深或空间层次与背景分离；轮廓光有窗、路灯、聚光灯、门缝、雪地反射等物理来源，不是全员模板。
- [ ] prompt 不含电影级质感、超清1080P、氛围感拉满、注意力百分比、莫兰迪或灰蒙胶片雾感等不可执行／弱识别词。

## 五、v3 导演和连续性闸门

- [ ] 一镜一个意图、一个主动作、一个主运镜、一个起点和终点。
- [ ] 每条镜头同时有空间层和时间层，不能只有动作描述。
- [ ] 移动镜遵循先稳—可见动作触发—终点停稳；固定镜能完成时优先固定。
- [ ] 同一 storyboard 两镜以上至少一个固定机位，最多一次推镜。
- [ ] 四镜以上的 storyboard 至少使用两种景别；八镜以上的长序列同时含空间建立镜和特写落点。全固定方案必须由明确静止声部以及足够的景别覆盖或机位变化支撑。
- [ ] 二十四镜以上若同一种移动镜覆盖三分之一以上镜头，必须重新分配运动动机；只用一次决定性移动不为凑配额再加技巧。
- [ ] 世界坐标、人物动线、道具归属、主光方向和环境声底连续。
- [ ] 画左／画右只用于当前横向运动、遮挡、负空间或匹配构图，不作为人物永久身份锁。
- [ ] 相邻 storyboard 使用成对的自然语言切点，不伪装无缝尾帧续接。
- [ ] 连续性按入口、窗、桌轴、座位、路线、道具归属和光源方向判断；反打允许主体改变屏幕位置，不得把“某角色始终画左／画右”当作跨机位身份锁。
- [ ] 不输出空泛电影词、普通负面缺陷词清单、内部 cNN、时间码或导演分析。

## 六、语音与模型编译对账

- [ ] 正向对账：计划中的每条有文本语音按顺序恰好出现一次，并对应一段完整引号语音；需分段时先在计划内拆单元。
- [ ] 反向对账：prompt 中每段引号文本都有明确说话人和 mode，并能回溯到计划；环境声和无文本音效不参与语音对账。
- [ ] 每个镜头只有一个基础运镜；移动镜写清稳定起点、可见动作触发和停稳终点。
- [ ] 每条镜头头部后都有 `画面中……` 和逐镜场景 token；首镜含物理光源，动作落到可见结果。
- [ ] 相邻 storyboard 的自然语言切点类型闭环，首段无入点，末段无出点。

## 七、确定性校验

```bash
python3 scripts/validate_storyboard.py candidate.json --duration-sec <DURATION_SEC> --narration-plan narration_plan.json --source source.txt
```

Run 中没有 `source.txt` 时才省略 `--source`。这一轮会再次将计划与机器原文逐字锚定，防止在分镜阶段替换或缩写计划绕过来源对账。只有退出码为 0 且输出 `OK: storyboard JSON is valid` 才能提交 `candidate.json`。
