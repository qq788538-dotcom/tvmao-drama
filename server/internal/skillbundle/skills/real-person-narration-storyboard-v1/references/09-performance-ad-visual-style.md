# 投放素材竖屏视觉与光影

本阶段把小说解说从普通影视覆盖调整为信息流投放画面：前三秒先让观众看懂冲突，小屏先读主体与关键证据，再保留真人叙事需要的空间、表演和光线连续性。投放视觉不是在每镜堆“电影级、超清、高级感”，而是把有限提示词预算给可见信息。

## 一、采用与拒绝

采用以下功能性原则：

- `9:16` 竖屏，小屏优先读脸、手中关键物、关系距离和动作结果；
- 主体与背景需要曝光、色温、景深或空间层次上的可读分离；
- 暗部保留可辨纹理，高光不过曝，避免二次压缩后黑场糊死；
- 全片只使用一组题材主对比色，同场不随机换调色；
- 第一条语音和第一个模型镜头共同承担前三秒主钩子；
- 光线按“物理主光来源 → 必要补光／反射 → 明暗关系 → 题材色彩”决策。

拒绝以下绝对化写法：

- “所有人物都加轮廓光”“固定 45 度侧逆光”：没有窗、路灯、聚光灯、门缝、雪地反射等来源时不成立，也会造成跨镜光向跳变；
- “前 3 秒光比拉满”：钩子强度来自可见冲突和证据，光比只服务该冲突；人脸、手和关键物仍要可读；
- “电影级质感、超清 1080P、氛围感拉满、注意力提升百分比”：它们不是可执行画面指令；分辨率、比例和生成时长由项目配置控制；
- 在每条 `镜头N` 重复完整光影模板：场级基线只建立一次，后镜只写真实变化。

## 二、前三秒主钩子

`N001.hookRole` 必须为 `primary`，并从 `storyboard[0]` 的 `镜头1` 开始声画同步。第一个镜头通常占 2～3 秒，只选择一种能立即读懂的视觉触发：

- **证据特写**：离婚协议、破碎玉佩、血字、录音、欠条、落款、伤痕；
- **结果先显**：门被封死、身份牌落地、主角已站上审判席，但不越过当前 `spoilerBoundary`；
- **关系冲突**：跪与站、门内与门外、众人退开、关键人物当面夺物；
- **动作冲击**：巴掌落下后的停顿、杯子砸碎、门锁转动、手电扫到证据。

钩子镜头先给读得懂的景别。手中证据用特写／大特写；权力关系用中景／中全景；空间威胁用中远景。不要用空景、普通走路、慢慢抬头或没有事实的情绪脸开场。一个 3 秒镜头内不同时完成“手部特写上移到脸再拉远全景”；需要时拆为后续第二镜。

## 三、小屏构图

- 每镜只有一个视觉主语；人物脸或关键物至少一项在竖屏有效区域内清楚可读。
- 用前景证据、人物中层、门窗／对手后景组织纵深，避免把多人平均摊平。
- 竖屏优先中景、近景和特写推进；全景只在必须交代地理、人数或权力距离时使用，随后迅速回到信息落点。
- 重要主体避免贴近顶部、底部和侧边 UI 易遮挡区；关键物不放在画面最底部。
- 背景压低一级信息密度，而不是统一虚焦。后景承担揭示、威胁或关系时必须可读。
- 夜景不使用无补光的纯黑背景；暗部可比主体低，但仍保留服装、墙面或空间边界。

## 四、题材色彩配置

`genreProfile` 决定一组全片基线；色彩是项目连续状态，不是每镜重新抽取。

| genreProfile | 主对比色 | 推荐物理来源 | 使用边界 |
|---|---|---|---|
| `general_drama` | 中性日光＋局部暖色实用灯 | 窗光、台灯、走廊灯 | 不强行染色，以人物和证据清晰为先 |
| `modern_romance` | 冷蓝环境＋暖金实用灯 | 雨夜天光、酒店灯、路灯 | 虐恋可加深冷暖分裂，日景不伪造夜色 |
| `costume_intrigue` | 黛青／冷灰＋暖棕金 | 阴天天光、宫灯、烛光、雪地反射 | 金色只落在权力、身份或关键物上 |
| `suspense` | 冷蓝灰＋局部中性硬光 | 手电、门缝、屏幕、顶灯 | 高反差仍要保留暗部层次，不用整片纯黑 |
| `comeback` | 清洁中性底＋明亮暖金 | 宴会聚光灯、窗光、商业灯带 | 饱和度适中偏高，人物肤色和服装纹理不能溢出 |

同一场景先在场级基线写主光来源、方向、冷暖和反射；空间母版继承这些状态。题材对比色只能来自场内已有光源或后期统一色彩倾向，不能让同一盏灯在相邻镜头无触发变色。

## 五、模型侧压缩写法

固定首行为：

```text
9:16竖屏投放素材，真人写实质感，主体与背景明暗分离，暗部保留可辨细节，高光不过曝，画面不要出现任何文字，生成视频无BGM；
```

每个 storyboard 首镜再用一句短物理光源：

```text
窗外冷蓝雨夜天光铺底，酒店门灯的暖光只勾亮人物湿发和协议书边缘，面部由门廊反射光保持可读。
```

后续镜头默认继承，只在可见触发发生时写变化：

```text
门打开时，走廊冷白光从门口切入桌面，照出信纸落款。
```

不要把“主光、补光、轮廓光、高对比、暗部提亮、统一色调、电影颗粒、1080P”作为每镜固定清单。若主体与背景已经通过窗口明暗、前后景或色温分开，不再额外添加轮廓光。

## 六、投放视觉质量闸门

- [ ] `N001` 和第一镜同时给出可见冲突／证据，不用普通动作暖场。
- [ ] 第一镜的景别让手机小屏能立即读懂主体和关键物。
- [ ] 每个 storyboard 首镜都有一个可解释主光来源、方向和冷暖。
- [ ] 暗部仍能辨认空间边界、服装或关键物，高光没有吞掉脸与证据。
- [ ] 同场继承同一光源、色彩对比和天气相位；变化有物理触发。
- [ ] 轮廓光有来源且确实需要主体分离；不是所有人物的固定模板。
- [ ] 提示词没有电影级、超清、氛围感、百分比收益等不可执行营销词。
- [ ] 光影没有覆盖剧情；删掉光影句后若钩子就不存在，说明缺的是事件，不是形容词。
