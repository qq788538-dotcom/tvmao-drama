# 阶段 06：标签与风格控制

应用投放竖屏基线、叙事性焦点、无文字字幕、无 BGM 和节奏量化。背景虚焦、轮廓光与特殊手法只是按需导演手段，不是为了达成百分比而填入 prompt 的配额。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 七、收尾标签与叙事性焦点

1. `【背景虚焦】`：只在需要隔离人物、压低背景干扰、或把关键信息稳定在一个焦平面时使用。若场景参考已有合适景深，不在文字中重复；若人物关系、后景揭示、前后景调度或构图匹配依赖深度信息，不加虚焦，或改写为一次明确的焦点转移。

   GT 统计（9177 子镜头）只用于**发现异常倾向**，不作为生成配额：

   | 景别 | GT 带【背景虚焦】 | 样本观察 |
   |---|---|---|
   | 远景/全景/中全景/中远景/定场/空镜 | ~**17%** | 样本中较少 |
   | 中景 | ~**41%** | 样本中约四成 |
   | 过肩镜头 | ~**48%** | 样本中约一半 |
   | 近景 | ~**87%** | 样本中较常见 |
   | 特写/大特写 | ~**76%** | 样本中较常见；纯物体/环境特写差异大 |

   - 整体约 58%、近景和特写更常见，说明景别是有用的先验，不是最终判定。
   - **末镜不因末镜必加背景虚焦**；末镜必带的是 `【不出现任何文字字幕】`。
   - **叙事回检**：加了虚焦后，若负空间、后景角色、环境信息或下一个揭示变得不可读，就删除。未加虚焦但背景明显抢掉主信息时，才补。
2. `【不出现任何文字字幕】`：**每个分镜最后一个子镜头必加**；对白镜也常加，整体约 **30% 子镜头**带此标签。
3. 二者常合并：`【背景虚焦，不出现任何文字字幕】`；标准文本 `不出现任何文字字幕`（不写"画面"二字）。
4. 全程贯彻：**画面零文字、零字幕、无 BGM**。

### 全局约束与局部约束

- 固定首行为 `9:16竖屏投放素材，真人写实质感，主体与背景明暗分离，暗部保留可辨细节，高光不过曝，画面不要出现任何文字，生成视频无BGM；`。它与末镜 `【不出现任何文字字幕】` 已承载项目级约束；不要在每个镜头正文重复“竖屏、高对比、无文字、无字幕、无水印、无 BGM”清单。
- 局部约束只处理当前镜头的剧情与连续风险，并遵循阶段 04c：优先写正向状态锁；只有“已完成动作不得重演”或“后续事件不得提前出现”需要短排除句。
- 不新增 `negativePrompt`、`negative_prompt` 等 JSON 字段，也不输出独立“负面提示词”段落。

### 投放风格稀疏编译

- `genreProfile` 只选择一组稳定对比色：现代情感用冷蓝＋暖金，古风权谋用黛青／冷灰＋暖棕金，悬疑用冷蓝灰＋局部中性硬光，逆袭爽文用清洁中性底＋明亮暖金，通用剧情使用自然中性色＋局部暖灯。
- 每个 storyboard 首镜写物理主光来源、方向和冷暖；后镜继承。只有门打开、灯熄灭、车灯扫过、云层移动等事件改变光线时再写变化量。
- 主体与背景可通过曝光、色温、景深、遮挡或纵深分离；轮廓光不是强制项，更不能为所有人物统一勾边。
- 前三秒钩子首先是证据、冲突或结果，不是抽象高光比。第一个镜头仍须保住脸、手和关键物细节。

### 拼接安全头尾

- 每个 storyboard 的第一个 `镜头N` 先稳定构图约 0.3~0.5s，再执行主动作；除明确冲击式开场外，不从运动模糊、急转头或说到一半的嘴型开始。
- 每个 storyboard 的最后一个 `镜头N` 必须让动作、表情、运镜或道具状态落定，并保持约 0.5s；该保持在内部 cNN 时长中核算，不额外增加空镜。
- 安全尾帧不是人人僵住：可以保留呼吸、衣摆、雨丝、灯光等持续微动，但主体姿态、镜头构图和关键道具状态不得在最后半秒继续大幅变化。
- `Bnnn` 只存在于内部衔接账本，不发送给模型。非末 storyboard 最后一个镜头写 `结尾供某类切`；非首 storyboard 第一个镜头写 `开头承接同类切`。自然剪辑短语不替代 `【不出现任何文字字幕】`。

### 八、节奏量化盘（实测 10963 个子镜头）

| 指标 | 取值 | 说明 |
|---|---|---|
| 分镜时长 | **`max(4, ceil(ΣtargetSec + ΣpauseAfterSec + 1))`，且不得超过 `__{{DURATION_SEC}}__`s** | 语音按 0.1s 连续累计，画面切镜与声音并行；整个 storyboard 最后只取整一次 |
| 子镜头/分镜 | **`ceil(duration÷3)..floor(duration÷2)`**（D=15 时约 5~7、常用 5~6） | 每个视觉事实 2～3s；首个 3s 钩子通常只做一件事 |
| 子镜头时长 | **2s≈43%、3s≈41%**、4s≈11%、1s≈3%、5s+稀有 | 以 2~3s 为主，禁均匀（**不随 `__{{DURATION_SEC}}__` 变**） |
| 解说密度 | **每条最多 14 个语义字符；12～15s 长段约 45～60 字** | `targetSec` 按基础 3 字／秒乘 1.5／1.6／1.7／1.8 的规划倍率保留一位小数；缺省规划值为 4.8 字／秒，但数值倍率不写入模型 prompt |
| 角色声音 | **每条最多 9 个语义字符** | 对白／OS／具名 VO／系统声按基础 3 字／秒规划，不跟随匿名解说的规划倍率 |
| 无文字标签 | 约 **30%** 子镜头 | 末镜必带 + 对白镜常带 |

表中的统计值只检查剧本节奏是否明显失真，不要反向为追求统计比例增加背景虚焦、特殊运镜、光影形容词或无意义镜头。

节奏量化不得牺牲镜头咬合：宁可把普通反应并入相邻内部 cNN，也不得删除 storyboard 边界所需的动作落定、安全尾帧和稳定入幅。
