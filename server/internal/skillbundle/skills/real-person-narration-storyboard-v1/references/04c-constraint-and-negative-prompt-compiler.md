# 阶段 04c：约束与负面提示词编译

本阶段不新增独立 `negativePrompt` 字段，也不把通用缺陷词清单塞入每个镜头。当前项目只消费 `storyboard[].prompt`，因此先在内部建立风险—约束账本，再把当前镜头真正需要的约束编译进对应 `镜头N`。

> 方法来源：Seedance 2.0 本地官方友好资料强调“参考承载状态，文字承载变化”、按镜头顺序写主体动作与摄影机终点，并避免用 `no blur / no artifacts / no extra fingers` 一类负面堆词反向植入缺陷。本阶段据此制定项目内编译规则，不把负面词当作越多越稳定的质量咒语。

## 一、内部风险—约束账本

每个内部 cNN 只记录可能破坏本镜意图或跨段连续的风险：

| 字段 | 含义 |
|---|---|
| 风险 | 具体会错在哪里，例如人物重复拆信、后续追赶提前出现、手离开关键道具 |
| 正向状态锁 | 用“画面中是什么、保持什么、动作止于哪里”消除风险 |
| 备用排除句 | 只有无法用正向状态锁说清时，才写短而具体的“不重复／暂不出现” |
| 作用域 | 当前镜头、当前 storyboard 或相邻片段边界；禁止把局部风险扩散到全片 |

账本只用于内部规划，不新增 JSON 字段，不输出“风险：”“正向状态锁：”“负面提示词：”等分析标签。

## 二、编译顺序

逐镜按以下顺序判断：

1. **参考或镜头设计已解决**：角色参考、场景参考、固定机位、可见起落点已经稳定该状态时，不再写约束。
2. **先写正向状态锁**：直接描述主体、构图、道具、光线或动作的确定状态。
3. **仍有时间顺序风险才写排除句**：只用于已经完成的动作不得重演，或保留给后续的事件不得提前出现。
4. **删去通用缺陷词**：模糊、伪影、畸变、多手指、变脸、闪烁等不属于剧情约束，不写进模型 prompt。

正向状态锁示例：

- 身份／构图：`@[角色-林砚]身份、发型和灰色外套保持一致，画面只保留林砚与林母。`
- 手与道具：`@[角色-林砚]双手始终握住@[物品-信封]边缘，信封形状完整。`
- 对白稳定：`对白期间固定近景，头部保持正面小幅动作，说完再转头。`
- 光线连续：`桌边暖色台灯的亮度和照射方向保持不变。`

仅在必要时允许的局部排除句：

- 已完成动作：`已完成的拆信动作不重复，本镜从信纸展开状态开始。`
- 未来事件：`本段止于抬眼，后续追赶暂不出现。`

## 三、约束预算与位置

- 约束与额外视觉变化量共享同一份稀疏预算；每镜最小画面基底不属于可删除的变化量，不能因增加约束而挤掉可见主体、具体场景区域和构图关系。
- 每条 `镜头N` 最多写一条局部约束；每个 storyboard 通常最多保留两条不同的局部约束。
- 相同约束只写在真正发生风险的镜头，不复制到每一镜。
- 固定投放风格首行 `9:16竖屏投放素材，真人写实质感，主体与背景明暗分离，暗部保留可辨细节，高光不过曝，画面不要出现任何文字，生成视频无BGM；` 保持一字不差；末镜的 `【不出现任何文字字幕】` 标签继续按阶段 06 执行，不在正文重复比例、画质、水印、字幕和文字清单。
- 约束放在主体动作和可见结果之后、声音之前。它是镜头执行条件，不是独立段落。

推荐行序：

```text
镜头N：景别，机位，唯一主运镜。画面中可见主体位于@[场景-名称]具体区域，写清构图／空间关系。主体动作与结果。[必要的一条视觉变化量或局部约束。]声音。【标签】
```

## 四、禁止的普通负面词堆叠

以下写法会挤占提示词并可能向模型植入不希望出现的概念，禁止发送：

- `负面提示词：不要模糊，不要变形，不要抖动，不要闪烁`
- `无伪影、无噪点、无穿模、无多手、无额外手指、无重复人物、不要变脸`
- `no blur, no artifacts, no extra fingers, no face drift`
- `绝对完美、百分百稳定、零错误`等不可验证的质量承诺

替换原则：

| 不推荐 | 推荐 |
|---|---|
| 不要抖动、不要闪烁 | `固定机位，构图和曝光保持稳定。` |
| 不要多手指、不要断手 | `双手完整握住信封边缘，手指动作幅度小。` |
| 不要变脸、不要人物复制 | `画面只保留@[角色-林砚]，身份、发型和服装保持一致。` |
| 不要道具变形 | `@[物品-信封]形状完整，始终由林砚双手握住。` |
| 不要重复上一动作 | `已完成的拆信动作不重复，本镜从信纸展开状态开始。` |
| 不要提前演后续剧情 | `本段止于抬眼，后续追赶暂不出现。` |

## 五、删减优先级

提示词过满时依次删除：

1. 普通负面缺陷词和不可验证的质量承诺；
2. 参考资产已经表达的人物身份细节和场景完整陈设清单；
3. 与本镜意图无关的次要视觉变化量；
4. 可由动作结果自然推出的重复约束。

不得删除每镜最小画面基底、主动作结果、主运镜触发与终点、原台词、参考 token，以及真正决定跨段连续的局部状态锁。
