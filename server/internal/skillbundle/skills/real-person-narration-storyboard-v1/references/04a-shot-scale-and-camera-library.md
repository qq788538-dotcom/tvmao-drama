# 景别与运镜导演知识库

本文件把本地 Seedance 专业资料中的导演读解、镜头合同、连续性账本和稳定性规则，收敛为当前项目的内部真人短剧导演规范；最终再由阶段 04 编译为可直接写入 `storyboard[].prompt` 的 `镜头N` 模型指令。先决定戏为什么这样拍，再选择景别和运镜；不得从运镜菜单随机抽取技巧。

## 零、本地资料取舍

| 资料 | 可移植能力 | 在本 skill 中的位置 | 不直接照搬的部分 |
|---|---|---|---|
| Seedance 官方提示词指南／官方发布说明 | 顺序 `镜头N`、标准景别和运镜词、按镜头描述空间层、主体动作与声音 | 阶段 04 的模型提示词编译器 | 不强塞逐镜精确时间段，不发送内部导演分析 |

| `seedance-sequence` | 多镜头职责、镜头间状态交接、连续性检查 | 整集镜头弧线、镜内咬合、边界账本 | 不使用只在某些产品表面有效的时间轴语法 |

结论：**复杂导演判断留在内部，最终 prompt 必须是结构化镜头指令，不是普通叙事段落。** 当前项目的 `@[角色/场景/物品-名称]` token 继续保留，因为后端会将其改写成资产引用；这不改变 Seedance 的镜头语法。

## 一、先做导演读解

每个 storyboard 写 cNN 前，内部回答五个问题：

1. **功能**：本段承担建立、推进、转折还是兑现？
2. **价值转变**：安全→受威胁、掌控→失控、怀疑→确认等，本段具体改变了什么？
3. **主观归属**：观众站在谁的体验里？
4. **权力变化**：谁占主动，权力在哪一刻转移？
5. **潜台词**：角色嘴上说什么，身体真正泄露什么？

将答案压成一个可拍摄意图，并让景别、机位、运镜、表演和声音共同服务它。若某项技巧无法回答“为什么此刻要这样拍”，删除该技巧。

## 二、统一导演声部与整集镜头弧线

真人短剧默认采用**克制写实的观察型声部**：平视为主、构图清楚、固定机位占主体、移动镜头只标记关系或认知变化。若剧本类型明确，可选择其他声部，但一集只用一个主声部；偏离只用于一次关键转折。

| 弧线位置 | 景别趋势 | 运镜趋势 | 剪辑作用 |
|---|---|---|---|
| 开放 | 远景／全景／中全景建立空间，随后进入中景 | 固定或一次缓慢横移 | 让观众先认清人物、方位和轴线 |
| 升级 | 中景→近景，关系逐渐收紧 | 固定为底，最多一次推镜或跟拍 | 压缩心理空间，不连续重复推镜 |
| 转折 | 用景别或运动的**单次反差**标记价值翻转 | 前面移动则此处固定；前面固定则此处一次明确移动 | 让形式变化等于剧情变化 |
| 高潮 | 近景／特写承载决定性反应；需要孤立时可突然回到全景 | 一个决定性推镜、快速横移，或完全固定 | 只保留最有意义的一种手段 |
| 释放 | 从近景回到中景／全景，恢复空间和呼吸 | 固定或缓慢拉镜 | 给结果和余韵，不继续加压 |

先在镜头衔接账本中给每个 storyboard 标记 `开放／升级／转折／高潮／释放`、景别趋势、运镜趋势和是否为反差镜。不得让每个 storyboard 都重新从“中景推到特写”。

### 解说视觉模式到摄影策略

`visualMode` 先决定镜头功能，再从该功能的候选中选择景别和运镜；它不是把所有内容安全地拍成中景的理由。

| visualMode | 首选景别功能 | 运镜选择 | 必须交付的画面结果 |
|---|---|---|---|
| `establishing`／`transition` | 远景、全景或中远景 | 固定为底；人物进入、空间揭示时才用跟拍、横移或拉镜 | 地点、路线、人物与环境关系可读 |
| `enactment` | 中全景或中景；动作关键处可切近景 | 固定、跟拍或横移三选一 | 动作从起点到可见结果完整 |
| `evidence` | 特写或大特写；先需关系时从中景进入 | 固定插入镜；遮挡解除、信息出现时可短推或横移 | 物件、地界、伤痕、结果等证据成为画面主语 |
| `reaction` | 近景或特写 | 固定为底；价值翻转点才允许短推 | 微动作或表情落点清楚，不能用泛转头代替 |
| `dialogue` | 双人中景建立后用近景／过肩 | 固定为主；关键词触发且口型稳定时才短推 | 说话人与听者关系、关键反应和口型可读 |
| `flashback` | 先用全景／中远景锚定过去时空，再切证据细节 | 转场镜只用一次，内部仍按事件任务选择 | 过去时空的进入、证据与退出边界清楚 |

全篇八个有效镜头以上时，导演账本至少要出现一次空间建立景别（远景／全景／中远景）和一次证据或反应落点（特写／大特写）；四镜以上的单个 storyboard 至少使用两种景别。摄影机移动只在人物、物件、空间或信息变化值得移动时使用；全固定方案只有在明确采用有意静止声部，并以充分的景别覆盖或机位变化组织弧线时才成立。二十四镜以上若同一种移动镜覆盖三分之一以上镜头，必须重新分配运动动机；只用一次决定性移动时，不为凑配额再加技巧。以上是防止安全模板塌缩的覆盖闸门，不是运镜配额。

## 三、景别阶梯与叙事功能

景别从松到紧的固定序列为：

`远景 → 全景 → 中远景 → 中全景 → 中景 → 近景 → 特写 → 大特写`

`过肩`是机位关系，不是景别；写成 `中景→中景，过肩`，不得写 `过肩镜头→近景`。

| 景别 | 主要用途 | 稳定性注意 |
|---|---|---|
| 远景／全景 | 建立地理、人物处境、进出场与大动作 | 不承担细微表情或口型 |
| 中远景／中全景 | 两人关系、走位、递物、起身、进门 | 保持世界路线、轴线侧和道具归属；屏幕方向只约束连续运动 |
| 中景 | 对话、普通动作、关系推进的默认景别 | 真人短剧最稳定的主力景别 |
| 近景 | 关键台词、迟疑、权力变化 | 动作减小，优先固定或极缓推镜 |
| 特写 | 决定性反应、关键道具、信息揭示 | 一镜只保留一个脆弱锚点 |
| 大特写 | 极端情绪或决定性细节 | 稀用；不用来承载大动作或长对白 |

景别选择规则：

- 建立空间后再进入人物，不用连续特写让观众失去方位。
- 同一主体的相邻切镜若构图相近，至少跨两级景别，或改变主体／机位角度 30° 以上；否则容易形成跳切。
- 单条 2~3s cNN 内最多跨两级景别。超过两级通常意味着运动过快或任务过多，应拆镜。
- 固定机位不改变景别；若人物主动走近镜头，景别变化来自人物动作，仍应改写为独立动作镜，避免把它冒充运镜。
- 情绪高点使用特写后，下一节拍应固定承接、切听者反应或放松景别，不继续机械推近。

## 四、景别与机位选择矩阵

| 戏剧功能 | 推荐覆盖 | 推荐机位 | 优先运镜 |
|---|---|---|---|
| 场景建立／人物到达 | 全景或中全景 | 平视、侧面 | 固定、横移或跟拍三选一 |
| 双人关系建立 | 中全景或中景双人 | 中性侧面、过肩 | 固定 |
| 普通对白 | 中景／近景单人 | 过肩或平视反打 | 固定 |
| 权力对抗 | 中景→近景 | 强者略低角度、弱者略高角度，保持轴线 | 权力转移点才允许一次缓慢推镜 |
| 发现／真相揭示 | 中景→近景或近景→特写 | 主观视角、过肩、物件插入 | 推镜、摇镜或固定反应三选一 |
| 决定／态度落定 | 近景→特写 | 平视正面或三分之二侧面 | 极缓推镜或固定 |
| 追逐／快速行动 | 中全景或中景 | 侧面、低机位 | 跟拍、手持跟随或横移三选一 |
| 孤立／失败 | 全景留负空间，或近景压缩背景 | 平视、高角度 | 固定或缓慢拉镜 |
| 喜剧落点 | 中景，清楚展示空间关系 | 正面或中性侧面 | 固定并多停半拍 |
| 道具证据 | 特写 | 插入镜头 | 固定、极缓横移或推镜三选一 |

两人对白默认覆盖顺序：双人建立镜 → 说话人过肩／单人镜 → 听者反应镜 → 必要的物件插入镜。先建立 180° 轴线，再做反打；视线方向必须相反且高度匹配。若要越轴，先给正面中性镜、全景或可见绕行重建轴线。

## 五、导演决策卡与摄影机物理契约

写每条 cNN 前先在内部完成一张导演决策卡，不写入 JSON：

1. **不可替代的镜头任务**：删掉这一镜，观众会漏掉什么变化？
2. **景别理由**：为什么观众此刻应站这么远，而不是更近或更远？
3. **固定替代测试**：只用固定机位和表演能否完成意图？如果能，默认固定。
4. **运动理由**：摄影机移动具体改变观众与人物的距离、信息、阵营、权力或运动关系中的哪一项？若一项都没有，不移动。
5. **运动时机**：哪一个眼神、动作、道具变化或关键词触发摄影机开始移动？
6. **落点理由**：摄影机为什么停在这个构图？落点是否就是本镜的剧情变化？
7. **全局关系**：这次景别／运镜是延续整集模式，还是只在转折处有意打破模式？
8. **稳定风险**：最容易漂移的是脸部、嘴型、双手、服装还是道具？如何简化动作或摄影机？

最终 prompt 不堆八个字段，只编译已经做出的导演选择，并使用 Seedance 2.0 的 `镜头N` 顺序分镜。移动镜使用标准字面短语：

`镜头2：中景，平视，滑轨缓慢推镜至近景。先稳定@[角色-林砚]读信的中景；当他看见落款并压住@[物品-信封]时开始推近；停稳在抬眼前的人物近景，保持脸部和信封形状。`

固定镜也必须说明观看关系和终点：

`镜头3：近景，过肩，固定机位。@[角色-林母]始终扶住门框，说完后保持注视，脸部和嘴型稳定。`

物理契约包含但不要求逐项贴标签：

- **镜头支撑**：`固定机位／三脚架／滑轨／轨道／稳定器／肩扛／手持／摇臂`；只保留实际影响生成的一项。
- **主运镜**：基础运动只用 `固定／推镜／拉镜／横移／摇镜／升降／跟拍／环绕／手持跟随`，一句内只能有一个。
- **起点与稳定入幅**：第一帧构图可见；移动镜默认先稳定约 0.3s，不从第一帧无故漂移。
- **触发点**：摄影机在剧情变化发生时才动，不以“增加动感”为触发理由。
- **速度与主体关系**：说明极缓／缓慢／均匀／快速，以及观察／靠近／远离／伴随／引导／发现／绕看哪个主体。
- **终点与停稳**：运镜在 `(落幅:)` 前完成并停稳，末帧可剪接；不得运动到切点才戛然而止。
- **稳定锚点**：保住最脆弱的 1~2 项；锚点越脆弱，运镜和表演越简单。

### 运镜时机：稳—动—稳

移动镜头默认遵循三段时机，而不是全程均匀漂移：

1. **稳**：先让观众读懂构图、主体和动作初态。
2. **动**：只在价值变化的触发点开始运动，例如看见证据、说出关键词、权力转移、人物作出决定。
3. **稳**：在反应或动作结果上停住，让观众看清变化并给剪辑留下落点。

对白镜若使用推镜，必须写清“在哪句台词或哪个微动作时开始”，并在口型结束前或表演落点上停稳；不得整句对白持续无意义推近。

## 六、九类主运镜的动机与物理边界

| 主运镜 | 适用意图 | 景别物理 | 优先支撑 | 禁忌 |
|---|---|---|---|---|
| 固定 | 对白、反应、喜剧时机、关键道具、口型稳定 | 起止景别相同 | 固定机位／三脚架 | 不写“固定”却让摄影机绕行或改变景别 |
| 推镜 | 发现、决定、逼近、认知收紧 | 只能由松到紧，最多两级 | 滑轨／轨道 | 同一 storyboard 连续推镜 |
| 拉镜 | 揭示环境、疏离、失败、释放 | 只能由紧到松，最多两级 | 滑轨／轨道 | 在秘密揭晓前提前暴露全貌 |
| 横移 | 伴随行走、揭开遮挡、展示并列关系 | 默认保持同级景别 | 滑轨／稳定器 | 同时再推近或环绕 |
| 摇镜 | 从人物视线转到对象、重新分配注意力 | 保持同级景别 | 三脚架 | 来回摆动或承担多个揭示 |
| 升降 | 身份出场、尺度揭示、空间层级变化 | 保持同级景别 | 摇臂 | 对白、脸部特写、狭小室内乱用 |
| 跟拍 | 行走、追逐、进入空间 | 保持主体景别与运动方向 | 稳定器／轨道 | 主体停下后摄影机仍无目的漂移 |
| 环绕 | 权力翻转、孤立主体、英雄式揭示 | 保持同级景别 | 稳定器 | 多人对白、脆弱脸部、狭窄空间；单 storyboard 最多一次 |
| 手持跟随 | 危机、追逐、纪实不安 | 保持主体可读和同级景别 | 肩扛／手持 | 口型、道具文字、精细手部动作；只允许轻微呼吸晃动 |

## 七、稳定出片的复杂度预算

- 每个含两个以上模型镜头的 storyboard 至少有一条 `固定机位`，为人物身份、空间或动作结果提供稳定锚点。
- 每个 storyboard 最多一次推镜；推镜只放在真正的认知／权力变化上。
- 2~3s 子镜头默认使用固定、推镜、拉镜、横移、摇镜或稳定跟拍中的一种；环绕、升降、手持跟随只在剧情明确需要时使用。
- 带同步对白、脸部特写、手部精细动作、道具形状／文字的镜头，优先固定；若移动，只允许极缓或缓慢的单轴运动。
- 一镜只有一个主要人物动作。摄影机运动已经复杂时，人物动作进一步减小；人物动作复杂时，摄影机固定或只伴随。
- 主运镜必须在本镜落幅前停止。跨 storyboard 不保留开放的摄影机运动相位，不把“正在推／摇／环绕中”留给下一次独立生成。
- 同一 storyboard 内若连续两镜服务同一主体，不重复相同移动方式；用“移动镜建立变化 → 固定镜承接结果”形成接力。

## 八、镜头咬合与剪辑检查

逐镜检查：

1. 前镜落幅与后镜起幅的人物世界锚点、轴线侧、朝向、视线、道具和动作相位是否一致？画面左／右是否只在同机位或连续运动时按需承接？
2. 同一主体连续切换是否满足两级景别差或 30° 机位变化？
3. 运动方向是否一致？需要反向时是否先完成转身或给中性镜？
4. 前镜主运镜是否已经停止，后镜是否重新声明新的摄影机起点？
5. 是否出现“固定却变景别”“推镜却变远”“拉镜却变近”“横移同时推近”等物理冲突？
6. 镜头复杂度是否让脸、手、嘴型或道具锚点容易漂移？若是，先简化运镜，再减少动作。

稳定不是让所有镜头都不动，而是让**运动只发生在值得移动的时刻，并且有可见起点、单一轨迹和明确终点**。

## 九、三种短剧调度范式

这些范式展示“为什么用”，不是固定镜头模板。

### 对峙：只在权力转移时移动

1. 中景双人固定，建立座位／站位、视线轴线和谁占据更多构图空间。
2. 强势方过肩近景固定，让台词和静止表演承担压力。
3. 权力转移到弱势方时，才从近景极缓推到特写；触发点是证据被放到桌上，终点是弱势方抬眼。
4. 切回强势方固定反应镜，让前一镜的推近产生后果。

错误做法：双方每句台词都推近；结果是运动没有层级，关键转折反而不突出。

### 揭晓：先隐藏，再让摄影机发现

1. 中景固定人物与遮挡物，观众暂时看不到答案。
2. 人物视线落向画外后，切物件特写，或用一次短摇镜把注意力转过去。
3. 答案出现后固定在人物反应，不再追加环绕或升降。

错误做法：第一镜就展示人物、证据和反应，再用运镜重复已经给出的信息。

### 行动：移动承担过程，固定承担结果

1. 中全景固定建立路线与屏幕方向。
2. 稳定器跟拍保持人物景别，只承载一次明确行动。
3. 动作完成后切固定中景／近景，显示代价、结果或人物反应。

错误做法：跟拍、推镜和手持晃动叠在同一镜，且在人物尚未停稳时切到下段独立生成。
