# 阶段 03：解说时长、画面映射与分镜切分

连续解说语音是时间主轴；2～3 秒画面节拍覆盖在声音时间轴上，为当前信息提供同步证据。`DURATION_SEC` 只控制一次视频生成的片段上限，全文总时长由完整解说稿、规划时钟和少量明确停顿自然得出。

## 一、先算语音，再分镜

1. 按 `narrationUnits` 顺序建立语音账本。
2. 基础规划值固定为 3 个语义字符／秒。匿名解说使用 `planningCps = 3 × playbackRate`，`playbackRate` 只允许 1.5／1.6／1.7／1.8、缺省 1.6；非解说声音使用 `planningCps=3`。这只是片段预算，不是 Seedance 请求中的真实音频倍速。
3. 每条语音 `targetSec = ceil((语义字符数 ÷ planningCps) × 10) ÷ 10`。保留 0.1 秒精度；不能把每条短意群先向上取到整数秒。
4. 匿名解说最多 14 个语义字符；角色对白、OS、具名 VO 和系统声最多 9 个。长句按自然换气或信息转折拆开，但拆分不等于另起视觉镜头。
5. 关键人物对白采用稳定机位和短句；解说与人物对白不同时发声。`pauseAfterSec` 只允许 0 或 0.5；仅在真实反转、对白交接、重大结果或时空转换时使用 0.5 秒。
6. 每个语音单元在最终 prompt 中恰好出现一次；视觉蒙太奇不能替代声音。禁止把 `1.6倍速` 等数值倍率写入 prompt。每个 storyboard 首个匿名解说写 `解说（画外音，电影解说式快速清晰、连续无拖腔）`，后续写简洁的 `解说（画外音）`。

**语音完整性高于片段压缩**：已有解说剧本中的解说、对白、OS／VO、系统或其他有文本声音不得静默删除、改写、重排或视觉化替代；小说／普通剧本在 `condensed` 计划通过后，最终分镜也不得再次删改计划语音。若当前 `DURATION_SEC` 无法自然容纳，拆分 storyboard；不能提高规划倍率硬塞，也不能在提示词里伪造数值倍速。

## 二、语音到内部镜头

- 内部 cNN 以 2～3 秒为主；它是视觉节拍，不是语音句子的容器。连续解说可以在一个内部切镜点前后持续，一条语音可覆盖一到两个画面，但声音文本只在开始镜写一次。切画面不打断、暂停或重新起声；连续单元前句收尾后立即接后句。
- 同一镜只承担一个主要视觉事实。先写可见主体、场景区域和空间关系，再写事件证据、动作结果和声音。
- 每条解说开始时，支撑它的画面必须已经进入构图。允许声音结束后短留反应，不允许声音长期领先空泛画面。
- 不因切到证据、反应或关系镜就重新起一句解说，也不因一个语音单元结束就强制切镜。音频意群边界和画面切点分别规划，在剧情信息落点对齐。
- 反转、身份揭晓、结果画面不得早于对应解说词。将其记录为 `reserved_for_later`，只在当前单元说到时释放。
- 相邻解说若描述同一动作链，可保持动作连续；若转入过去、异地或因果解释，使用独立建立镜或明确时空转场。

## 三、视觉模式选择

按 `visualMode` 执行，不机械逐字插图：

- `enactment`：人物完成原文动作，落到可见结果；
- `evidence`：让地界、物品、环境或结果成为画面主语；
- `reaction`：只用于心理、态度和权力变化，必须是具体行为；
- `establishing`：交代人物在环境中的位置和处境，不拍无人空景；
- `transition`：用物件、光线、动作或构图连接新时空；
- `flashback`：建立不同时间质感，并在结束时明确返回；
- `dialogue`：说话人入镜、稳定构图、短句、口型期间减少大动作。

连续镜头必须各自增加新信息。禁止用多条近似的走路、抬头、握拳、看远处画面承载不同解说事实。

## 四、storyboard 切分

当前项目把每个 storyboard 作为一次彼此独立的视频生成提交；后段不会自动取得上一段成片、尾帧或真实运动相位。因此边界必须在完整语音和完成动作之后，并通过可剪辑状态而不是真实尾帧承诺来咬合。

- 每个 storyboard 为一次独立生成，`duration` 为 `4..DURATION_SEC` 的整数，但必须按内容计算，禁止默认填上限：
  - 一条语音单元必须对应一段完整引号语音；声音可以跨内部视觉切镜持续，但不得跨独立 storyboard 被截成半句；
  - `continuousVoiceSec = ΣtargetSec`，直接累计 0.1 秒精度，不对每条语音分别取整，也不设每条至少 2 秒；
  - `plannedPauseSec = ΣpauseAfterSec`，普通连续解说为 0；画面切镜与语音并行，不以“镜头数－语音数”追加静音时长；
  - `contentSec = max(4, ceil(continuousVoiceSec + plannedPauseSec + 1))`，其中整段稳定入幅和安全尾帧合计 1 秒；
  - 若 `contentSec <= DURATION_SEC`，`duration` 必须精确等于 `contentSec`；若超过上限，在完整语音意群和自然剪辑点拆成两个 storyboard，不能把倍率提高到范围外。
- 当 `DURATION_SEC>=12` 时，使用贪心装载：同场、同一因果链且无真实停顿的下一语音单元只要仍能装入，就继续留在当前 storyboard。优先形成 12～15 秒附近的快速解说片段；包含匿名解说的 12～15 秒片段集中约 45～60 个有声语义字符。只有下一单元会超过时长／60 字上限，或当前已到反转、重大结果、对白交接、时空切换，才允许提前切段；全文最后不足 12 秒的余量可独立收尾。
- 一个 storyboard 只有一个叙事任务和一个完成终点。视觉镜头数控制在 `ceil(duration÷3)..floor(duration÷2)`；即每个画面一般 2～3 秒，首个三秒钩子通常只给一个清楚事件，不塞三次运镜。
- 边界必须落在完整语音意群、动作完成、明确反应、证据揭示或时空切换之后。
- 末镜动作和声音落定后留约 0.5 秒安全尾帧；下一段首镜先给约 0.3～0.5 秒稳定入幅，再执行新动作或开口。两者都已包含在公式的安全头尾预算中，最终 prompt 只写“先稳定／保持半秒”。
- 同场跨多个 storyboard 时统一使用 `空间母版-场景名`，通过世界锚点保持人物、门窗、道路、家具、道具和光源关系。

## 五、片段咬合

只使用：`动作完成切、反应切、视线切、物件切、构图匹配切、时空转场切`。

相邻片段入点和出点类型一致。独立生成不能承诺真实尾帧或解说音色天然无缝延续，因此不在半动作、半句话、运动模糊或持续口型中切断；解说在当前 storyboard 结束前完成一个意群，下段继续使用同一种“电影解说式快速清晰、连续无拖腔”声音方向。环境声底同场保持一致，跨时空时先收束旧声场，再建立新声场。

原生 Seedance 发声仍是概率控制：上述规划时钟和字数密度用于避免明显过慢、过空，但不能保证精确 1.6 倍。需要跨片段完全一致的音色、时长和真实倍速时，使用统一 TTS 连续铺轨或后期变速，Seedance 只负责画面、环境声和必要角色原声。

切分后建立镜头衔接账本，逐段记录：唯一叙事任务、开放／升级／转折／高潮／释放位置、景别和运镜趋势；逐镜记录意图、起落幅、人物动线、摄影机触发与终点；逐边界记录切点类型、轴线、世界锚点、视线、道具归属、光线相位和环境声底。进入阶段 04 前先完成边界闭环。

## 六、全文与测试范围

`faithful` 模式不设 90～135 秒总时长上限；长小说在本次 Run 中按场景、冲突阶段和语音时长连续增加 storyboard。当前输出 schema 不表达多集；如需多集，必须由上游按明确原文范围分别运行。测试或调试可以显式指定原文范围，但必须在 `narration_plan.json` 的 `sourceText` 和 `sourceUnits` 中只放入该测试范围，不能假装已经覆盖全文。
