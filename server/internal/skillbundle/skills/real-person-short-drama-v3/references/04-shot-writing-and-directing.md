# 阶段 04：镜头编写与 Seedance 2.0 提示词编译

先用 [景别与运镜导演知识库](04a-shot-scale-and-camera-library.md) 在内部完成导演读解、cNN 时长规划和镜头选择，再用 [调度、构图与光线连续性](04b-blocking-composition-lighting.md) 建立场级视觉基线与镜级变化量，并按 [约束与负面提示词编译](04c-constraint-and-negative-prompt-compiler.md) 建立风险—约束账本，最后将规划**编译**成 Seedance 2.0 模型友好的 `镜头1／镜头2／镜头3` 分镜提示词。导演分析用于做决定，不作为提示词散文发送给模型。

> 官方指导边界：Seedance 2.0 同时理解空间层“画面里有什么”与时间层“事情如何变化”。按镜头顺序组织，每镜使用标准景别／运镜术语，并写清主体、动作、场景环境、位置／空间变化与音频；一镜尽量只指定一种运镜。官方资料没有要求每镜把八大要素逐项填满，但复杂影视化分镜不能省掉空间层。精确 `0–3s` 时间限制可能影响稳定性，因此 cNN 秒数只保留在内部账本，最终 prompt 由 `storyboard.duration` 控制整段时长。

资料优先级：以[火山引擎 Seedance 2.0 官方提示词指南](https://www.volcengine.com/docs/82379/2222480?lang=zh)和 [ByteDance Seedance 2.0 官方发布说明](https://seed.bytedance.com/en/blog/seedance-2-0-official-launch)定义模型侧写法；本地 `seedance-camera`、`seedance-sequence`、`seedance-continuation` 只补充导演动机、连续性和稳定性。两者冲突时，模型 prompt 语法以官方公开指南为准。

## 五、两层镜头契约

### 5.1 内部导演层：决定为什么这样拍

每条内部 cNN 必须记录：

- 一个可见意图；
- 空间层起幅：可见主体、具体场景区域、主体位置、朝向／视线、前后景与物理光线；
- 时间层起幅：动作相位和道具状态；
- 主表演者的起点—路径—终点，以及次要人物是否需要保留微动；
- 景别选择理由与唯一主运镜选择理由；
- 移动镜的稳定起点、剧情触发点、速度、主体关系、停止终点；
- 该镜构图用途、是否继承场级光线，以及剧情触发的光线／氛围变化；
- 可能破坏本镜意图或连续性的具体风险、优先使用的正向状态锁，以及是否确有必要写局部排除句；
- 落幅、稳定锚点和下一镜／下一段的剪辑方式。

逐镜通过七项导演决策闸门：

1. **任务成立**：删镜会丢失剧情变化、信息、反应或空间关系。
2. **距离成立**：能解释为什么观众此刻站在这个景别。
3. **固定替代成立**：固定镜若能完成任务，默认固定。
4. **运动成立**：移动确实改变距离、信息、阵营、权力或运动关系。
5. **时机成立**：能指出触发摄影机开始运动的动作、眼神、道具变化或关键词。
6. **落点成立**：摄影机停止位置就是剧情落点。
7. **全局与稳定成立**：符合整集导演声部，并照顾脸、嘴型、手或道具等脆弱锚点。

任何一项答不清，回到导演读解重新选镜，不得用更多术语掩盖判断缺失。

### 5.2 模型执行层：只发送官方友好的短镜头块

`storyboard[].prompt` 使用：

```text
真人电影风格,画面不要出现任何文字，生成视频无BGM；
镜头1：起始景别，机位角度，标准运镜短语。画面中可见主体位于@[场景-名称]的具体区域，写清构图／空间关系和本片段物理光源。主体完成一个动作并写清结果。[必要的一条视觉变化量或局部约束。]声音信息。【标签】
镜头2：起始景别，机位角度，标准运镜短语。画面中可见主体位于@[场景-名称]的具体区域，写清当前构图／空间关系。主体动作；移动镜写明触发时机与停稳结果。[必要的一条视觉变化量或局部约束。]声音信息。【标签】
```

使用空间母版时保持同一格式，只把逐镜场景 token 换为 `@[场景-空间母版-场景名]`。首镜用一句短状态锁说明本段继承的入口侧／窗侧座位、轴线和道具归属；后续镜头只写本镜变化量，不重复母版完整内容。反打或推近时明确落幅仍保留的前景肩部／门框等锚点；裁在画外的道具视为留在原位，不要求重新入画。世界坐标跨镜继承，画面左／右只在当前构图、横向运动、遮挡揭示或匹配剪辑确实需要时写，不把角色身份永久绑定在某一屏幕侧。

禁止把以下内部规划语法发送给模型：

- `c01,3s`、`0–3s` 等子镜头精确时间戳；
- `(意图:)`、`(起幅:)`、`(落幅:)`、`主运镜:` 等分析标签；
- “因为权力转移所以推镜”等导演解释；
- 同义运镜长句、参数清单和重复约束。
- 参考图已显示的人物外观细节和场景完整陈设清单；但不得以此为由省略当前镜头的具体场景区域和构图关系；
- `高级感`、`电影感运镜`、`唯美光影`、`增强氛围`等无物理来源、可见触发和结果的空泛指令。
- `负面提示词：`独立段落，或模糊、伪影、变形、闪烁、多手指、变脸等普通缺陷词堆叠。

### 5.3 镜头行的固定顺序

每行按“摄影机 + 空间层 + 时间层 + 按需变化量／约束 + 声音”组织：

1. **运镜或切换**：`景别，机位，标准运镜短语。`
2. **空间层画面基底**：必须以 `画面中` 起句，写可见主体、`@[场景-名称]` 的具体区域，以及至少一项相对入口／窗／家具／另一主体的世界锚点、朝向／视线、前后景、负空间、遮挡或主体距离关系。画面左／右／中央仅在当前取景确实依赖时添加。每个 storyboard 首镜再写一个物理光源与方向；参考资产只免除身份细节和完整陈设复述。
3. **时间层主体动作**：用 `@[角色-名称]`／`@[物品-名称]` 写一个可见动作、表演细节和完成结果；移动镜再写清触发与停稳结果。
4. **可选变化量／约束**：只在它直接承担本镜意图或独立片段连续时，写一条调度变化、物理光线变化、氛围互动、焦点转移或局部状态锁。它不占用第 2 项的最小画面基底。约束与视觉变化量共享稀疏预算；优先写正向状态，只在防止已完成动作重演或未来事件抢跑时使用短排除句。
5. **音频**：对白、画外音、环境声或音效；无配乐明确写 `无配乐`，不要重复风格串。

母版片段再通过三项删减检查：同段是否只发送一个空间答案；母版已锁定的普通道具是否被多余的单品图再次约束；移动镜落幅是否仍保留至少一个空间锚点。任一不满足，先删冗余参考，再改文字，不追加普通负面缺陷词。

参考格式：

`镜头2：近景，平视，滑轨缓慢推镜至特写。画面中@[角色-林砚]位于@[场景-旧宅]靠窗的木桌一端，半开的信纸占前景，通往走廊的门框留在后景。先稳定他低头读信的近景；当他读到落款时开始推近；停稳在他抬眼看向门口前的脸部特写并保持半秒。纸张摩擦声，无配乐。【背景虚焦，不出现任何文字字幕】`

该句只告诉模型“怎么拍、拍什么、何时动、停在哪”，不解释为什么推镜；“坏消息导致认知收紧”只留在内部导演账本。

参考图已经稳定承载人物身份和旧宅完整陈设时，不再复述发型、服装或家具清单，但仍要告诉模型本镜取靠窗桌端、信纸前景和门框后景。只有门真正打开并改变了光线时，才补变化量：`门打开时，走廊冷白光从门口切入屋内`。

## 六、Seedance 2.0 字面运镜词表

优先使用官方指导中模型容易直接理解的标准词，不造“情绪化运镜”新词。

| 内部主运镜 | 模型侧标准短语 | 景别物理 |
|---|---|---|
| 固定 | `固定机位` | 起止同景别 |
| 推镜 | `缓慢推镜至特写／近景`、`快速推镜至近景` | 只能由松到紧，最多两级 |
| 拉镜 | `缓慢拉镜至中景／全景` | 只能由紧到松，最多两级 |
| 横移 | `平稳横移`、`滑轨横移` | 默认保持同级景别 |
| 摇镜 | `缓慢摇镜`、`快速摇镜` | 默认保持同级景别，只转移注意力一次 |
| 升降 | `平稳升镜／降镜` | 默认保持同级景别 |
| 跟拍 | `横向稳定跟拍`、`稳定跟拍` | 保持主体景别与屏幕方向 |
| 环绕 | `弧形绕摄` | 保持同级景别，单 storyboard 最多一次 |
| 手持跟随 | `手持跟随，轻微呼吸晃动` | 保持主体可读，不用于口型／道具精细镜 |

硬规则：

- 一个模型镜头只能出现一个基础运镜词；`横移跟拍`、`推镜环绕`按两个运镜处理并禁止。
- 移动镜使用“稳—动—稳”：先读清构图，在剧情触发点启动，在动作／表演结果上停稳。
- 对白期间优先固定；若必须推镜，在关键词或微动作上启动，并在口型结束前停稳。
- 含两个以上模型镜头的 storyboard 至少一个固定镜；每个 storyboard 最多一次推镜。
- 不写 `电影感运镜`、`增强压迫感`、`动态镜头`、`高级镜头语言`等无法直接执行的词。

## 七、镜头之间的咬合

- 后镜动作初态承接前镜结果：人物世界锚点、轴线侧、朝向、视线、道具归属、门窗状态和光源来源不能重置。画面左／右只在同机位续拍、横向运动或构图匹配时承接；反打不机械复制。
- 动作不可重演：上一镜已完成的动作不再从头执行；需要隐藏动作跨越时，切反应、视线对象或物件。
- 同一主体相邻切镜至少跨两级景别，或更换主体／改变机位 30° 以上，避免近似构图跳切。
- 先用全景／中景建立 180° 轴线，再做过肩反打；越轴前先给正面中性镜、全景或可见绕行。
- 移动镜建立变化后，下一镜通常固定承接结果；不得每镜重新推近。

## 八、独立 storyboard 的自然剪辑衔接

项目会独立生成每个 storyboard，内部账本仍用 `B001、B002…` 对边界编号，但编号不发送给 Seedance。模型 prompt 使用自然剪辑短语：

- 上一段最后一个镜头写：`结尾供反应切／视线切／物件切／动作完成切／构图匹配切／时空转场切。`
- 下一段第一个镜头写：`开头承接反应切／视线切／物件切／动作完成切／构图匹配切／时空转场切。`
- 相邻两段的类型必须一致，数组顺序就是边界顺序。

边界要求：

- 上一段的动作、台词、口型和主运镜全部完成，最后保持约 0.5s。
- 下一段先给稳定构图约 0.3~0.5s，再启动新动作或新运镜。
- 同场延续轴线、人物世界位置、视线、道具状态和环境声底；屏幕运动方向只在连续横向运动或同机位动作时继承。
- 同场光源方向、冷暖、实用灯状态和可见氛围介质默认继承；只在光源熄灭、门窗打开或天气变化等物理触发出现时改变。
- 优先切到不同主体、视线对象、物件或明显不同景别；不让两个独立片段伪装同一帧无缝续拍。

## 九、导演细节

- 每句台词配一个具体、可见且不重复的微动作，不使用抽象情绪词替代表演。
- 特写／大特写只给真正的信息或情绪落点；高潮后用固定反应镜或较松景别释放。
- 同一 storyboard 内避免重复相同肢体动作、机位和运镜词。
- 荷兰角、直视镜头、逆光剪影、环绕、升降、手持等特殊手法只在剧情信号明确时使用；技巧不是配额任务。
- 最终每个模型镜头必须同时成立为空间层画面和时间层动作：一个最小画面基底、一个主动作、一个运镜、一个完成结果和必要声音；额外变化量或局部约束通常最多再选一项。
- 提示词过满时，先删普通负面缺陷词和空泛质量词，再删参考资产已表达的身份细节／完整陈设，然后删次要微动和次要摄影指令；不删每镜最小画面基底、主动作结果、运镜触发终点、参考 token、真正决定连续的局部状态锁与原台词。
