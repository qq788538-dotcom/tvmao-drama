# 调度、构图与光线连续性

本阶段补齐画面导演决策，但不把最终 Seedance 提示词变成字段表。核心是：**每镜先用空间层形成一幅可见画面，再用时间层描述动作与运镜；参考资产可以省略身份细节，不能省略本镜构图。**

## 一、资料边界

- Seedance 2.0 官方指导将提示词信息分为空间层“画面里有什么”和时间层“事情怎样变化”，复杂影视化分镜按运镜、主体动作、位置／空间变化与音频组织。它没有要求每镜逐项填满所有摄影字段，但空间层不能缺失。
- 本地 `seedance-prompt`、`seedance-camera`、`seedance-lighting`、`seedance-sequence` 提供的共同方法是：一镜一意图，物理光源优先于抽象氛围词，长序列维护持久状态，最终 prompt 删除参考图已经显示的信息。
- 下面的“镜级最小画面基底 + 场级视觉基线 + 稀疏变化量”是为当前项目独立生成、后期直接拼接的工程整合。

上述名称仅记录知识来源，所需规则已完整整合在本文件和阶段 04 中。项目运行时不得加载或调用外部 Seedance skill；`real-person-short-drama-v3` 目录必须自包含。

## 二、场级视觉基线（只在内部维护）

每个连续场景先建一份基线，同场 storyboard 默认继承，除非剧情触发了可见变化。

1. **地理与轴线**：出入口、窗、家具、座位和关键道具的世界方位；角色对话轴线、跨画面运动方向、视线对应。
2. **人物调度**：每位角色的起始站位、可用路径、前／中／后景层级、交互点和停止点；明确谁是主表演者，其他人只保留不抢主任务的持续微动。
3. **构图与焦点**：场的默认视觉中心、主体大致画面位置、视线空间、前景遮挡与纵深层次；只在叙事需要时设置景深或焦点转移。
4. **物理光线**：主光的可解释来源（窗、台灯、走廊、阴天或路灯）、方向、冷暖、实用灯开关状态、阴影相位与反射状态。
5. **色彩与氛围**：稳定的色彩倾向、对比关系、天气与可见介质。雾、雨、尘、烟只在与光线或人物动作发生物理互动时记录，不作装饰形容词。

场景资产承载空间全貌、材质和稳定美术基线；角色资产承载身份与服装。它们都不能自动决定当前镜头截取场景的哪一部分、人物站在画面哪里、前后景怎样组织，因此仍须编译镜级空间层。

### 2.1 把脆弱空间编译成一张母版

- 同一逻辑场跨两个以上独立 storyboard 时，将场级视觉基线实际生成为 `空间母版-场景名` 场景资产；多角色反打、座位关系或道具归属容易漂移的单段也可使用。
- 母版只锁**持久状态**：人物身份与固定位置、对话轴线、入口／窗、桌椅几何、关键道具归属和物理光向。镜头景别、当前表演、一次主运镜和声音仍由各 storyboard prompt 控制。
- 同场所有片段引用同一母版；未入镜的锚点视为仍在画外原位，不为“交代连续性”强行移进构图。道具不需要出现在每个反打里。
- 一旦剧情完成起身、换座、开门或移交道具等真实状态变化，从动作完成后的边界起切换到带状态后缀的新母版；不能让旧母版和新状态同时约束一段。
- 母版是参考，不是最终构图。每条 `镜头N` 仍写具体可见区域、人物相对物理锚点／彼此／前后景的关系、视线和落幅；尤其要写移动镜结束时保留哪个空间锚点。画面左／右只在本镜构图或运动确实依赖时补充。

### 2.2 世界坐标强锁，画面坐标按镜选用

连续性先锁跨机位仍成立的**世界坐标**，再按当前摄影机选择是否需要**画面坐标**：

- **必须继承的世界锚点**：入口侧／窗侧座位、长桌轴线、门内／门外、靠墙／靠窗、谁持有道具、光源从哪一物理方向进入、人物走到哪个交互点。母版和边界账本优先写这些关系。
- **默认镜头写法**：`入口侧座位上的单知影`、`落地窗侧对座的相里凛`、`对方肩部留在前景`、`沿长桌轴线对视`、`木盒仍在单知影手边`。它们既给出画面选择，又不会把摄影机锁死。
- **按需使用画面左／右**：主体明确横向进出画或跨画移动；负空间、遮挡、揭示、运动终点或构图匹配决定剪辑；同机位连续动作需要保持屏幕方向。此时画面坐标属于当前镜头契约，不是角色永久属性。
- **禁止机械继承**：不得把“单知影始终在画左、相里凛始终在画右”当作跨反打连续性。反打后屏幕位置可能改变；判断连续性看是否留在同一对话轴线侧、世界座位、视线和道具归属是否一致。
- **防漂移判定**：若人物仍在同一世界锚点但构图因反打变化，不算漂移；若提示词让人物从入口侧座位无动作跳到窗侧、换座、换手持物或越过桌轴，才算空间状态错误。

## 三、镜级调度决策（只在内部维护）

每条 cNN 除了意图、景别和摄影机契约，再记录：

- **主表演者**：这一镜的一个主体，其他角色是视线对象、前景或背景支撑。
- **起点—路径—终点**：主体从哪里开始，是否跨越画面或前后景，与谁／什么交互，最后停在哪里。没有空间位移时，只记录稳定站位，不虚构动线。
- **构图用途**：构图是否承担揭示、权力、隔绝、视线空间、前景遮挡或剪辑匹配。若无叙事任务，继承场基线。
- **光线／氛围变化**：只记录可见的剧情变化，例如开门让走廊冷光切入、台灯熄灭、车灯扫过墙面。无变化时写“继承场基线”即可。
- **边界状态**：主体世界终点、轴线侧、按需屏幕运动方向、道具归属、主光来源／相位、实用灯状态和持续氛围，供下一镜与下一 storyboard 对账。

逐镜先做这些决策，再由阶段 04 删除不需要发送给模型的内容。

## 四、模型侧的空间层与时间层

### 4.1 每镜最小画面基底（必须写）

每条 `镜头N` 的摄影机头部之后，必须以自然短句写出 `画面中……`，至少包含：

1. **可见主体**：本镜真正入画的角色或物件 token；环境空镜则以场景为主体。
2. **具体场景区域**：必须出现 `@[场景-名称]`，并指出镜头看到的是桌边、门口、走廊、窗边、院门或其他具体区域，不能只在 storyboard 引用数组里声明场景。
3. **构图／空间关系**：至少写清一项相对入口／窗／家具／另一主体的世界锚点、朝向与视线、前景／中层／后景、负空间、遮挡或主体距离关系。画左／画右／中央是可选的当前镜头坐标，不是必填字段。
4. **片段视觉基线**：每个 storyboard 的首镜写一个有物理来源的主光方向与冷暖，并在需要时补一项与光或人物互动的氛围；后续镜头默认继承，只在光源或环境发生变化时重写。

这四项不是让提示词变成清单。合格的空间层通常只需一到两句：

`画面中@[角色-林砚]坐在@[场景-旧宅]靠窗的木桌一端，半开的信纸占据前景，通往走廊的门口留在后景；桌边台灯暖光落在他的手和纸面。`

### 4.2 参考承载身份，文字必须选择画面

- 参考资产可以省略人物的脸型、发型、服装细节，以及场景资产已经稳定的完整陈设清单。
- 使用空间母版时，不同时发送基础空景；母版已锁定的普通道具也不再重复作为视频参考图。参考图过多会让模型在多个几何答案之间折中。角色图只保留实际入画／发声者，关键物件图只在特写需要时保留。
- 参考资产不能省略当前镜头的场景 token、可见区域、主体世界锚点／关系、朝向、前后景和构图重心；这些信息决定“这一帧具体长什么样”。画面左／右只在本镜需要精确投影时添加。
- 文字仍以最小足够为准：写本镜选择出的画面和必要变化，不复述整个资产提示词。
- 若必须改变光线或空间基线，写物理触发和可见结果。

### 4.3 什么时候再写视觉变化量

| 类型 | 写入条件 | 稀疏写法 |
|---|---|---|
| 调度 | 跨越空间、进出画、权力位置、轴线或交互终点影响理解 | `从木桌靠窗一端绕到门口，停在门内`；若横向轨迹是镜头意图，再补画面起止位置 |
| 构图 | 揭示对象、负空间、遮挡、纵深或构图匹配是剧情机制 | `人物近景占一侧，通往走廊的门口留出负空间`；只有匹配剪辑需要时指定左／右 |
| 光线 | 光源变化本身就是戏，或跨独立片段容易来源／冷暖跳变 | `门打开时，走廊冷白光从门口切入屋内` |
| 氛围 | 雨、雾、尘、烟与光、人物或道具发生可见互动 | `开门带入雨雾，走廊光里可见细密水滴` |
| 焦点／景深 | 关键信息需要从一层转到另一层，或背景会干扰主体识别 | `焦点从前景信封转到门口人物` |

表中的内容是最小画面基底之外的**变化量**。每条 `镜头N` 通常最多再选一项；只有当第二项直接决定独立片段的轴线、光线或剪辑连续时才保留。不得把“变化量最多一项”误读成“每镜只写动作”。

### 4.4 压缩顺序

提示词过满时，依次删除：

1. 空泛质量词和情绪形容词；
2. 参考资产已显示的人物身份细节和场景完整陈设清单；
3. 不影响主动作或剪辑点的次要人物微动；
4. 不承担揭示、调度或连续性的景深、光影和氛围修饰；
5. 次要运镜与次要动作。

保留顺序为：每镜最小画面基底与参考 token → 主体动作和完成结果 → 主运镜的触发与终点 → 原台词／必要声音 → 连续约束 → 真正必要的一条视觉变化量。

## 五、对比示例

**场级内部基线**：旧宅木桌靠窗，通往走廊的门在桌后；林砚坐在靠窗一端；桌边台灯是稳定暖主光，屋内安静。这些世界关系全部在账本中保留，画面左／右由当前机位决定。

**错误：只有动作，没有空间层**：

`镜头1：中景，平视，固定机位。@[角色-林砚]拆开@[物品-信封]，信纸完全展开后手指停在落款旁。纸张摩擦声，无配乐。`

**正确：先形成可见画面，再发生动作**：

`镜头1：中景，平视，固定机位。画面中@[角色-林砚]坐在@[场景-旧宅]靠窗的木桌一端，@[物品-信封]位于前景，通往走廊的门口留在后景；桌边台灯暖光落在他的手和纸面。他拆开信封，读到落款后手指停住。纸张摩擦声，无配乐。`

**光线本身发生剧情变化时才写**：

`镜头2：近景，平视，固定机位。画面中@[角色-林砚]的脸和持信双手占据@[场景-旧宅]桌边近景，通往走廊的门框虚影留在后景。他抬眼看向门口；门打开时，走廊冷白光从门口切入屋内，他的手停在信纸上。门轴轻响，无配乐。`

不写：`电影级唯美光影，氛围感拉满，高级构图`。这些词既没有物理来源，也没有可见触发或结果，只会与参考资产和模型的自动规划争抢空间。
