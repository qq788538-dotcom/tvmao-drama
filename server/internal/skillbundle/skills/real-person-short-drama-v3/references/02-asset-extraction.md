# 阶段 02：资产提取

从归一化剧本中提取并去重角色、场景、物品，统一命名、分类、造型状态，并编写资产生图提示词。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 三、顶层 `character` / `scene` / `item`（整集去重资产 + 生图提示词）

- **覆盖整集去重**：列出本集出现的**所有**角色/场景/物品。`name` 用**规范名**（纯名，不带 `@`、不带类型前缀），与 prompt 里 `@[类型-名称]` 名称严格一致。
- **分类硬规则**：
  - **动物（母云豹/云豹幼崽/金雕/狗…）归 `item`**，即使有动作/会移动，也只进 `item`、写 `@[物品-母云豹]`，绝不进 `character`。归在物品的条目不得出现在角色，反之亦然。
  - 同一角色不同造型分别成项，用**括号包裹的描述性造型后缀**，格式 `角色（造型）`（`林砚`、`林砚（睡衣）`、`林砚（西装）`、`林砚（受伤）`），**禁无意义编号**（不写 `林砚1`）；场景/物品不同状态同理（`客厅（夜）`、`笔记本（沾血）`）。造型括号属于 `name` 一部分，token 写作 `@[角色-林砚（睡衣）]`，与 token 后情绪括注互不冲突。
  - 某类为空则该数组为 `[]`。`机械的电子音女声` 等非角色资产声源**不进** `character`、不生成生图提示词、不加 token。
- 每项 `prompt` = 该资产「**生图提示词**」（文生图参考图）。体貌／服装／材质据剧本线索 + 合理常识补全；**这是新生成的视觉描述，不受台词零改写约束**。生产上将“身份锚点”与“单场戏剧布光”分开：角色／物品资产优先准确和中性，场景资产承载本场稳定的空间、色调和物理光线基线。这是基于“参考承载状态，文字承载变化”的工程推导，不是 Seedance 官方强制模板。模板：

  **角色**（正面头肩肖像 + 三视图）：
  > `真实摄影, 中性色彩, <角色名>, 包含角色完整的正面头肩肖像（头部及颈部完整可见，占画面左侧约三分之一）, 全身正面、侧面、背面三视图, 并排排列, <性别+年龄+身高>, <头身比／腿型／体型>, <发型+发色>, (超写实主义:1.5), 8k分辨率, <脸型+五官+瞳色>, 上身穿<上装>, 下身穿<下装+鞋>, <配饰或"无饰品">, 纯白无缝背景, (画面极其纯净:1.5), 画面只包含同一角色的身份板，不出现文字、图表、标注或水印, 大面积中性柔光, 中性低反差照明, 阴影柔和, 肤色与服装颜色准确自然`
  > 群体角色（汉子们/讨债村民）：描述群体统一外观（人数感、服装、年龄段、神态），仍套此模板。

  **场景**（无人空景 + 方位锚定）：
  > `面向<正北／正南…>, 平视, <现代写实／古装写实…>, <时间>, <主光物理来源+方向+冷暖>, <阴影与实用灯状态>, <与光线或物体互动的氛围>, 无人空景，画面只呈现场景本身，不出现人物、文字或水印, (色调统一:1.5), (光影连续性:1.5), 8k超高清, <场景规范名>, 面向<朝向>, 室内／室外, <空间结构+陈设+地域专属细节+材质，用方位词组织：画面中心／左侧／右侧／上方／远处>`

  **空间母版**（仍归 `scene`，复用当前项目引用链）：
  - 同一逻辑场跨两个以上独立 storyboard 时必须增加一项，命名严格为 `空间母版-<场景规范名>`；单个 storyboard 内含多角色反打、关键道具归属或复杂走位时也优先增加。剧情真正改变座位／区域后，先把新状态声明为独立场景资产（如 `云顶餐厅（起身后）`），再建立同名对应母版 `空间母版-云顶餐厅（起身后）`。
  - 母版不是第二张空景，而是竖屏中全景的**空间调度参考图**：锁定出入口、窗、桌椅、人物相对这些物理锚点的位置与座位、对话轴线、视线对应、关键道具归属、前中后景和主光来源／方向。只呈现一个稳定时刻，不包含动作序列、文字或分镜格。
  - 母版采用**世界坐标强锁、画面坐标弱绑定**：必须写“入口侧座位／落地窗侧对座／长桌轴线／木盒归谁／窗光从哪里来”等跨机位仍成立的关系；不得用“某角色永远固定画左／画右”定义角色身份或跨反打连续性。母版本身是一张确定构图，确有单图布局需要时可补一次当前画面的左／右，但它只描述这张参考图，不继承为后续所有镜头的固定屏幕位置。
  - 母版 `prompt` 直接使用已有项目 token 作为生图参考来源，顺序写基础空景、入画角色、关键道具，例如：
    > `竖屏9:16，真人电影写实，空间调度母版。以@[场景-云顶私人餐厅]为空间基底，@[角色-单知影]固定坐在靠入口的一侧座位，@[角色-相里凛]固定坐在靠落地窗的对座；@[物品-木盒]紧邻单知影右手，酒杯紧邻相里凛右手。中全景完整看见长桌、入口、落地窗和两人对话轴线，冷色窗光从落地窗方向进入、顶灯暖光落在桌面。单一稳定画面，不出现动作序列、分镜格、文字或水印。`
  - 项目先确认角色／空场景／关键物品图，再生成母版候选；运行时会把母版 prompt 中的 token 自动解析为生图参考图。不要在母版 prompt 重写角色五官、服装或场景完整材质清单。

  **物品**（产品实拍）：
  > `真实摄影, 产品实拍, <物品名>, <尺寸+材质+形状+关键细节>, <光泽/质感对比>, 柔和布光, 纯白背景, 画面仅包含该物品，不出现杂物、文字、标注或水印, 8k分辨率, 极致真实`

- 资产提示词只保留影响身份板、无人场景或产品实拍用途的排除条件，不追加“无模糊、无伪影、无畸变、无多手指、无变脸”等普通缺陷词清单。人物身份、姿态、服装、材质和光线优先用正向状态描述；同一排除条件不要用中英文、括号权重和同义词重复表达。
- 分镜使用母版时，`storyboard[].scene` 只引用 `空间母版-<场景规范名>`，每条镜头的场景 token 也使用该母版名；不要同时把基础空景作为视频参考图发送。角色 token继续承担身份与对白配音。母版已经明确归属的道具默认写成自然语言“母版中的木盒／酒杯”，只有物件特写需要额外形态约束时才保留 `@[物品-名称]`。
