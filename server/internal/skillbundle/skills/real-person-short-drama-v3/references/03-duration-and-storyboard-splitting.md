# 阶段 03：时长核算与分镜切分

先核算整集目标时长，再按“场 → 功能节拍 → 分镜 → 子镜头 → 台词递进”的顺序切分。

本阶段的 `c01、c02…` 与每镜秒数是**内部时长账本**，用于核算对白、动作密度和 `storyboard.duration`，不得原样写入最终模型 prompt。阶段 04 会按顺序将它们编译成 Seedance 2.0 的 `镜头1、镜头2…`；模型侧不写精确子镜头时间戳。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 四、转换流程（三层切分）

**Phase 1 · 时长核算引擎（最高优先级，先核算再输出）**

**GT 铁律：几乎每个子镜头都是 2~3s。** 4 部 GT 实测——对白镜均 **2.64s**、非对白镜均 **2.70s**，且**与动作个数无关**（3 个动作的镜也只 2.63s）。先把每条 `cNN` 锚定在 **2~3s**；只有铺垫/定场/单一缓慢长动作才到 4s，5s+ 稀有，6s+ 视为异常。**注意：子镜头的 2~3s 是物理常量，不随 `__{{DURATION_SEC}}__` 缩放**；变的只是「一个分镜里塞几个这样的 2~3s 子镜头」。

核算一条 `cNN` 时长**不是把各项相加**，而是判断"内容能否在 2~3s 内自然演完"：

| 镜型 | 时长 | 规则 |
|---|---|---|
| 对白镜 | **2~3s** | 装 ~12~15 字（GT 均 14.6 字 / 2.64s、口播 ~5 字/秒；现代剧偏少 ~11 字、古装偏多）。**动作边说边做、并行，不在对白时间外另加秒数**。称呼+短句、2~3 个逗号短分句可同镜。 |
| 动作/反应/空镜 | **2~3s** | 本镜**所有动作压进一个 2~3s 镜**、快速连续呈现，**绝不按动作个数 ×2~3s 累加**（1 个动作 2.69s、3+ 个动作 2.63s，几乎一样）。只有单一缓慢长动作（开棺、全程缓慢起跪）才 4s。 |
| 情绪留白 | **一般不单加** | 仅重大震惊/转折/答案揭晓时，单独给一个 **1~2s 静镜**；不是给每个对白镜都 +留白。 |

**硬判定（防两类膨胀）：**
- **禁按动作个数累加**：`笑容凝固 + 手一顿` 是**一个 2~3s 镜**，不是 5s。多动作快速连续呈现在同一镜内。
- **禁对白外加时间**：对白镜时长 = 对白本身口播时长（~12~15 字 / 2~3s），动作并行不另加；不得靠"加动作/加留白"把 2s 对白镜撑到 4~5s。
- **禁碎镜**：不得把一句话拆成一镜 3~5 字（GT 对白镜均 ~14 字）；称呼+短句/2~3 个逗号短分句装同镜，换角色/超 ~18 字/真停顿才换镜。
- 标注秒数取整后落 2~3s 为主；4s 上限给铺垫/长动作，6s+ 异常须拆。长台词按原文顺序逐字切段（不改写不概括），每段 ~12~15 字 / 2~3s。

**总时长闸门（同等最高优先级，与 `__{{DURATION_SEC}}__` 无关）**
- 常规单集目标 **90~135s**（整集墙钟时长，贴 GT，**不随每分镜切多长而变**）；极密集/大量闪回可到 **150s**；超 **150s** 必须回收。
- 由此推得**分镜数 ≈ 目标总时长 ÷ `__{{DURATION_SEC}}__`**（如 D=15 → 常规 6~9 个分镜；D=10 → 约 9~13 个；D=20 → 约 5~7 个）。先按此预估体量再生成，不只因台词拆短就无限加分镜。
- 回收顺序：同功能节拍短台词塞回同一 `__{{DURATION_SEC}}__`s 分镜 → 快闪/回忆压成 1~2s 蒙太奇 → 合并普通反应镜 → 减少非关键情绪留白。**不得为满足单镜核算把一集膨胀到远超「目标总时长÷`__{{DURATION_SEC}}__`」个分镜。**
- Phase 1 只约束单镜不超载，不代表每句台词都新开分镜：拆成多个短 `cNN`，但优先装进同一 `__{{DURATION_SEC}}__`s 分镜。

**语音完整性冲突规则（高于压缩）**：语音完整性高于分镜数压缩和总时长回收。回收时不得静默删除、概括、重排、视觉化替代或用异常语速挤压语音账本中的任何项目。若全部有文本语音无法在现有时长约束内自然容纳，停止生成并请求用户调整时长或剧本约束；不得牺牲语音完整性后继续输出 JSON。

**Phase 2 · 生成片段与镜头衔接账本（先规划边界，再写 cNN）**

当前项目会把每个 `storyboard` 作为一次**彼此独立**的视频生成提交，最后按数组顺序直接拼接；下一段不会自动取得上一段成片、尾帧或真实运动相位。因此：

- 一个 storyboard 只能承担**一个叙事任务**，例如“逼问升级到答案揭晓”“人物完成进门并发现异常”，不得把多个无关目的塞进一次生成。
- storyboard 边界必须落在**完成的动作、说完的意群、明确的反应或有意设计的转场**上。禁止让上一段停在半次起身、半次开门、半句台词或运动模糊中，再要求下一次独立生成从同一帧无缝继续。
- 分界前的最后一条内部 cNN 必须在动作/台词落定后留约 **0.5s 安全尾帧**；分界后的第一条内部 cNN 先给约 **0.3~0.5s 稳定入幅**再发生新动作。安全头尾包含在内部核算时长中，最终 prompt 只写“先稳定／保持半秒”，不输出具体时间轴。
- 同场相邻 storyboard 优先用**反应切、视线切、动作完成切、物件切、构图匹配切**隐藏独立生成的画面差异；跨时空用**时空转场切**。没有上一段尾帧作为输入时，不使用“无缝续接”“同一运动中途接上”等承诺。

切分后建立内部镜头衔接账本。账本先完整维护导演和画面状态，阶段 04 再为每镜编译不可省略的空间层画面基底，以及当前镜头真正必要的变化量：

1. 先锁定整集唯一**导演声部**，再给每个 storyboard 标记 `开放／升级／转折／高潮／释放`、景别趋势、运镜趋势和是否为唯一反差镜；不得每段都重新“中景推到特写”。
2. 为每个连续场景建立**场级视觉基线**：空间轴线与出入口、角色起始站位与可用动线、前中后景层级与视觉中心、主光物理来源／方向／冷暖、实用灯状态、色彩与持续氛围。同场 storyboard 的内部状态默认继承，只在剧情中出现物理触发时改变；由于各 storyboard 独立生成，每段首镜仍须把当前物理光源与画面基底编译给模型。
3. 为每个 storyboard 写一行“叙事任务”，并完成导演读解：功能、价值转变、主观归属、权力变化、潜台词。所有 cNN 都服务这一任务。
4. 为每条 cNN 写一个**可见意图**，说明观众这一镜应看见、发现或感受到什么；意图必须由画面动作承载，不写“电影感”“增强氛围”等空话。
5. 为每条 cNN 记录起幅、落幅、景别选择理由和主运镜选择理由；移动镜还要记录触发点、摄影机起点、速度、主体关系、终点与稳定锚点。若固定机位同样能完成意图，优先固定。
6. 为每条 cNN 记录主表演者的**起点—路径—终点**，以及可见主体、具体场景区域、相对入口／窗／家具／另一主体的世界位置、朝向、前后景和构图是否承担揭示、视线空间、遮挡、权力或匹配剪辑。只有当前构图或运动确实依赖时才另记画面左／右／中央。光线／氛围无剧情变化时在内部继承场基线；有变化时记录光源、物理触发和最终状态。
7. 为每个 storyboard 边界从 `B001` 连续编号，记录切点类型，以及两侧的轴线、人物世界锚点、按需画面坐标、视线、道具归属／状态、主光方向／光线相位、实用灯状态、持续氛围与环境声底。相邻两段的编号和类型必须一致。反打改变取景后，角色可能落到不同屏幕区域；只要仍在同一轴线侧、世界位置和视线关系未变，就不判为人物漂移或跳轴。
8. 先完成整集导演弧线、视觉连续和边界对账，确认镜头选择有递进且没有跳轴、人物瞬移、道具复原、动作重演、光线方向突变或环境声无故重置，再进入阶段 04。

**第 1 层 · 场 → 功能节拍 → 分镜**
- 一场是一个空间/时间单元，**不是天然只能对应一个分镜**。先在场内识别功能节拍，再按剧本顺序排成连续 storyboard 元素。
- **连续对白/连续动作段**优先压进同一个 `__{{DURATION_SEC}}__`s 分镜；但**功能不同的节拍不得为了压缩分镜数而合并**。一场可拆成多个连续分镜。
- 每个 storyboard 的 cNN 必须围绕同一个叙事任务形成“建立 → 推进 → 落点”；如果中途出现第二个独立任务，在自然切点另起 storyboard，不靠随机换景别假装节奏变化。
- **分镜时长主规则：所有分镜 `duration` 必须在 `4~__{{DURATION_SEC}}__`s。** `__{{DURATION_SEC}}__` 是优先靠近的主切割时长：连续对白/连续动作优先在同一分镜内组织到接近该时长，但不得为了凑满而拼接无关节拍、拉长动作或补无意义留白。
- 空间或时间明显切换 → 必另起分镜。
- **⚠️ 功能性独立段**（① 情绪余韵段：高潮后无台词纯视觉收尾；② 纯环境铺垫段：无台词场景建立；③ 画外音+物体空镜段：角色画外音讲解、人物不出镜；④ 单一视觉冲击段：一个震撼画面）可独立成分镜；只要在 `4~__{{DURATION_SEC}}__`s 内即可。优先靠近主切割时长，但节拍自然结束时不得强行拼接无关内容。
- **跨时空转场必须显式保留**：现实→回忆、当下→闪回、室内→室外这类切换，不能直接让对白或 VO 接管。即使并入 `__{{DURATION_SEC}}__`s 分镜，也必须在画面描述里单独写出 `过渡画面/画面模糊/溶解/拉镜/切入新时空/环境突变` 等明确转场动作。
- **分镜下限**：任何位置的分镜都不得少于 4s；若一个独立节拍不足 4s，应与相邻同场内容合并或重新切分。禁止 1/2/3s 的分镜。

**第 2 层 · 分镜 → 子镜头**
- 每个 `4~__{{DURATION_SEC}}__`s 分镜在内部拆成 `c01、c02…`，个数按**实际 `duration`**约为 `duration÷3 ~ duration÷2`；当 D=15 且分镜接近 15s 时即 GT 实测 **4~6、均 ~5**，仅极密集对白才再 +1~2 个。短分镜按实际长度配 1~5 镜，不为凑数硬填充。内部编号连续递增不跳号，**内部子镜头时长之和 = 该分镜 `duration`**；最终模型 prompt 按相同顺序输出 `镜头1、镜头2…`，不携带单镜秒数。
- **子镜头默认 2~3s**（众数 2s≈42%/3s≈41%）：对白镜多 **2~3s**，反应镜/特写 1~2s，铺垫/定场/连续动作 3~4s，长动作镜偶 5s+。**既禁默认 3s 流水，也禁把对白全压成 1~2s 碎镜**。
- **一个子镜头 = 一个画面 = 一个可见意图 = 一个主运镜 = 一个触发点 = 一个落点**。允许动作与一句短台词并行，但不得堆叠多个先后核心动作或互相冲突的运镜。移动镜默认“先稳—触发后动—落点停稳”；优先靠“分镜内加短镜”承载同功能节拍的连续对白/动作，但功能性独立段必须新开分镜。
- **镜内咬合**：除明确切到反应、物件或新时空外，`cNN` 的起幅必须承接上一条 cNN 的落幅：人物相对入口／窗／桌轴／座位的世界位置、朝向、视线、手中道具、动作完成度、主光来源／相位和实用灯状态不能重置。画面左／右是当前机位的投影，只有同机位续拍、构图匹配或连续横向运动时才需要承接；反打不机械继承。改变轴线时先给中性正面／全景建立镜，禁止直接越过 180° 轴线。
- **对白节奏（统一硬约束，逐条 `cNN` 执行）：**
  - **一镜一人一段话**：同一 `cNN` 只许一位角色一段短台词；A 说完 B 答必须拆连续两镜，禁止同镜写两人对白。声音统一 `@[角色-名称]（情绪）：“台词”`（中文引号）。
  - **装满不赶字（按 GT 颗粒度，别过切）**：按 `对白字数 ÷ 4.5` 核算。一个对白镜**应装满 ~10~12 字、约 2~4s**（53% 的 GT 对白镜 ≥10 字、26% ≥14 字）。**一个镜可含「称呼+短句」或 2~3 个逗号短分句**，只要同一角色、一口气说完、≤约 18 字——参考 GT：`从现在起，跟在我后面，听我命令。`（3 分句/3s）、`上头派我来这儿干什么？喝西北风吗？`（2 问句/3s）、`师傅，这探测仪读数全乱套了。`（称呼+句/3s）。**只有换角色、超 ~18 字/需换气、剧本明确停顿或转折才换镜**。不要逐逗号/逐信息点拆。
  - **按秒数分层断句**（对白/旁白/OS/VO 同规）：`1s` 极短反应词；`2s` 一个短意群（≤约 9 字）；`3s` 单句或称呼+短句或 2 个逗号短分句（≤约 13 字）；`4s` 一句或两个短分句（≤约 18 字）；`5s+` 略长单句；`6s+` 对白视为异常须拆。**每段以 。/？/！ 收尾（镜内逗号正常保留，只是不以逗号结尾拖句）**。
  - **对白镜常 2~4s**：装满 ~10~12 字；`5s+` 才优先给纯动作/过渡/空镜/无台词反应镜。
  - **托台词**：带对白子镜头必须有可见动作支撑（递物/指向/翻看/前倾/回头/停顿/看人/按压/收手后再说），不写空泛的"语气平稳""目光坚定"。
  - **先停顿再落句（仅真停顿）**：仅在确有戏剧停顿的节点（关系转场/质问升级/答案揭晓/重大震惊）才先反应镜再落句；普通连贯台词不要逐句、逐信息点拆。
  - **过载检测**：走过去/递出/翻看/摔落/握手/开门/跪下等先后发生的核心动作占时，震惊/悲伤/重大转折留停顿；皱眉/扫视/攥手/眼神/手指微动与台词并行、不累加秒数。核算超秒就拆镜，不靠快语速。

**⚠️ 切分密度（内密外简：分镜数克制，分镜内塞短镜）**
复刻真分镜结构——分镜内塞 2~3s 为主的短镜；接近 `__{{DURATION_SEC}}__`s 的分镜约为 **`__{{DURATION_SEC}}__`÷2.8 个**（GT 在 15s 下极少超 7），而非膨胀分镜数或把对白压成碎镜。同一场连续对白的短镜优先在同一分镜中组织到接近 `__{{DURATION_SEC}}__`s，再按自然节拍换下一个。
- **分镜数对齐体量**：分镜数 ≈ 目标总时长 ÷ `__{{DURATION_SEC}}__`（常规 90~135s / 长场闪回动作密集可 150s）；不得把普通长对白集拆成远超该数的分镜。
- **两类错误自检**：欠切分（整集压成寥寥几镜/明显偏短）→ 查是否误删功能性独立段、`__{{DURATION_SEC}}__`s 分镜镜头是否太少（<`__{{DURATION_SEC}}__`÷4）；过切分（分镜数远超场次/时长翻倍）→ 查是否把本该同分镜的连续对白拆成多个分镜，应合并。
- **动作/少台词节拍别一带而过**（盲跑偏短主因）：追逐/打斗/搜寻/环境揭示/情绪停留等无台词或少台词段，GT 常给足时长——多个 3~4s 动作镜 + 反应镜 + 环境/空镜铺陈，而不是压成 1~2 个镜。

**第 3 层 · 台词 → 多镜递进**
- 剧本里一段长台词，按语义切成短句，分配到**连续多个子镜头**，每镜一短句，配合表情/景别递进（近景→特写→大特写）。
- 两人对话必须用"说话人镜头 → 听者反应/回答镜头"的节奏展开：A 的长句可拆成 A1/A2 两镜，B 的回应另起一镜。不要在一个子镜头里连续写 `A：“...” B：“...”`。

**真分镜对白节奏蒸馏（拆镜不是按字数，而是按可演节拍）**
- 第09集父女质问拆法：先给"苏振邦站定审视"的无对白镜，再把质问拆成"半个月就回"一镜、"怎么不打电话"一镜，苏晚晴低声回应另起特写镜——核心是 **审视→前半句压力→后半句追问→女儿反应** 四个节拍，而非字数。
- 第09集堂屋汇报拆法：供货能力、山货数量、旧渠道压价、统一质检、收入翻倍各成镜——长说明按 **一个信息点一个镜头** 推进。
- 同角色长句拆镜也要景别递进：中景/过肩交代关系 → 近景/特写承接关键信息 → 听者反应/回应。
- 判断口诀：**一人一口气，一镜一反应；换人必换镜，长句按信息点断句。**（完整范例见后文示例 C 苏振邦父女长对白）
