# 阶段 08：输入输出示例

本文件展示最终送入当前项目和 Seedance 2.0 的提示词格式。内部仍先完成 cNN 时长账本、导演意图、起落幅、人物动线、场级构图／光线／氛围基线和边界编号；这些分析不全量进入最终 JSON，但每条模型镜头必须保留空间层最小画面基底，不能只剩动作。

## 示例 1 · 两个独立生成片段的反应切

输入节拍：林砚拆信读到坏消息，抬眼看向门口；门口的母亲看出异常并追问。两个 storyboard 分别生成，所以在完成视线后切母亲反应，不要求两个片段共享真实尾帧。

```json
{
  "character": [
    {"name":"林砚","prompt":"角色生图提示词"},
    {"name":"林母","prompt":"角色生图提示词"}
  ],
  "scene": [
    {"name":"旧宅","prompt":"场景生图提示词"},
    {"name":"空间母版-旧宅","prompt":"竖屏9:16，真人电影写实，空间调度母版。以@[场景-旧宅]为空间基底，@[角色-林砚]固定坐在靠窗的木桌一端，@[角色-林母]固定站在连接走廊的门口，@[物品-信封]留在林砚手边；中全景完整看见木桌、门口、两人视线轴线和桌边台灯暖光。单一稳定画面，不出现动作序列、分镜格、文字或水印。"}
  ],
  "item": [{"name":"信封","prompt":"物品生图提示词"}],
  "storyboard": [
    {
      "name":"林砚拆信发现异常",
      "duration":6,
      "prompt":"真人电影风格,画面不要出现任何文字，生成视频无BGM；\n镜头1：中景，平视，固定机位。画面中@[角色-林砚]坐在@[场景-空间母版-旧宅]靠窗的木桌一端，@[物品-信封]位于前景，通往走廊的门口留在后景负空间；母版中的座位、门口和桌边台灯暖光保持固定。他拆开信封，信纸完全展开后手指停在落款旁。纸张摩擦声，无配乐。\n镜头2：近景，平视，滑轨缓慢推镜至特写。画面中@[角色-林砚]仍在@[场景-空间母版-旧宅]靠窗的桌端，半开的信纸占前景，通往走廊的门框留在后景。先稳定他低头读信的近景；当他读到落款时开始推近；停稳在他抬眼看向门口前的脸部特写，门框仍留在后景并保持半秒，结尾供反应切。低环境声，无配乐。【不出现任何文字字幕】",
      "character":["林砚"],
      "scene":["空间母版-旧宅"],
      "item":["信封"]
    },
    {
      "name":"林母察觉异常追问",
      "duration":6,
      "prompt":"真人电影风格,画面不要出现任何文字，生成视频无BGM；\n镜头1：近景，过肩，固定机位。开头承接反应切，先稳定门口构图。画面中@[角色-林母]站在@[场景-空间母版-旧宅]连接走廊的门口并朝向室内木桌，门框占前景，林砚所在的靠窗桌端虚化在后景；母版中的门口、木桌和两人视线轴线保持固定。她看到桌边异常后轻轻收紧扶门框的手。低环境声，无配乐。\n镜头2：近景，平视，固定机位。画面中@[角色-林母]仍位于@[场景-空间母版-旧宅]门口，视线越过前景门框投向靠窗木桌，身后走廊保持虚暗。她没有进门，只压低声音追问。@[角色-林母]（压低声音）：“信里写了什么？”说完维持视线，门框仍留在前景并保持半秒。低环境声，无配乐。【背景虚焦，不出现任何文字字幕】",
      "character":["林母"],
      "scene":["空间母版-旧宅"],
      "item":[]
    }

```

导演层对账：内部 `B001-反应切` 两侧一致；模型层只出现“结尾供反应切／开头承接反应切”。前段已完成抬眼，后段切不同主体与构图，因此独立生成后仍有剪辑因果。每镜都写出旧宅中实际被镜头选中的区域和构图关系；参考资产承载人物身份与旧宅完整陈设，不替代这些镜级画面选择。

## 示例 2 · 光线只在发生剧情变化时写

场级基线：夜间室内，桌边台灯是稳定暖主光，门外连接冷白走廊。这些世界状态由场景资产和内部账本承载，画面左／右由当前机位决定。

- 门未开时的普通反应镜：`镜头1：近景，平视，固定机位。画面中@[角色-林砚]位于@[场景-旧宅]靠窗的木桌一端，信纸占前景，通往走廊的门框位于后景；桌边台灯暖光落在他的脸和手上。他停下拆信，抬眼看向门口。纸张摩擦声停止，无配乐。` 不写“高级氛围、电影布光”等空词。
- 门打开的变化镜：`镜头2：近景，平视，固定机位。画面中@[角色-林砚]的脸和持信双手占据@[场景-旧宅]桌边近景，门框虚影留在后景。他保持看向门口；门打开时，走廊冷白光从门口切入屋内，他的手停在信纸上并保持半秒。门轴轻响，无配乐。【不出现任何文字字幕】` 只写光源、物理触发和可见结果。

这个示例不意味着“每个 storyboard 都要有光线变化”；没有剧情变化时，继承场级基线才是更稳定的做法。

## 示例 3 · 负面提示词只编译为必要的局部约束

普通缺陷词清单不是稳定性保险，先把风险改写成模型能看到的正向状态：

| 不推荐 | 推荐 |
|---|---|
| `负面提示词：不要模糊、不要变形、不要多手指、不要变脸` | `@[角色-林砚]双手始终握住@[物品-信封]边缘，信封形状完整；身份、发型和灰色外套保持一致。` |
| `不要抖动、不要闪烁` | `固定机位，构图和桌边台灯曝光保持稳定。` |

只有时间顺序无法用普通状态锁完整表达时才保留短排除句：

- 前段已经完成拆信，后段从结果开始：`已完成的拆信动作不重复，本镜从信纸展开状态开始。`
- 追赶属于下一片段：`本段止于抬眼，后续追赶暂不出现。`

约束接在动作结果之后、声音之前；每镜最多一条，并与构图、光线、氛围、焦点等视觉变化量共享稀疏预算。固定风格首行和 JSON schema 不变，不新增 `negativePrompt` 字段。

## 示例 A · 无台词情绪余韵

```json
{"name":"隧道余韵","duration":6,"prompt":"真人电影风格,画面不要出现任何文字，生成视频无BGM；\n镜头1：全景，平视，固定机位。画面中@[场景-秦岭隧道]从积水前景向黑暗深处延伸，@[物品-矿灯]落在前景积水边，冷白光束斜扫侧后方湿石壁，隧道深处保持幽暗。水滴落入前景积水，矿灯光束晃过石壁后停住。水滴声，无配乐。\n镜头2：中景，侧面，滑轨缓慢推镜至特写。画面中@[角色-徐毅]站在@[场景-秦岭隧道]中层靠近湿石壁，@[物品-手电筒]贴近胸前，后景石壁反出微弱冷光。先稳定人物中景；当他攥紧手电筒时开始推近；停稳在发抖指尖的特写并保持半秒。人物不再追赶，呼吸声压低，无配乐。【背景虚焦，不出现任何文字字幕】","character":["徐毅"],"scene":["秦岭隧道"],"item":["矿灯","手电筒"]}
```

这里的推镜不是“增加动感”，而是由攥紧动作触发，并以发抖指尖这一新信息为终点。

## 示例 B · 画外音与物件镜头

```json
{"name":"石壁纹样解读","duration":6,"prompt":"真人电影风格,画面不要出现任何文字，生成视频无BGM；\n镜头1：特写，侧面，平稳横移。画面中@[场景-秦岭隧道]石壁裂缝占据前景，刻痕沿湿石壁横向延伸，冷白矿灯光从侧后方擦过湿润表面。先稳定裂缝特写；当水珠滑入刻痕时沿刻痕延伸方向横移；停稳在一组重复纹样上。@[角色-徐开来]（画外音）：“这些符号不是装饰。”水滴声，无配乐。\n镜头2：特写，平视，轨道缓慢拉镜至中景。画面中重复纹样位于@[场景-秦岭隧道]石壁中心区域，前景水珠保持清晰，周围更多刻痕隐入后景暗部。先稳定纹样特写；当画外音说到记录方式时开始拉远；停稳在整面纹样连成一片的中景并保持半秒。@[角色-徐开来]（画外音）：“是古人记录磁场异常的方式。”无配乐。【不出现任何文字字幕】","character":["徐开来"],"scene":["秦岭隧道"],"item":[]}
```

横移保持特写景别，只改变画面所见区域；拉镜才承担从局部到整体的信息扩展。

## 示例 C · 长对白的景别递进

同一角色的长句按完整意群拆镜，但不重复推近：先用过肩中景建立人物关系，再用固定近景承载质问，最后切听者固定特写承接反应。内部每镜仍有意图、起幅和落幅；模型 prompt 写成 `镜头N：景别，机位，运镜。画面中主体、具体场景区域与构图关系。动作结果。声音。`。

## 综合示例 D · 有文本语音全量保留

源剧本中的声音先按顺序记入内部语音账本 `A001~A005`，编号不写入最终 JSON。模型层格式为：

- 角色对白：`@[角色-林砚]（冷声）：“别让任何人进来。”`
- 内心独白：`@[角色-林砚](内心OS)：“我必须撑到天亮。”`
- 具名 VO：`@[角色-林砚](VO)：“那天之后，我再也没回过这里。”`
- 匿名旁白：`旁白（画外音）：“午夜十二点，整栋楼陷入黑暗。”`
- 系统音：`机械的电子音女声：“警告，生命体征异常。”`

每项声音按原顺序放进承担对应信息的 `镜头N`。`【音效】` 和环境声不进入语音账本；环境声仍需在同场 storyboard 边界两侧保持一致。

## 不同剧本格式的归一化对照

| 维度 | 标准场次 | 第一人称 OV | Markdown 场次 | 统一处理 |
|---|---|---|---|---|
| 场景头 | `1-1 日 外 地点` | `诊室，日，内` | `### 日外 山中` | 识别为一场，再切功能节拍和独立生成片段 |
| 叙述 | `△动作` | `OV：我…` | `△动作` | 动作可视化；OV 原文同时保留为声音 |
| 对白 | `角色（情绪）：` | 同左 | 同左 | 说话人 token + 中文引号，正文零改写 |
| 心理 | `OS` | OV 心理句 | 情绪括注 | 具名 OS 用角色 token；匿名 OV 保留旁白 |
| 特殊 | 系统音 | —— | 快闪 | 系统声不建资产；快闪仍须内部镜头契约 |
