# 阶段 02：资产提取

从归一化剧本中提取并去重角色、场景、物品，统一命名、分类、造型状态，并编写资产生图提示词。

> 本 skill 内置规则。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 三、顶层 `character` / `scene` / `item`（整集去重资产 + 生图提示词）

- **覆盖整集去重**：列出本集出现的**所有**角色/场景/物品。`name` 用**规范名**（纯名，不带 `@`、不带类型前缀），与 prompt 里 `@[类型-名称]` 名称严格一致。
- **分类硬规则**：
  - **动物（母云豹/云豹幼崽/金雕/狗…）归 `item`**，即使有动作/会移动，也只进 `item`、写 `@[物品-母云豹]`，绝不进 `character`。归在物品的条目不得出现在角色，反之亦然。
  - 同一角色不同造型分别成项，用**括号包裹的描述性造型后缀**，格式 `角色（造型）`（`林砚`、`林砚（睡衣）`、`林砚（西装）`、`林砚（受伤）`），**禁无意义编号**（不写 `林砚1`）；场景/物品不同状态同理（`客厅（夜）`、`笔记本（沾血）`）。造型括号属于 `name` 一部分，token 写作 `@[角色-林砚（睡衣）]`，与 token 后情绪括注互不冲突。
  - 某类为空则该数组为 `[]`。`机械的电子音女声` 等非角色资产声源**不进** `character`、不生成生图提示词、不加 token。
- 每项 `prompt` = 该资产「**生图提示词**」（文生图参考图）。体貌/服装/材质据剧本线索 + 合理常识补全；**这是新生成的视觉描述，不受台词零改写约束**。模板：

  **角色**（正面头肩肖像 + 三视图）：
  > `3D 国漫风格，高精度虚幻五 CG 渲染，官方角色设定展示板，保留人体基础结构逻辑，全脸精致美化，流畅柔和面部轮廓，硬朗骨骼棱角，五官立体精致对称，身材比例优化修长，体态挺拔舒展，发型规整柔顺富有层次，服饰细节清晰质感高级，柔和全局漫射光，干净柔和软阴影，色调干净高级，PBR 物理材质，8K超高清，超高精细建模，电影级光影，极致细节精致妆容, <角色名>, 包含角色完整的正面头肩肖像（头部及颈部完整可见，占画面左侧约三分之一）, 全身正面、侧面、背面三视图, 并排排列, <性别+年龄+身高>, <头身比/腿型/体型>, <发型+发色>, <脸型+五官+瞳色>, 上身穿<上装>, 下身穿<下装+鞋>, <配饰或"无饰品">, 纯白无缝背景, (画面极其纯净:1.5), (无文字:2.0), 无水印, 无图表, 无标注`
  > 群体角色（汉子们/讨债村民）：描述群体统一外观（人数感、服装、年龄段、神态），仍套此模板。

  **场景**（无人空景）：
  > `3D 国漫风格，高精度虚幻五 CG 渲染，柔和全局漫射光，干净柔和软阴影，色调干净高级，PBR 物理材质，8K 超高清，超高精细建模，电影级光影，极致细节，电影级生活流、超写实，禁止出现人物, <时间+光线或整体色调>, <氛围>, (no people:2.0), (uninhabited:2.0), empty scene, <场景规范名>, <场景主体与空间结构>, <地面、中心锚点、左右陈设、材质、光影、背景和远景等关键细节>`
  > 按上述顺序写成一条逗号分隔的提示词。场景名使用规范名，不附加朝向；正文从整体空间写到中心锚点、地面、周边陈设、光影和远景。

  **物品**（道具渲染图）：
  > `三维动漫风格, 道具渲染图, <物品名>, <材质、结构或形状>, <颜色>, <表面纹理与光泽>, <磨损痕迹、加工细节或自然生长形态>, 柔和布光, 纯白背景, 无杂物, (无文字:2.0), 无水印, 8k分辨率, 极致真实`
  > 按物品实际特征取舍描述项，不为缺失信息硬凑字段；重点写出能稳定识别该道具的材质、颜色、轮廓、纹理、光泽和使用痕迹或自然形态。
