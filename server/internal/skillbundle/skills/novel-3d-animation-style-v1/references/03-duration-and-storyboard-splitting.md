# 阶段 03：时长核算与分镜切分

先根据完整语音账本核算整集自然时长，再按“场 → 功能节拍 → 分镜 → 子镜头 → 台词递进”的顺序切分。

> 本 skill 内置 1.8x 加速规则；`__{{DURATION_SEC}}__` 保持为调用时参数。

### 四、转换流程（三层切分）

**Phase 1 · 时长核算引擎（最高优先级，先核算再输出）**

**铁律：几乎每个子镜头都是 1~2s。** 对白镜以 **1.5s** 为众数、非对白镜以 **1.5s** 为众数，且**与动作个数无关**。先把每条 `cNN` 锚定在 **1~2s**（0.5 步进）；只有铺垫/定场/单一缓慢长动作才到 2s，2.5~3s 稀有，3.5s+ 视为异常。**注意：子镜头的 1~2s 是物理常量，不随 `__{{DURATION_SEC}}__` 缩放**；变的只是「一个分镜里塞几个这样的 1~2s 子镜头」。

核算一条 `cNN` 时长**不是把各项相加**，而是判断"内容能否在 1~2s 内自然演完"：

| 镜型 | 时长 | 规则 |
|---|---|---|
| 对白镜 | **1~2s** | 装 ~12~15 字（口播 ~8.1 字/秒）。**动作边说边做、并行，不在对白时间外另加秒数**。称呼+短句、2~3 个逗号短分句可同镜。 |
| 动作/反应/空镜 | **1~2s** | 本镜**所有动作压进一个 1~2s 镜**、快速连续呈现，**绝不按动作个数 ×1~2s 累加**。只有单一缓慢长动作（开棺、全程缓慢起跪）才 2s。 |
| 情绪留白 | **一般不单加** | 仅重大震惊/转折/答案揭晓时，单独给一个 **0.5~1s 静镜**；不是给每个对白镜都 +留白。 |

**硬判定（防两类膨胀）：**
- **禁按动作个数累加**：`笑容凝固 + 手一顿` 是**一个 1~2s 镜**，不是 3s。多动作快速连续呈现在同一镜内。
- **禁对白外加时间**：对白镜时长 = 对白本身口播时长（~12~15 字 / 1~2s），动作并行不另加；不得靠"加动作/加留白"把 1s 对白镜撑到 2~2.5s。
- **禁碎镜**：不得把一句话拆成一镜 3~5 字（GT 对白镜均 ~14 字）；称呼+短句/2~3 个逗号短分句装同镜，换角色/超 ~18 字/真停顿才换镜。
- 标注秒数按 0.5 步进取值后落 1~2s 为主；2s 上限给铺垫/长动作，3.5s+ 异常须拆。长台词按原文顺序逐字切段（不改写不概括），每段 ~12~15 字 / 1~2s。

**整集自然时长规则（同等最高优先级）**
- 总时长由完整语音账本和必要动作镜头自然决定，不设固定上下限；`__{{DURATION_SEC}}__` 只控制单个 storyboard 的主切割时长，不代表整集总时长。
- 分镜数由完整内容自然决定：按剧本顺序持续增加 storyboard，直到语音账本和必要视觉节拍全部覆盖。正文再长也不得只抽开头、转折、结尾等主线句，更不得只生成一个 `__{{DURATION_SEC}}__` 时长的分镜。
- Phase 1 只约束单个 cNN 和单个 storyboard 不超载，不限制整集 storyboard 数量。连续同功能短台词仍应优先装进同一 `__{{DURATION_SEC}}__`s 分镜，避免无意义碎分镜。

**语音完整性规则（高于紧凑度）**：不得为缩短总时长删减、概括、重排、视觉化替代或用异常语速挤压语音账本中的任何项目，也不得静默删除任何账本项。单个分镜无法自然容纳时，按原顺序继续拆到后续 cNN 和 storyboard；不得牺牲语音完整性后继续输出 JSON。

**第 1 层 · 场 → 功能节拍 → 分镜**
- 一场是一个空间/时间单元，**不是天然只能对应一个分镜**。先在场内识别功能节拍，再按剧本顺序排成连续 storyboard 元素。
- **连续对白/连续动作段**优先压进同一个 `__{{DURATION_SEC}}__`s 分镜；但**功能不同的节拍不得为了压缩分镜数而合并**。一场可拆成多个连续分镜。
- **分镜时长主规则：所有分镜 `duration` 必须在 `4~__{{DURATION_SEC}}__`s。** `__{{DURATION_SEC}}__` 是优先靠近的主切割时长：连续对白/连续动作优先在同一分镜内组织到接近该时长，但不得为了凑满而拼接无关节拍、拉长动作或补无意义留白。
- 空间或时间明显切换 → 必另起分镜。
- **⚠️ 功能性独立段**（① 情绪余韵段：高潮后无台词纯视觉收尾；② 纯环境铺垫段：无台词场景建立；③ 画外音+物体空镜段：角色画外音讲解、人物不出镜；④ 单一视觉冲击段：一个震撼画面）可独立成分镜；只要在 `4~__{{DURATION_SEC}}__`s 内即可。优先靠近主切割时长，但节拍自然结束时不得强行拼接无关内容。
- **跨时空转场必须显式保留**：现实→回忆、当下→闪回、室内→室外这类切换，不能直接让对白或 VO 接管。即使并入 `__{{DURATION_SEC}}__`s 分镜，也必须在画面描述里单独写出 `过渡画面/画面模糊/溶解/拉镜/切入新时空/环境突变` 等明确转场动作。
- **分镜下限**：任何位置的分镜都不得少于 4s；若一个独立节拍不足 4s，应与相邻同场内容合并或重新切分。禁止 1/2/3s 的分镜。

**第 2 层 · 分镜 → 子镜头**
- 每个 `4~__{{DURATION_SEC}}__`s 分镜拆成 `c01、c02…`，个数按**实际 `duration`**约为 `duration÷1.7 ~ duration÷1.4`；当 D=15 且分镜接近 15s 时为 **9~11、均 ~10**，仅极密集对白才再 +2~3 个。短分镜按实际长度配镜，不为凑数硬填充。编号连续递增不跳号，**子镜头时长之和 = 该分镜 `duration`**。不要把单分镜塞到远超其 `duration÷1.4` 个镜。
- **子镜头默认 1~2s**（众数 1.5s≈45%/1s≈30%/2s≈20%）：对白镜多 **1~2s**，反应镜/特写 0.5~1s，铺垫/定场/连续动作 1.5~2s，长动作镜偶 2.5~3s。**既禁默认 1.5s 流水，也禁把对白全压成 0.5s 碎镜**。
- **一个子镜头 = 一个画面 = 一个动作或一句短台词**；优先靠"分镜内加短镜"承载同功能节拍的连续对白/动作，但功能性独立段必须新开分镜。
- **对白节奏（统一硬约束，逐条 `cNN` 执行）：**
  - **一镜一人一段话**：同一 `cNN` 只许一位角色一段短台词；A 说完 B 答必须拆连续两镜，禁止同镜写两人对白。声音统一 `@[角色-名称]（情绪）：“台词”`（中文引号）。
  - **装满不赶字**：按 `对白字数 ÷ 8.1` 核算。一个对白镜**应装满 ~10~12 字、约 1~2s**。**一个镜可含「称呼+短句」或 2~3 个逗号短分句**，只要同一角色、一口气说完、≤约 18 字。**只有换角色、超 ~18 字/需换气、剧本明确停顿或转折才换镜**。不要逐逗号/逐信息点拆。
  - **按秒数分层断句**（对白/旁白/OS/VO 同规；**字数上限不变，秒数 ÷1.8**）：`0.5s` 极短反应词；`1s` 一个短意群（≤约 9 字）；`1.5s` 单句或称呼+短句或 2 个逗号短分句（≤约 13 字）；`2s` 一句或两个短分句（≤约 18 字）；`2.5~3s` 略长单句；`3.5s+` 对白视为异常须拆。**每段以 。/？/！ 收尾（镜内逗号正常保留）**。
  - **对白镜常 1~2s**：装满 ~10~12 字；`2.5s+` 才优先给纯动作/过渡/空镜/无台词反应镜。
  - **托台词**：带对白子镜头必须有可见动作支撑（递物/指向/翻看/前倾/回头/停顿/看人/按压/收手后再说），不写空泛的"语气平稳""目光坚定"。
  - **先停顿再落句（仅真停顿）**：仅在确有戏剧停顿的节点（关系转场/质问升级/答案揭晓/重大震惊）才先反应镜再落句；普通连贯台词不要逐句、逐信息点拆。
  - **过载检测**：走过去/递出/翻看/摔落/握手/开门/跪下等先后发生的核心动作占时，震惊/悲伤/重大转折留停顿；皱眉/扫视/攥手/眼神/手指微动与台词并行、不累加秒数。核算超秒就拆镜，不靠快语速。

**⚠️ 切分密度（内密外简：分镜数克制，分镜内塞短镜）**
复刻真分镜结构——分镜内塞 1~2s 为主的短镜；接近 `__{{DURATION_SEC}}__`s 的分镜约为 **`__{{DURATION_SEC}}__`÷1.55 个**（15s 下极少超 12），而非膨胀分镜数或把对白压成碎镜。同一场连续对白的短镜优先在同一分镜中组织到接近 `__{{DURATION_SEC}}__`s，再按自然节拍换下一个。
- **分镜数对齐完整内容**：分镜数以完整覆盖语音账本和必要视觉节拍为准；不得预设整集分镜数量，也不得因正文较长而删减语音。
- **两类错误自检**：欠切分（整集压成寥寥几镜/明显偏短）→ 查是否误删功能性独立段、接近 `__{{DURATION_SEC}}__`s 的分镜镜头是否太少（<`__{{DURATION_SEC}}__`÷2.2）；过切分（分镜数远超场次/时长翻倍）→ 查是否把本该同分镜的连续对白拆成多个分镜，应合并。
- **动作/少台词节拍别一带而过**（盲跑偏短主因）：追逐/打斗/搜寻/环境揭示/情绪停留等无台词或少台词段，仍需给足镜头数——多个 1.5~2s 动作镜 + 反应镜 + 环境/空镜铺陈，而不是压成 1 个镜。

**第 3 层 · 台词 → 多镜递进**
- 剧本里一段长台词，按语义切成短句，分配到**连续多个子镜头**，每镜一短句，配合表情/景别递进（近景→特写→大特写）。
- 两人对话必须用"说话人镜头 → 听者反应/回答镜头"的节奏展开：A 的长句可拆成 A1/A2 两镜，B 的回应另起一镜。不要在一个子镜头里连续写 `A：“...” B：“...”`。

**真分镜对白节奏蒸馏（拆镜不是按字数，而是按可演节拍）**
- 第09集父女质问拆法：先给"苏振邦站定审视"的无对白镜，再把质问拆成"半个月就回"一镜、"怎么不打电话"一镜，苏晚晴低声回应另起特写镜——核心是 **审视→前半句压力→后半句追问→女儿反应** 四个节拍，而非字数。
- 第09集堂屋汇报拆法：供货能力、山货数量、旧渠道压价、统一质检、收入翻倍各成镜——长说明按 **一个信息点一个镜头** 推进。
- 同角色长句拆镜也要景别递进：中景/过肩交代关系 → 近景/特写承接关键信息 → 听者反应/回应。
- 判断口诀：**一人一口气，一镜一反应；换人必换镜，长句按信息点断句。**（完整范例见后文示例 C 苏振邦父女长对白）
