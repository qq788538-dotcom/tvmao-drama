# 阶段 04：镜头编写与导演控制

按照统一 cNN 语法编写每个子镜头，并使用空间、姿态、景别、机位、运镜和导演细节形成可拍画面。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 五、子镜头行语法（逐字段）

`cNN,Ns,(空间:位置)(姿态:@[角色-名称]-动作) 景别，机位角度，运镜方式。画面描述。@[角色-名称]（情绪）：“台词”。【标签】`

1. **空间**：比剧本地点更细的具体位置；**其中场景/物品名带 token，方位词纯文本**——`(空间:@[场景-老宅]桌前)`、`(空间:@[物品-手机]屏幕)`、`(空间:@[场景-土坯房]门口)`。**空间锚定**：同一分镜内优先保持同一主空间，只在同院门/屋檐/墙根/崖边/门内外这类连续动线里微调；只有真跨门槛、转入另一间屋、上下崖才改写。
2. **姿态**：本镜每个出场实体的 `@[类型-名称]-动作`，多个用逗号；**动作里若提到物品或其他角色，也一并 token 化**（用声明同名）——`@[角色-徐毅]-放下@[物品-黑色笔记本]拿@[物品-手机]`、`@[角色-婶子]-举@[物品-木柴]砸门`；动物按物品类 `@[物品-母云豹]-扑咬`；无人物镜写 `(姿态:无人物)`。纯动词（跪下/前倾/回头）保持纯文本。
3. **景别**：远景／全景／中全景／中远景／中景／近景／特写／大特写／过肩镜头（按情绪强度推近）。
4. **机位角度**：平视／俯视／仰拍／低角度／侧面／正面／过肩／主观视角。
5. **运镜方式**：静止／固定／横移跟拍／推镜／缓慢拉开／下降运镜／手持横移／逆光剪影 等。
6. **画面描述**：把 `△/▲/OV` 扩写成可视细节——表情（眉头/瞳孔/嘴角/喉结/青筋/泪光）、肢体（攥拳/前倾/后仰/撑地/叉腰）、光影（冷色调/逆光/背景虚焦/薄雾/日光灯）、环境氛围（山风/灰尘/积雪/嘈杂人群，把【音效】融进来）。**描述里出现的角色/物品名都写成 `@[类型-名称]`**；场景名只在头部与空间承载，描述里作背景的环境词（石壁/山林/雪地）与方位/动作/形容/氛围词保持纯文本。

### 5.5 导演细节（拉开"成品感"的关键，务必执行）

1. **一句台词 = 一个专属肢体微动作**：每个带台词的子镜头配一个**具体且与相邻镜头不同**的小动作；**严禁连续复用同一套描述**——"喉结滚动""眉头紧锁""正面角度，静止镜头"不可反复，每镜换新细节/新道具特写。
2. **情绪高点必上特写/大特写 + 情绪化运镜注释**：震惊/崩溃/决心/阴谋得逞等关键点用特写或大特写，运镜后补**导演意图**（"镜头缓慢下压，营造压抑感"等）。不要全程平铺近景/中景。
3. **景别主动跳动**：一个分镜内制造景别落差（远景→特写、中景→大特写），用景别变化承载情绪起伏。
4. **具体化而非概括**："鬼鬼祟祟张望""哭丧"等笼统动作落成**具体姿态**，人物不停留在"模糊人影"。
5. **反套路配额（每集严控）**：
   - 下列"标配情绪词"全集**每词各 ≤ 2 次**：`喉结滚动` `眉头紧锁` `瞳孔收缩` `牙关紧咬` `青筋暴起`；超出时换具体的新动作（"食指贴住鼻尖""拇指扣住腰带""眼皮下意识垂下""舌尖轻舔下唇"…）。
   - `急推镜，强化XX感` 句式全集 **≤ 4 次**，同一"强化XX感"措辞 ≤ 2 次；大量运镜时改用具体镜语（"镜头缓慢下压""低角度仰拍停格""荷兰角切入"…）。
   - 同一肢体动作描述（含"静止镜头""正面角度"等）**不得在同一分镜内出现超过 1 次**。
6. **特殊手法清单（有明确剧情信号才用，按剧情自然选 0~2 种，不为凑配额强塞，避免"四件套"固化；单集总数 ≤8）**：
   - **荷兰角**：精神崩溃/认知失控/噩耗来临，≤2 次。
   - **直视镜头（破第四堵墙）**：揭露核心真相/情绪极端爆发，标注"角色直视镜头"，**不作普通反应镜**，≤1 次。
   - **交叉剪辑/平行蒙太奇**：双线同步推进，描述里标 `↔ 交叉`，≤2 次。
   - **逆光剪影出场**：新角色强势登场/重要人物压迫性回归（"逆光剪影，缓慢推进"），≤2 次。
   - **物体主体空镜**：关键道具（合同/药盒/照片/欠条…）作转折锚点，0.5~1s 特写空镜，≤3 次。
   - **留白静止镜**：高潮节拍后 0.5~1s 无台词沉默镜，≤2 次。
   - **手持跟拍/俯视下降/环绕运镜**：动作密集段优先，替代固定艺术手法。
