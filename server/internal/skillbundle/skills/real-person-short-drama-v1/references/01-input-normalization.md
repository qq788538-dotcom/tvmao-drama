# 阶段 01：输入归一化

在开始资产提取前，先识别并统一全剧设定、单集正文、场景头、动作、对白、OS、OV、系统音与快闪等输入标记。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 一、输入（自动兼容多种剧本格式）

你会收到（可能合并在一起）：**全剧设定（可选）+ 单集剧本正文**。剧本「场（scene）」头可能是任意写法，都要识别为一场：`1-1 日 外 青峦岭半山腰土坯房外` ／ `11-1 清水村 日/内` ／ `诊室，日，内` ／ `### 日外 山中`（markdown 三级标题）。正文常见标记：

| 剧本标记 | 含义 | 处理 |
|---|---|---|
| `△` / `▲` | 动作/画面提示 | 扩写成具体子镜头画面 |
| `人物：…` | 本场出场角色 | 计入顶层 `character` 与本分镜 `character`，并出现在「姿态」 |
| `【音效】：…` | 环境声 | 融进画面氛围描写（不单列、不进入语音账本） |
| `角色（情绪/语气）：台词` | 对白 | 写成 `@[角色-名称]（情绪/语气）：“台词”`，保留括号内原文 |
| `角色OS：…` / `（内心）` | 内心独白 | 写成 `@[角色-名称](内心OS)：“…”` |
| `OV：…` / `▲+OV：…` | 匿名旁白/画外叙述 | 原文保留为 `旁白（画外音）：“…”`；可同步视觉化，但画面不得替代声音 |
| `【叮！系统提示…】` | 系统/电子音 | 写成 `机械的电子音女声：“…”`，数字改中文 |
| `【快闪1】…` | 快切蒙太奇 | 拆成 0.5~1s 的快切子镜头 |

### 语音账本（必须先于资产与分镜）

按原剧本顺序提取每个连续发声单元并编号 `A001、A002…`。每项记录类型、说话人、原始情绪括注和原始正文。账本只用于内部推理和最终对账，不写入 JSON。

必须进入语音账本：

- 角色对白；
- OS／内心独白；
- 具名 VO；
- 匿名 OV／旁白；
- 具名或匿名画外音；
- 系统／电子语音；
- 广播、电话、录音等带明确台词文本的声音。

不进入语音账本：`【音效】`、环境声、脚步声、敲门声、风声等无台词声音。它们仍可融入画面氛围，但不参与语音对账。

不得在归一化阶段删除、概括或视觉化替代账本中的任何文本。长语音可在后续拆成连续多个 `cNN`，但必须保留原顺序和完整正文。
