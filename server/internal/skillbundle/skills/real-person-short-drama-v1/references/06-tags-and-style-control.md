# 阶段 06：标签与风格控制

应用背景虚焦、无文字字幕、固定风格串、无 BGM、节奏量化和特殊手法配额。

> 来源：项目根目录 `prompt.md`。`__{{DURATION_SEC}}__` 保持为调用时参数。

### 七、收尾标签（实测频率已校准）

1. `【背景虚焦】`：**主要由「景别」决定，不是每镜都挂**。GT 全量（9177 子镜头，整体 58%）按景别分档判每条 `cNN`：

   | 景别 | GT 带【背景虚焦】 | 口径 |
   |---|---|---|
   | 远景/全景/中全景/中远景/定场/空镜 | ~**17%** | **一般不加** |
   | 中景 | ~**41%** | **约一半**才加 |
   | 过肩镜头 | ~**48%** | 约一半 |
   | 近景 | ~**87%** | **基本都加** |
   | 特写/大特写 | ~**76%** | **多数加**（纯物体/环境空镜特写可不加） |

   - **全集整体 55~60%**；做成 80~95% 即过标须回收。
   - **末镜不因末镜必加背景虚焦**（GT 末镜也仅 ~57%）；末镜必带的是 `【不出现任何文字字幕】`，背景虚焦仍按景别判。
   - **双向回检**：连续多个近景/特写没挂→多半漏了补；远景/全景/定场/空镜/无人物镜挂了→多半多余删。场景情绪只 ±5~10% 微调，景别才是主依据。
2. `【不出现任何文字字幕】`：**每个分镜最后一个子镜头必加**；对白镜也常加，整体约 **30% 子镜头**带此标签。
3. 二者常合并：`【背景虚焦，不出现任何文字字幕】`；标准文本 `不出现任何文字字幕`（不写"画面"二字）。
4. 全程贯彻：**画面零文字、零字幕、无 BGM**。

### 八、节奏量化盘（实测 10963 个子镜头，秒数已 ÷1.8）

| 指标 | 取值 | 说明 |
|---|---|---|
| 分镜时长 | **`4~__{{DURATION_SEC}}__`s，优先接近 `__{{DURATION_SEC}}__`s** | 不为凑满而拼接无关节拍；不足 4s 时与相邻同场内容合并或重切 |
| 子镜头/分镜 | **≈ `duration`÷1.7 ~ `duration`÷1.4**（D=15 且分镜接近 15s 时为 9~11、均 ~10） | 极密集才再 +2~3；短分镜按实际长度配镜 |
| 子镜头时长 | **1.5s≈45%、1s≈30%、2s≈20%**、0.5s≈3%、2.5~3s≈2% | 以 1~2s 为主，禁均匀（**不随 `__{{DURATION_SEC}}__` 变**） |
| 台词密度 | **约 (`__{{DURATION_SEC}}__`÷1.7) 个对白镜 / 分镜，每镜 ~10~12 字 / 1~2s** | 口播 ~8.1 字/秒；别切成 3~5 字碎镜 |
| 无文字标签 | 约 **30%** 子镜头 | 末镜必带 + 对白镜常带 |
