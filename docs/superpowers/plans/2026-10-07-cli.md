# 桌面端命令行（CLI）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户和 AI 助手在终端里用 `miaoju` 命令操作本机正在运行的喵剧桌面端的自由画布；CLI 改动画布后，已打开的画布在空闲时自动刷新。

**Architecture:** 壳每次启动 sidecar 时多生成一个 CLI token（stdin 第 2 行），sidecar 就绪后壳把端口和 CLI token 写进默认数据目录的 `cli-endpoint.json`。sidecar 照搬参考仓的 `cliapi` 与 `cli_*.go`，挂在 `/api/v1/cli/*`，由 `localauth` 只放行 CLI token。CLI 二进制照搬参考仓 `apps/cli`，删掉登录、升级、远程地址，改为读地址文件。CLI 的画布写入经事件中心推 SSE，前端空闲时整拉快照。

**Tech Stack:** Go 1.26（chi、cobra）、Rust（Tauri v2、tokio）、React + zustand + antd + vitest。

**Spec:** `docs/superpowers/specs/2026-10-07-cli-design.md`

**调研依据**（参考仓前缀 `R=/Users/james/github/huabu_studio`）：
- 后端：`R/apps/api/internal/cliapi/`、`R/apps/api/internal/http/cli_*.go`、`R/apps/api/internal/http/router.go:265-313`、`R/apps/api/cmd/server/main.go:573-587`。桌面端 `server/go.mod` 的 module 名与参考仓相同（`github.com/james/huabu_studio/apps/api`），`cliapi` 用到的 `projects`、`canvasstate`、`canvasinputs`、`canvasgen`、`generation`、`models`、`library`、`assets` 符号签名两边逐一核对过，完全一致。
- CLI：`R/apps/cli/`（module `github.com/james/huabu_studio/apps/cli`，cobra）。

## Global Constraints

- **命令名**：用户安装后在终端里敲 `miaoju`。安装包内的文件名是 `miaoju-cli`（Windows 为 `miaoju-cli.exe`），因为 `tauri.conf.json` 的 `mainBinaryName` 已经是 `miaoju`，同名会覆盖主程序。
- **地址文件**：文件名 `cli-endpoint.json`，放在壳的 `default_data_dir()`（即 `app.path().app_data_dir()`）。
  - macOS：`~/Library/Application Support/com.miaoju.desktop/cli-endpoint.json`
  - Windows：`%APPDATA%\com.miaoju.desktop\cli-endpoint.json`
  - 内容固定为 `{"version":1,"port":<u16>,"token":"<hex>","appVersion":"<x.y.z>"}`。
  - 原子写入（先写 `cli-endpoint.json.tmp`，再改名）；unix 下文件权限 0600。
- **CLI 路由**：前缀 `/api/v1/cli/`。
  - 只认 `Authorization: Bearer <CLIToken>`，不认 `?token=`。
  - 带 `Origin` 头的请求一律 403。
  - 网页 token 和媒体 token 访问这组路由一律 401；CLI token 访问其他路由也一律 401。
- **ping**：`GET /api/v1/cli/ping`，返回 `{"app":"miaoju-desktop","version":"<sidecar 版本>"}`。
- **退出码**：`AppNotRunning = 8`、`SandboxBlocked = 9`。原有的 0、2–7 不变。提示文案固定为以下两句，不得改字：
  - `喵剧未运行，请先打开应用`
  - `网络被 AI 助手的沙箱拦截，请允许本命令访问网络后重试`
- **外部变更事件**：`GET /api/v1/projects/{projectID}/events`，SSE，用网页 token（走 `?token=`）。每条消息格式为 `data: {"projectId":N,"version":N,"source":"cli"}\n\n`。只有 CLI 的画布写入才发事件。
- **Go module**：
  - `server/` 沿用 `github.com/james/huabu_studio/apps/api`，从参考仓复制的文件 import 一律不改。
  - `cli/` 沿用 `github.com/james/huabu_studio/apps/cli`（照搬，不改名）。
- `go get` 和 `go mod tidy` 必须带 `GOPROXY=https://goproxy.cn,direct`。
- 命令在哪个目录执行：
  - Go：`server/` 或 `cli/` 下
  - 前端：`web/` 下
  - Rust：`src-tauri/` 下
- 用户可见文案和注释用中文，风格与周边代码一致。

## Review Focus

1. **sidecar 崩溃自动重启后，端口和 token 都变了**：地址文件必须随之重写；CLI 手里拿的是旧值时，收到 401 要重读一次文件再试。
   - Task 3：`ready_hook_fires_on_start_restart_and_crash_restart`
   - Task 10：`TestUnauthorizedRereadsEndpointOnce`
2. **CLI 事件到达时用户正在拖拽，或者本地 mutation 还在途**：必须推迟刷新；如果拉快照期间本地又发出了写入，这次拉到的结果要丢掉，等空闲后重新拉。
   - Task 7：`defers reload while pointer is down`、`discards a reload that raced a local mutation`
3. **外部刷新后用户按撤销**：撤销不能删掉 CLI 新建的节点，所以刷新时要清空 undo/redo 栈。
   - Task 7：`clears undo history and dangling ui ids on external reload`
4. **用户迁移数据目录**：迁移时不能复制 `cli-endpoint.json`，清理时也不能删它。
   - Task 3：`TestIgnorableIncludesCLIEndpoint`
5. **应用退出时还有 SSE 长连接**：sidecar 必须立即结束这些连接，不能每次退出都等满 2.5 秒的 shutdownTimeout。
   - Task 6：`TestProjectEventsEndsOnHubClose`

```go
func readToken(r *bufio.Reader, label string) (string, error) {
	line, err := r.ReadSlice('\n')
	if errors.Is(err, bufio.ErrBufferFull) {
		return "", fmt.Errorf("%s 长度超过 %d", label, maxTokenLen)
	}
	token := strings.TrimSpace(string(line))
	if token == "" && err != nil {
		return "", fmt.Errorf("读取 %s: %w", label, err)
	}
	if len(token) < 32 {
		return "", fmt.Errorf("%s 长度不足 32", label)
	}
	if len(token) > maxTokenLen {
		return "", fmt.Errorf("%s 长度超过 %d", label, maxTokenLen)
	}
	return token, nil
}
```

```rust
#[tokio::test]
async fn ready_hook_fires_on_start_restart_and_crash_restart() {
    // 第 1 次启动后立刻崩溃 → 自动重启（4002）；之后手动 restart（4003）。
    let crash_after_ready = r#"read t; read c; echo "READY 4001"; exit 1"#;
    let f = scripted(vec![crash_after_ready, SERVE_4002, SERVE_4003]);
    let m = SidecarManager::new(f, recorder().0, fast());
    let seen: Arc<Mutex<Vec<ServerInfo>>> = Arc::default();
    let s = seen.clone();
    m.set_ready_hook(Arc::new(move |i: &ServerInfo| s.lock().unwrap().push(i.clone())));

    m.start().await.unwrap();
    // 等崩溃自动重启就绪
    let info = loop {
        let i = m.wait_info().await.unwrap();
        if i.port == 4002 { break i; }
        tokio::time::sleep(Duration::from_millis(20)).await;
    };
    assert_eq!(info.port, 4002);
    m.restart().await.unwrap();

    let seen = seen.lock().unwrap();
```

```rust
#[derive(serde::Serialize)]
#[serde(rename_all = "camelCase")]
struct EndpointFile<'a> {
    version: u32,
    port: u16,
    token: &'a str,
    app_version: &'a str,
}

/// 原子写入：tmp（unix 下 0600）→ fsync → 改名 → fsync 目录。与 datadir::write_durable 同一顺序，
/// 但必须在创建时就设 0600，不能先按 umask 建好再 chmod（中间会有一段时间别人可读）。
pub fn write(dir: &Path, info: &ServerInfo, app_version: &str) -> io::Result<()> {
    use std::io::Write;
    let body = serde_json::to_vec(&EndpointFile {
        version: 1,
        port: info.port,
        token: &info.cli_token,
        app_version,
    })
    .map_err(io::Error::other)?;
    let path = dir.join(FILE_NAME);
    let tmp = dir.join(format!("{FILE_NAME}.tmp"));
    let mut opts = std::fs::OpenOptions::new();
    opts.write(true).create(true).truncate(true);
    #[cfg(unix)]
    {
        use std::os::unix::fs::OpenOptionsExt;
        opts.mode(0o600);
    }
    let mut f = opts.open(&tmp)?;
    f.write_all(&body)?;
    f.sync_all()?;
    drop(f);
    std::fs::rename(&tmp, &path)?;
    #[cfg(not(windows))]
    std::fs::File::open(dir)?.sync_all()?;
    Ok(())
}

/// 应用退出时删除。文件不存在不算错（幂等）。
pub fn remove(dir: &Path) {
    let _ = std::fs::remove_file(dir.join(FILE_NAME));
}
```

如果上一次写入崩溃时留下了 0644 的 tmp 文件，`OpenOptions::mode` 不会改变已存在文件的权限。所以在 `opts.open` 之前先执行 `let _ = std::fs::remove_file(&tmp);`。

```go
package cliapi

import "encoding/json"

// ChangeNotifier 接收 CLI 的画布写入事件（CLI spec 第 6 节），由 sidecar 的事件中心实现。
// 只有 CLI 写入才发：生成回写、Agent、网页自己的写入走各自已有的链路，不经过这里。
type ChangeNotifier interface {
	Publish(projectID, version int64, source string)
}

// SourceCLI 是事件里的 source 字段值。
const SourceCLI = "cli"

type notifyingStore struct {
	ProjectStore
	n ChangeNotifier
}

// WithChangeNotifier 包一层 ProjectStore：MutateSnapshot 提交成功且确有改动时发事件。
// 包在存储层而不是逐个写方法里调用，新增写操作时不会漏发。
func WithChangeNotifier(s ProjectStore, n ChangeNotifier) ProjectStore {
	if n == nil {
		return s
	}
	return notifyingStore{ProjectStore: s, n: n}
}

func (s notifyingStore) MutateSnapshot(projectID int64, fn func(payload json.RawMessage) (json.RawMessage, bool, error)) (int64, error) {
	changed := false
	v, err := s.ProjectStore.MutateSnapshot(projectID, func(p json.RawMessage) (json.RawMessage, bool, error) {
		out, ch, err := fn(p)
		changed = ch && err == nil
		return out, ch, err
	})
	if err == nil && changed && v > 0 {
		s.n.Publish(projectID, v, SourceCLI)
	}
	return v, err
}
```

```go
// Package events 是 sidecar 进程内的项目变更事件中心（CLI spec 第 6 节）：CLI 写画布后发布，
// 网页经 SSE 订阅，空闲时整拉快照。只保证"尽力送达"：订阅者缓冲满了直接丢，前端每次
// （重）连上都会比较一次版本号，丢掉的事件靠这一步补回来。
package events

import "sync"

type Event struct {
	ProjectID int64  `json:"projectId"`
	Version   int64  `json:"version"`
	Source    string `json:"source"`
}

const bufferSize = 16

type Hub struct {
	mu     sync.Mutex
	subs   map[int64]map[chan Event]struct{}
	closed bool
	done   chan struct{}
}

func NewHub() *Hub {
	return &Hub{subs: map[int64]map[chan Event]struct{}{}, done: make(chan struct{})}
}

func (h *Hub) Publish(projectID, version int64, source string) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.closed {
		return
	}
	e := Event{ProjectID: projectID, Version: version, Source: source}
	for ch := range h.subs[projectID] {
		select {
		case ch <- e:
		default: // 慢订阅者：丢弃，不阻塞 CLI 的写请求
		}
	}
}

// Subscribe 返回事件 channel 和退订函数（幂等）。Hub 已关闭时返回一个已关闭的 channel。
func (h *Hub) Subscribe(projectID int64) (<-chan Event, func()) {
	ch := make(chan Event, bufferSize)
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.closed {
		close(ch)
		return ch, func() {}
	}
	if h.subs[projectID] == nil {
		h.subs[projectID] = map[chan Event]struct{}{}
	}
	h.subs[projectID][ch] = struct{}{}
	var once sync.Once
	return ch, func() {
		once.Do(func() {
			h.mu.Lock()
			defer h.mu.Unlock()
			if _, ok := h.subs[projectID][ch]; ok {
				delete(h.subs[projectID], ch)
				close(ch)
			}
		})
	}
}

// Close 关闭全部订阅并让 Done 可读。sidecar 退出时调用：srv.Shutdown 不会取消在途请求的 ctx，
// SSE handler 靠 Done 及时返回，否则每次退出都要等满 shutdownTimeout。
func (h *Hub) Close() {
	h.mu.Lock()
	defer h.mu.Unlock()
	if h.closed {
		return
	}
	h.closed = true
	for _, set := range h.subs {
		for ch := range set {
			close(ch)
		}
	}
	h.subs = nil
	close(h.done)
}

func (h *Hub) Done() <-chan struct{} { return h.done }
```

```go
package http

import (
	"encoding/json"
	"fmt"
	nethttp "net/http"
	"time"

	"github.com/james/huabu_studio/apps/api/internal/events"
)

const sseHeartbeat = 25 * time.Second

// ProjectEvents 是 GET /api/v1/projects/{projectID}/events：推送 CLI 对该项目画布的写入（CLI spec 第 6 节）。
// EventSource 带不了请求头，token 走 ?token=（localauth 已支持）。
func ProjectEvents(hub *events.Hub) nethttp.HandlerFunc {
	return func(w nethttp.ResponseWriter, r *nethttp.Request) {
		fl, ok := w.(nethttp.Flusher)
		if !ok {
			writeError(w, nethttp.StatusInternalServerError, "streaming unsupported")
			return
		}
		ch, cancel := hub.Subscribe(projectIDFromContext(r.Context()))
		defer cancel()

		h := w.Header()
		h.Set("Content-Type", "text/event-stream")
		h.Set("Cache-Control", "no-cache")
		h.Set("Connection", "keep-alive")
		w.WriteHeader(nethttp.StatusOK)
		_, _ = fmt.Fprint(w, ": ok\n\n")
		fl.Flush()

		tick := time.NewTicker(sseHeartbeat)
		defer tick.Stop()
		for {
			select {
			case <-r.Context().Done():
				return
			case <-hub.Done():
				return
			case <-tick.C:
				if _, err := fmt.Fprint(w, ": ping\n\n"); err != nil {
					return
				}
				fl.Flush()
			case e, ok := <-ch:
				if !ok {
					return
				}
				b, _ := json.Marshal(e)
				if _, err := fmt.Fprintf(w, "data: %s\n\n", b); err != nil {
					return
				}
				fl.Flush()
			}
		}
	}
}
```

```ts
// 外部（CLI）变更的整拉（CLI spec 第 6 节）：只在画布空闲时把服务端快照换进 store，
// 保留视口与选中，清空撤销栈（否则撤销会删掉外部新增的节点）。
import { getSnapshot } from '@/shared/api';
import { useCanvasStore } from '../store';
import type { CanvasSnapshot } from '../types';
import { canvasMutationSeq, isCanvasPersistenceIdle, seedCanvasBaselines } from './canvasMutations';

let pointerDown = false;

/** 全局跟踪"有按键按着"：节点拖动、缩放、平移、框选、连线都是 mousedown 后挂 window 监听的自研手势，统一用它判断。 */
export function installPointerTracker(win: Window = window): () => void {
  const down = () => { pointerDown = true; };
  const up = () => { pointerDown = false; };
  win.addEventListener('pointerdown', down, true);
  win.addEventListener('pointerup', up, true);
  win.addEventListener('pointercancel', up, true);
  win.addEventListener('blur', up);
  return () => {
    win.removeEventListener('pointerdown', down, true);
    win.removeEventListener('pointerup', up, true);
    win.removeEventListener('pointercancel', up, true);
    win.removeEventListener('blur', up);
    pointerDown = false;
  };
}

/** 与 CanvasEditor 快捷键里的判定一致：输入框、下拉、contenteditable（提示词编辑器）。 */
export function isEditingText(el: Element | null): boolean {
  if (!el) return false;
  const tag = el.tagName;
  return tag === 'INPUT' || tag === 'TEXTAREA' || tag === 'SELECT' || (el as HTMLElement).isContentEditable === true;
}

export function isCanvasIdle(doc: Document = document): boolean {
  if (pointerDown) return false;
  if (isEditingText(doc.activeElement)) return false;
  if (useCanvasStore.getState().connecting) return false;
  return isCanvasPersistenceIdle();
}

/** 拉快照并换进 store，返回快照版本；拉取期间本地有新写入则丢弃结果并返回 null（调用方等空闲后重来）。 */
export async function reloadCanvasFromServer(pid: number): Promise<number | null> {
  const seq = canvasMutationSeq();
  const snap = await getSnapshot(pid);
  if (canvasMutationSeq() !== seq || !isCanvasPersistenceIdle()) return null;
  const raw = (snap.payload ?? {}) as Partial<CanvasSnapshot>;
  const nodes = raw.nodes ?? [];
  const s = useCanvasStore.getState();
  s.load({ nodes, connections: raw.connections ?? [], view: s.view }, { preserveUiState: true, resetHistory: true });
  // 基线必须对齐服务端，否则下一次 diff 会把旧值当成本地改动重发
  seedCanvasBaselines(nodes);
  return snap.version;
}
```

```ts
// 订阅 CLI 对当前项目画布的写入（CLI spec 第 6 节）。收到更新的版本后，等画布空闲再整拉；
// 断线自动重连（原生 EventSource 收到非 200 会直接放弃重试，所以手动重连），重连成功后比较一次版本补漏。
import { useEffect, useRef } from 'react';
import { getSnapshot } from '@/shared/api';
import { buildEventSourceUrl } from '@/shared/server';
import { currentSidecarSession } from '@/shared/sidecarSession';
import { installPointerTracker, isCanvasIdle, reloadCanvasFromServer } from '../persistence/externalChanges';

const IDLE_RETRY_MS = 500;
const MAX_BACKOFF_MS = 30_000;

interface ExternalChangeEvent {
  projectId: number;
  version: number;
  source: string;
}

export function useExternalChanges(opts: {
  projectId: number;
  enabled: boolean;
  initialVersion: number;
  onReloaded?: (version: number) => void;
}): void {
  const { projectId, enabled, initialVersion } = opts;
  const onReloadedRef = useRef(opts.onReloaded);
  onReloadedRef.current = opts.onReloaded;

  useEffect(() => {
    if (!enabled) return;
    let disposed = false;
    let loaded = initialVersion; // 最近一次整拉（或首次加载）的快照版本
    let wanted = 0; // 已知需要追上的最高版本
    let es: EventSource | null = null;
    let opened = false;
    let retry = 0;
    let reloading = false;
    let idleTimer: ReturnType<typeof setTimeout> | undefined;
    let retryTimer: ReturnType<typeof setTimeout> | undefined;
    const removeTracker = installPointerTracker();

    const schedule = (ms = IDLE_RETRY_MS) => {
      clearTimeout(idleTimer);
      idleTimer = setTimeout(() => void tryReload(), ms);
    };

    const tryReload = async () => {
      if (disposed || reloading || wanted <= loaded) return;
      if (!isCanvasIdle()) {
        schedule();
        return;
      }
      reloading = true;
      let v: number | null = null;
      try {
        v = await reloadCanvasFromServer(projectId);
      } catch {
        v = null;
      } finally {
        reloading = false;
      }
      if (disposed) return;
      if (v === null) {
        schedule();
        return;
      }
      loaded = Math.max(loaded, v);
      onReloadedRef.current?.(v);
      if (wanted > loaded) schedule();
    };

    const want = (version: number) => {
      if (version <= loaded) return;
      wanted = Math.max(wanted, version);
      void tryReload();
    };

    // 用户松手或输入框失焦时立刻再试一次，不用干等定时器
    const onSettled = () => {
      if (wanted > loaded) schedule(0);
    };
    window.addEventListener('pointerup', onSettled);
    document.addEventListener('focusout', onSettled);

    const reconnect = () => {
      if (disposed) return;
      const delay = Math.min(1000 * 2 ** retry, MAX_BACKOFF_MS);
      retry += 1;
      retryTimer = setTimeout(() => void connect(), delay);
    };

    const connect = async () => {
      const info = await currentSidecarSession();
      if (disposed) return;
      if (!info) {
        reconnect();
        return;
      }
      const src = new EventSource(buildEventSourceUrl(info, `/api/v1/projects/${projectId}/events`));
      es = src;
      src.onopen = () => {
        retry = 0;
        if (opened) {
          // 断线期间的事件收不到了：比较一次版本补上
          getSnapshot(projectId)
            .then((s) => !disposed && want(s.version))
            .catch(() => {});
        }
        opened = true;
      };
      src.onmessage = (m) => {
        let e: ExternalChangeEvent;
        try {
          e = JSON.parse(m.data) as ExternalChangeEvent;
        } catch {
          return;
        }
        if (e.source !== 'cli' || e.projectId !== projectId) return;
        want(e.version);
      };
      src.onerror = () => {
        src.close();
        if (es === src) es = null;
        reconnect();
      };
    };
    void connect();

    return () => {
      disposed = true;
      es?.close();
      clearTimeout(idleTimer);
      clearTimeout(retryTimer);
      window.removeEventListener('pointerup', onSettled);
      document.removeEventListener('focusout', onSettled);
      removeTracker();
    };
  }, [projectId, enabled, initialVersion]);
}
```

```go
package endpoint

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"runtime"
)

const FileName = "cli-endpoint.json"

// appDirName 与 tauri.conf.json 的 identifier 一致（壳用 app_data_dir()）。
const appDirName = "com.miaoju.desktop"

// ErrNotRunning：地址文件不存在，应用没开（或已正常退出）。
var ErrNotRunning = errors.New("喵剧未运行")

type Info struct {
	Version    int    `json:"version"`
	Port       int    `json:"port"`
	Token      string `json:"token"`
	AppVersion string `json:"appVersion"`
}

func (i Info) BaseURL() string { return fmt.Sprintf("http://127.0.0.1:%d", i.Port) }

func DefaultDir() (string, error) { return defaultDir(runtime.GOOS, os.UserHomeDir, os.Getenv) }

func defaultDir(goos string, home func() (string, error), getenv func(string) string) (string, error) {
	switch goos {
	case "darwin":
		h, err := home()
		if err != nil {
			return "", fmt.Errorf("无法确定用户主目录: %w", err)
		}
		return filepath.Join(h, "Library", "Application Support", appDirName), nil
	case "windows":
		a := getenv("APPDATA")
		if a == "" {
			return "", errors.New("未找到 APPDATA 环境变量")
		}
		return filepath.Join(a, appDirName), nil
	default:
		return "", fmt.Errorf("喵剧桌面端只支持 macOS 与 Windows（当前 %s）", goos)
	}
}

func Load(dir string) (Info, error) {
	b, err := os.ReadFile(filepath.Join(dir, FileName))
	if errors.Is(err, fs.ErrNotExist) {
		return Info{}, ErrNotRunning
	}
	if err != nil {
		return Info{}, fmt.Errorf("读取地址文件: %w", err)
	}
	var i Info
	if err := json.Unmarshal(b, &i); err != nil {
		return Info{}, fmt.Errorf("地址文件格式错误: %w", err)
	}
	if i.Version != 1 {
		return Info{}, fmt.Errorf("地址文件版本 %d 不受支持，请在喵剧 设置 → 配置 → 命令行工具 中重新安装", i.Version)
	}
	if i.Port <= 0 || i.Port > 65535 || i.Token == "" {
		return Info{}, errors.New("地址文件内容不完整")
	}
	return i, nil
}
```

```go
	App     string `json:"app"`
	Version string `json:"version"`
}

// connect 读地址文件并 ping 一次，确认端口上确实是本应用。refresh=true 表示上一次的 token 被拒，重读后再试。
func (c *Client) connect(ctx context.Context, refresh bool) error {
	if c.resolve == nil {
		return &AppNotRunningError{Err: errors.New("未配置地址解析")}
	}
	info, err := c.resolve()
	if errors.Is(err, endpoint.ErrNotRunning) {
		return &AppNotRunningError{Err: err}
	}
	if err != nil {
		return err
	}
	c.server, c.token = info.BaseURL(), info.Token
	var p pingResult
	if err := c.attemptJSON(ctx, "GET", "/ping", &p); err != nil {
		var api *APIError
		if errors.As(err, &api) && api.Status == 401 {
			if !refresh {
				return c.connect(ctx, true)
			}
			return &AppNotRunningError{Err: err}
		}
		return err
	}
	if p.App != pingApp {
		return &AppNotRunningError{Err: fmt.Errorf("端口 %d 上不是喵剧（app=%q）", info.Port, p.App)}
	}
	if !c.connected && c.warn != nil && c.version != "" && c.version != "dev" &&
		info.AppVersion != "" && info.AppVersion != c.version {
		c.warn(fmt.Sprintf("命令行工具版本 %s 与喵剧 %s 不一致，请在喵剧 设置 → 配置 → 命令行工具 中重新安装", c.version, info.AppVersion))
	}
	c.connected = true
	return nil
}
```

```go
func (c *Client) do(ctx context.Context, req request, out any) error {
	if !c.connected {
		if err := c.connect(ctx, false); err != nil {
			return err
		}
	}
	err := c.doOnce(ctx, req, out)

		// 应用重启过：端口和 token 都换了，重读地址文件再试一次（不占用 maxRetries）
		if cerr := c.connect(ctx, true); cerr != nil {
			return cerr
		}
		err = c.doOnce(ctx, req, out)
```

```rust
//! 设置 → 配置 → 命令行工具（CLI spec 7.2）：把安装包里的 miaoju-cli 装成终端里的 `miaoju`。
//! macOS：~/.miaoju/bin/miaoju 符号链接到包内文件，~/.zshrc（及已存在的 ~/.bash_profile）追加带标记的 PATH 行。
//! Windows：复制到 %USERPROFILE%\.miaoju\bin\miaoju.exe（普通用户建不了符号链接），写用户级 Path。

use serde::Serialize;
use std::path::{Path, PathBuf};
use tauri::Manager;

const MARK_BEGIN: &str = "# >>> miaoju cli >>>";
const MARK_END: &str = "# <<< miaoju cli <<<";
const PATH_LINE: &str = r#"export PATH="$HOME/.miaoju/bin:$PATH""#;

#[derive(Serialize)]
#[serde(rename_all = "camelCase")]
pub struct CliToolStatus {
    installed: bool,
    up_to_date: bool,
    command_path: String,
    bin_dir: String,
    skill_entry: String,
}

pub fn add_path_block(content: &str) -> String {
    if content.contains(MARK_BEGIN) {
        return content.to_string();
    }
    let mut s = content.to_string();
    if !s.is_empty() && !s.ends_with('\n') {
        s.push('\n');
    }
    s.push_str(&format!("{MARK_BEGIN}\n{PATH_LINE}\n{MARK_END}\n"));
    s
}

pub fn remove_path_block(content: &str) -> String {
    let Some(b) = content.find(MARK_BEGIN) else { return content.to_string() };
    let Some(rel) = content[b..].find(MARK_END) else { return content.to_string() };
    let mut end = b + rel + MARK_END.len();
    if content[end..].starts_with('\n') {
        end += 1;
    }
    format!("{}{}", &content[..b], &content[end..])
}

fn same_dir(a: &str, b: &str) -> bool {
    a.trim_end_matches('\\').eq_ignore_ascii_case(b.trim_end_matches('\\'))
}

pub fn add_to_path_list(list: &str, dir: &str) -> String {
    if list.split(';').any(|p| same_dir(p, dir)) {
        return list.to_string();
    }
    if list.is_empty() { dir.to_string() } else { format!("{list};{dir}") }
}

pub fn remove_from_path_list(list: &str, dir: &str) -> String {
    list.split(';').filter(|p| !p.is_empty() && !same_dir(p, dir)).collect::<Vec<_>>().join(";")
}

pub fn version_matches(output: &str, app_version: &str) -> bool {
    !app_version.is_empty() && output.contains(app_version)
}

fn command_file() -> &'static str { if cfg!(windows) { "miaoju.exe" } else { "miaoju" } }
fn bundled_file() -> &'static str { if cfg!(windows) { "miaoju-cli.exe" } else { "miaoju-cli" } }

fn home(app: &tauri::AppHandle) -> Result<PathBuf, String> {
    app.path().home_dir().map_err(|e| format!("无法确定用户主目录：{e}"))
}

fn bin_dir(home: &Path) -> PathBuf { home.join(".miaoju").join("bin") }

fn bundled_cli() -> Result<PathBuf, String> {
    let exe = tauri::utils::platform::current_exe().map_err(|e| format!("无法定位主程序：{e}"))?;
    let p = exe.parent().ok_or("无法定位主程序所在目录")?.join(bundled_file());
    if p.exists() { Ok(p) } else { Err(format!("安装包里缺少命令行工具：{}", p.display())) }
}

fn skill_entry(app: &tauri::AppHandle) -> Result<PathBuf, String> {
    let dir = app.path().resource_dir().map_err(|e| format!("无法定位资源目录：{e}"))?;
    Ok(dir.join("cli-skill").join("SKILL.md"))
}

fn installed_output(cmd: &Path) -> Option<String> {
    let out = std::process::Command::new(cmd).arg("version").output().ok()?;
    out.status.success().then(|| String::from_utf8_lossy(&out.stdout).into_owned())
}

fn status(app: &tauri::AppHandle) -> Result<CliToolStatus, String> {
    let bin = bin_dir(&home(app)?);
    let cmd = bin.join(command_file());
    let installed = cmd.exists();
    let app_version = app.package_info().version.to_string();
    let up_to_date = installed && installed_output(&cmd).is_some_and(|o| version_matches(&o, &app_version));
    Ok(CliToolStatus {
        installed,
        up_to_date,
        command_path: cmd.display().to_string(),
        bin_dir: bin.display().to_string(),
        skill_entry: skill_entry(app)?.display().to_string(),
    })
}

#[tauri::command]
pub fn cli_tool_status(app: tauri::AppHandle) -> Result<CliToolStatus, String> {
    status(&app)
}

#[tauri::command]
pub fn install_cli_tool(app: tauri::AppHandle) -> Result<CliToolStatus, String> {
    let home = home(&app)?;
    let bin = bin_dir(&home);
    std::fs::create_dir_all(&bin).map_err(|e| format!("创建 {} 失败：{e}", bin.display()))?;
    let src = bundled_cli()?;
    let dst = bin.join(command_file());
    let _ = std::fs::remove_file(&dst);
    #[cfg(unix)]
    {
        std::os::unix::fs::symlink(&src, &dst).map_err(|e| format!("创建链接失败：{e}"))?;
        // zsh 是 macOS 默认 shell，.zshrc 不存在就新建；.bash_profile 只在已存在时追加，
        // 新建它会让 bash 跳过用户原有的 ~/.profile。
        edit_rc(&home.join(".zshrc"), true, add_path_block)?;
        edit_rc(&home.join(".bash_profile"), false, add_path_block)?;
    }
    #[cfg(windows)]
    {
        std::fs::copy(&src, &dst).map_err(|e| format!("复制命令行工具失败：{e}"))?;
        let dir = bin.display().to_string();
        win_path::update(|cur| add_to_path_list(cur, &dir))?;
    }
    status(&app)
}

#[tauri::command]
pub fn uninstall_cli_tool(app: tauri::AppHandle) -> Result<CliToolStatus, String> {
    let home = home(&app)?;
    let bin = bin_dir(&home);
    let _ = std::fs::remove_file(bin.join(command_file()));
    #[cfg(unix)]
    {
        edit_rc(&home.join(".zshrc"), false, remove_path_block)?;
        edit_rc(&home.join(".bash_profile"), false, remove_path_block)?;
    }
    #[cfg(windows)]
    {
        let dir = bin.display().to_string();
        win_path::update(|cur| remove_from_path_list(cur, &dir))?;
    }
    status(&app)
}

#[cfg(unix)]
fn edit_rc(path: &Path, create: bool, f: fn(&str) -> String) -> Result<(), String> {
    let cur = match std::fs::read_to_string(path) {
        Ok(s) => s,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            if !create {
                return Ok(());
            }
            String::new()
        }
        Err(e) => return Err(format!("读取 {} 失败：{e}", path.display())),
    };
    let next = f(&cur);
    if next != cur {
        std::fs::write(path, next).map_err(|e| format!("写入 {} 失败：{e}", path.display()))?;
    }
    Ok(())
}

#[cfg(windows)]
mod win_path {
    use winreg::{enums::*, RegKey, RegValue};

    /// 读写 HKCU\Environment\Path，保持原值类型（通常是 REG_EXPAND_SZ，里面可能有 %USERPROFILE%，
    /// 按 REG_SZ 写回会让这些变量失效），写完广播 WM_SETTINGCHANGE 让新开的终端生效。
    pub fn update(f: impl Fn(&str) -> String) -> Result<(), String> {
        let env = RegKey::predef(HKEY_CURRENT_USER)
            .open_subkey_with_flags("Environment", KEY_READ | KEY_WRITE)
            .map_err(|e| format!("打开注册表失败：{e}"))?;
        let (cur, vtype) = match env.get_raw_value("Path") {
            Ok(v) => (String::from_utf16_lossy(&utf16(&v.bytes)).trim_end_matches('\0').to_string(), v.vtype),
            Err(_) => (String::new(), REG_EXPAND_SZ),
        };
        let next = f(&cur);
        if next == cur {
            return Ok(());
        }
        let bytes: Vec<u8> = next.encode_utf16().chain(std::iter::once(0)).flat_map(|u| u.to_le_bytes()).collect();
        env.set_raw_value("Path", &RegValue { vtype, bytes })
            .map_err(|e| format!("写入注册表失败：{e}"))?;
        broadcast();
        Ok(())
    }

    fn utf16(b: &[u8]) -> Vec<u16> {
        b.chunks_exact(2).map(|c| u16::from_le_bytes([c[0], c[1]])).collect()
    }

    fn broadcast() {
        use windows::core::w;
        use windows::Win32::Foundation::{LPARAM, WPARAM};
        use windows::Win32::UI::WindowsAndMessaging::{SendMessageTimeoutW, HWND_BROADCAST, SMTO_ABORTIFHUNG, WM_SETTINGCHANGE};
        unsafe {
            let _ = SendMessageTimeoutW(HWND_BROADCAST, WM_SETTINGCHANGE, WPARAM(0),
                LPARAM(w!("Environment").as_ptr() as isize), SMTO_ABORTIFHUNG, 2000, None);
        }
    }
}
```

```tsx
import { Alert, App as AntApp, Button, Card, Descriptions, Space, Tag, Typography } from 'antd';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { cliToolStatus, errorText, installCliTool, uninstallCliTool, type CliToolStatus } from '../api';

const CODEX_CONFIG = `# ~/.codex/config.toml
sandbox_mode = "workspace-write"

[sandbox_workspace_write]
network_access = true`;

/** 设置 → 配置 → 命令行工具（CLI spec 7.2）。 */
export function CliToolCard() {
  const { message } = AntApp.useApp();
  const qc = useQueryClient();
  const q = useQuery({ queryKey: ['cli-tool-status'], queryFn: cliToolStatus });
  const onDone = (s: CliToolStatus) => qc.setQueryData(['cli-tool-status'], s);
  const install = useMutation({
    mutationFn: installCliTool,
    onSuccess: (s) => { onDone(s); message.success('已安装，重新打开终端后输入 miaoju --help'); },
    onError: (e) => message.error(errorText(e)),
  });
  const uninstall = useMutation({
    mutationFn: uninstallCliTool,
    onSuccess: (s) => { onDone(s); message.success('已卸载'); },
    onError: (e) => message.error(errorText(e)),
  });
  const s = q.data;
  const busy = install.isPending || uninstall.isPending;
  const tag = !s ? null : !s.installed ? <Tag>未安装</Tag> : s.upToDate ? <Tag color="green">已安装</Tag> : <Tag color="orange">版本不一致</Tag>;

  return (
    <Card
      title={<Space>命令行工具{tag}</Space>}
      extra={
        <Space>
          {s?.installed && <Button disabled={busy} onClick={() => uninstall.mutate()}>卸载</Button>}
          <Button type="primary" loading={install.isPending} disabled={busy || !s} onClick={() => install.mutate()}>
            {s?.installed ? '重新安装' : '安装'}
          </Button>
        </Space>
```
