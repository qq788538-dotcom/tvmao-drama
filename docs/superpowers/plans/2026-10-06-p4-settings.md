## Global Constraints

- 应用名“喵剧AI”，标识 `com.miaoju.desktop`（spec E6）。
- M10：只开放安全字段——启用/隐藏、显示名、排序、uiSchema 默认值、并发和重试，以及 settings 里的预设提示词、候选模型；请求模板、轮询模板、base_path、图片协议等技术字段只读。保存时后端校验；每个模型和每项配置提供“恢复默认”按钮。
- M8：模型和配置全部内置，用户只能修改，不能新增或删除（本计划不做模型新增/删除接口和按钮）。
- M7：客户端不提供导入导出功能。A4 / F10：不做 Skill 新建、编辑、Skill JSON 导入导出。
- A2：用户只能在内置的文本模型之间切换 Agent 使用的模型，其余参数（max_tokens、temperature、thinking 等）不可改。
- X3：积分、估价、价格说明全部删除——设置页不显示 `billingConfig`、`priceNote`；接口也不返回。X4：无登录、无账户。
- M3：API Key 存 SQLite `settings.upstream_api_key`。**任何接口响应都不得包含 Key 明文**，只返回是否已设置和掩码（`sk-` + 8 个 `•` + 末 4 位）。日志也不得打印 Key。
- S2：数据目录可在设置页修改并迁移；新路径不得含 `?`、不得以 `file:` 开头（与 `db.Open` 一致）；数据库用 `VACUUM INTO` 复制（不能只拷 `data.db`，会丢未 checkpoint 的 WAL）。
- E4：设置里显示当前版本号（应用版本 + 本地服务版本）。
- Go：沿用 P1a 约定——JSON 参数传 `string` 不传 `[]byte`；不直接绑定 `time.Time`；注释中文。本计划**不新增 Go 依赖**，不改 `server/go.mod`。
- HTTP 辅助函数一律加 `sc` 前缀（`scWriteError`、`scDecodeStrict`），避免与 P1b 移植的 `writeError` / `decodeJSON` 重名。
- 错误响应体统一 `{"error": "<中文文案>", "field": "<可选>"}`；500 不回显内部错误（P0 遗留要求），只记日志。
- 界面文案中文；前端只用 AntD 组件 + 内联 style，不引入 Tailwind（P3a 负责全局样式）。

## Review Focus

1. **API Key 明文泄露**：保存 Key 后，`GET /settings/general` 和 `PUT /settings/upstream` 的响应、前端页面都不能出现明文。（Task 2 `TestUpstreamResponsesNeverContainPlainKey`，Task 9 `GeneralPage` 组件测试）
2. **整份配置保存时丢字段**：绘图预设的 value 是自由 JSON，页面按草稿整份 PUT，若页面只回传它认识的字段，未知字段会被静默删掉。（Task 8 `updateAt` 测试、Task 12 `keeps unknown preset fields`）
3. **自定义数据目录在移动硬盘上、启动时没插** → 不能悄悄在原路径新建空库让用户以为数据丢了，必须报错。（Task 7 `missing_custom_dir_is_error`）
4. **迁移中途崩溃 / 断电** → 原数据不能丢，下次启动能重新迁移，不会卡在“目标目录不为空”。（Task 6 `TestMigrateResumesAfterPartialTarget`、`TestMigrateFailureLeavesSourceIntact`；Task 7 `next_step_*`）
5. **停用一个仍被 Agent 或画布配置引用的模型** → 应拒绝并说明被谁引用，而不是保存成功后生成时报错。（Task 3 `TestPatchRejectsDisablingReferencedModel`）

| `ModelEditService.RestoreModelDefault(ctx, id)` | `RestoreModelDefault(ctx, modelID)` | 同上换 modelID |
| `ModelEditService.ModifiedModelFields(ctx)` | `ListModels(ctx) ([]ModelState, error)`，`ModelState.Overrides` 是字段路径 | 路径映射回 `ModelPatch` 的 json 名（`ui_schema.*.default` → `uiSchemaDefaults`） |
| `SettingEditService.UpdateSetting(ctx, key, value)` | `UpdateSetting(ctx, key, edits map[string]json.RawMessage) (SettingState, error)` | P4 传整份新值；适配器按 `builtin.SettingEditableFields(key)` 的模式在新旧两份文档上展开具体路径（数组按元素的 `key` 属性寻址，如 `presets[fisheye].prompt`），只把值有变化的路径作为 edits 提交；`base_domain` 用 `{"$": <JSON 字符串>}`。不在白名单里的改动不会被提交（P2a 也不会应用），前端保存后以服务端回显为准 |
| `SettingEditService.RestoreSettingDefault(ctx, key)` | `RestoreSettingDefault(ctx, key)` | — |
| `SettingEditService.ModifiedSettings(ctx)` | `ListSettings(ctx) ([]SettingState, error)` | `len(Overrides) > 0` 的 key |
| `AgentModelService.*` | P5：`agent.BackboneRepo.List()`、`agent.BackboneModelSwitcher.SetModelName/ResetModelName`、`agentseed.DefaultBackboneModelName(id) (string, bool)` | “已修改” = 当前 model_name ≠ 内置默认值 |

错误约定：`*builtin.ValidationError{Path, Msg}` → `*SettingsValidationError`（400），`builtin.ErrNotFound`、`agent.ErrBackboneNotFound` → `ErrSettingsNotFound`（404）。

`upstream_api_key` 不经过编辑服务（P2a 对它返回 `ErrNotFound`，且其合并永远不碰这个 key），P4 直接用 `settings.Repository.Set` 写。

```go
// do 发一个请求，返回状态码和响应体文本。body 为 string 时原样发送（用于构造非法 JSON）。
func (e *scEnv) do(method, path string, body any) (int, string) {
	e.t.Helper()
	var rd *bytes.Reader
	switch b := body.(type) {
	case nil:
		rd = bytes.NewReader(nil)
	case string:
		rd = bytes.NewReader([]byte(b))
	default:
		raw, err := json.Marshal(b)
		if err != nil {
			e.t.Fatal(err)
		}
		rd = bytes.NewReader(raw)
	}
	req := httptest.NewRequest(method, "/api/v1/settings"+path, rd)
	req.Header.Set("Content-Type", "application/json")
	rec := httptest.NewRecorder()
	e.handler.ServeHTTP(rec, req)
	return rec.Code, rec.Body.String()
}

func decodeTo[T any](t *testing.T, s string) T {
	t.Helper()
	var v T
	if err := json.Unmarshal([]byte(s), &v); err != nil {
		t.Fatalf("decode %q: %v", s, err)
	}
	return v
}
```

```go
func scValidation(field, msg string) error { return &SettingsValidationError{Field: field, Message: msg} }

// parseSettingsID 解析路径参数 {id}（模型、Agent 模型共用）。
func parseSettingsID(r *nethttp.Request) (int64, error) {
	id, err := strconv.ParseInt(chi.URLParam(r, "id"), 10, 64)
	if err != nil || id <= 0 {
		return 0, scValidation("id", "无效的 id")
	}
	return id, nil
}


func scWriteError(w nethttp.ResponseWriter, err error) {
	var ve *SettingsValidationError
	switch {
	case errors.As(err, &ve):
		body := map[string]any{"error": ve.Message}
		if ve.Field != "" {
			body["field"] = ve.Field
		}
		writeJSON(w, nethttp.StatusBadRequest, body)
	case errors.Is(err, ErrSettingsNotFound), errors.Is(err, models.ErrNotFound):
		writeJSON(w, nethttp.StatusNotFound, map[string]any{"error": "要修改的项目不存在"})
	default:
		log.Printf("设置接口内部错误: %v", err)
		writeJSON(w, nethttp.StatusInternalServerError, map[string]any{"error": "保存失败，请查看日志"})
	}
}

// scDecodeStrict 解码 JSON 请求体：未知字段、多余内容、超过 2MB 一律返回 *SettingsValidationError。
func scDecodeStrict(w nethttp.ResponseWriter, r *nethttp.Request, v any) error {
	dec := json.NewDecoder(nethttp.MaxBytesReader(w, r.Body, scMaxBody))
	dec.DisallowUnknownFields()
	if err := dec.Decode(v); err != nil {
		const unknown = "json: unknown field "
		if msg := err.Error(); strings.HasPrefix(msg, unknown) {
			f := strings.Trim(strings.TrimPrefix(msg, unknown), `"`)
			return scValidation(f, "字段「"+f+"」不允许修改")
		}
		var mbe *nethttp.MaxBytesError
		if errors.As(err, &mbe) {
			return scValidation("", "请求内容过大")
		}
		return scValidation("", "请求格式不正确")
	}
	if dec.More() {
		return scValidation("", "请求格式不正确")
	}
	return nil
}
```

```go
func (h *generalSettingsHandler) putUpstream(w nethttp.ResponseWriter, r *nethttp.Request) {
	var body struct {
		BaseDomain  *string `json:"baseDomain"`
		APIKey      *string `json:"apiKey"`
		ClearAPIKey bool    `json:"clearApiKey"`
	}
	if err := scDecodeStrict(w, r, &body); err != nil {
		scWriteError(w, err)
		return
	}
	if body.BaseDomain == nil && body.APIKey == nil && !body.ClearAPIKey {
		scWriteError(w, scValidation("", "没有要修改的字段"))
		return
	}
	if body.APIKey != nil && body.ClearAPIKey {
		scWriteError(w, scValidation("apiKey", "不能同时设置和清除 API Key"))
		return
	}
	// 先全部校验，再写入：避免地址写进去了、Key 却因格式错误被拒的半成功。
	var newBase, newKey string
	var err error
	if body.BaseDomain != nil {
		if newBase, err = normalizeBaseDomain(*body.BaseDomain); err != nil {
			scWriteError(w, err)
			return
		}
	}
	if body.APIKey != nil {
		if newKey, err = normalizeAPIKey(*body.APIKey); err != nil {
			scWriteError(w, err)
			return
		}
	}
	if body.BaseDomain != nil {
		cur, err := h.d.Settings.Get(settingBaseDomain)
		if err != nil {
			scWriteError(w, err)
			return
		}
		if strings.TrimRight(cur, "/") != newBase {
			if err := h.d.SettingEdit.UpdateSetting(r.Context(), settingBaseDomain, newBase); err != nil {
				scWriteError(w, err)
				return
			}
		}
	}
	// API Key 没有内置默认值、不参与 M11 合并，直接写 settings（spec M3）。
	if body.APIKey != nil || body.ClearAPIKey {
		if err := h.d.Settings.Set(settingUpstreamAPIKey, newKey); err != nil {
			scWriteError(w, err)
			return
		}
	}

// maskAPIKey 只保留前 3 位和后 4 位；8 位及以下全部遮住。Key 明文永不出 sidecar。
func maskAPIKey(k string) string {
	if k == "" {
		return ""
	}
	r := []rune(k)
	if len(r) <= 8 {
		return strings.Repeat("•", 8)
	}
	return string(r[:3]) + strings.Repeat("•", 8) + string(r[len(r)-4:])
}

// normalizeBaseDomain 只接受 http/https 绝对地址，去掉末尾 "/"；允许路径前缀（反向代理场景）。
func normalizeBaseDomain(s string) (string, error) {
	s = strings.TrimSpace(s)
	if s == "" {
		return "", scValidation("baseDomain", "请填写上游地址")
	}
	u, err := url.Parse(s)
	if err != nil || (u.Scheme != "http" && u.Scheme != "https") || u.Host == "" {
		return "", scValidation("baseDomain", "上游地址必须是 http:// 或 https:// 开头的完整地址")
	}
	if u.User != nil || u.RawQuery != "" || u.Fragment != "" {
		return "", scValidation("baseDomain", "上游地址不能包含账号、查询参数或 #")
	}
	return u.Scheme + "://" + u.Host + strings.TrimRight(u.Path, "/"), nil
}

// normalizeAPIKey 去首尾空白；只允许可见 ASCII，最长 512。
func normalizeAPIKey(s string) (string, error) {
	s = strings.TrimSpace(s)
	if s == "" {
		return "", scValidation("apiKey", "API Key 不能为空；要删除请点「清除」")
	}
	if len(s) > 512 {
		return "", scValidation("apiKey", "API Key 过长")
	}
	for _, c := range s {
		if c <= 0x20 || c >= 0x7f {
			return "", scValidation("apiKey", "API Key 只能包含可见的英文字符，不能有空格")
		}
	}
	return s, nil
}
```

```go
		return

func intInRange(field, label string, v *int, lo, hi int) error {
	if v != nil && (*v < lo || *v > hi) {
		return scValidation(field, fmt.Sprintf("%s必须在 %d 到 %d 之间", label, lo, hi))
	}
	return nil
}

// validateModelPatch 本地校验取值范围；字段是否允许修改由严格解码和 P2a 编辑策略共同把关。
func validateModelPatch(m *models.ModelConfig, p *ModelPatch) error {
	if p.Name != nil {
		n := strings.TrimSpace(*p.Name)
		if n == "" {
			return scValidation("name", "显示名不能为空")
		}
		if utf8.RuneCountInString(n) > 64 {
			return scValidation("name", "显示名最多 64 个字")
		}
		p.Name = &n
	}
	for _, c := range []struct {
		field, label string
		v            *int
		lo, hi       int
	}{
		{"sortOrder", "排序", p.SortOrder, -1000000, 1000000},
		{"concurrency", "并发上限", p.Concurrency, 0, 200},
		{"canvasMaxRetries", "最大重试次数", p.CanvasMaxRetries, 0, 10},
		{"canvasRetryIntervalSec", "重试间隔", p.CanvasRetryIntervalSec, 0, 600},
	} {
		if err := intInRange(c.field, c.label, c.v, c.lo, c.hi); err != nil {
			return err
		}
	}
	if len(p.UISchemaDefaults) > 0 {
		return validateUISchemaDefaults(m.UISchema, p.UISchemaDefaults)
	}
	return nil
}

// validateUISchemaDefaults 要求每个默认值都等于该字段 options 中某一项的 value（按 JSON 值比较，"1" ≠ 1）。
func validateUISchemaDefaults(uiSchema json.RawMessage, defaults map[string]json.RawMessage) error {
	var schema map[string]struct {
		Options []struct {
			Value json.RawMessage `json:"value"`
		} `json:"options"`
	}
	if len(uiSchema) > 0 {
		if err := json.Unmarshal(uiSchema, &schema); err != nil {
			return scValidation("uiSchemaDefaults", "该模型的参数定义无法解析，不能修改默认值")
		}
	}
	for field, raw := range defaults {
		def, ok := schema[field]
		if !ok || len(def.Options) == 0 {
			return scValidation("uiSchemaDefaults."+field, "参数「"+field+"」不存在或没有可选项")
		}
		var want any
		if err := json.Unmarshal(raw, &want); err != nil {
			return scValidation("uiSchemaDefaults."+field, "默认值格式不正确")
		}
		matched := false
		for _, o := range def.Options {
			var got any
			if json.Unmarshal(o.Value, &got) == nil && reflect.DeepEqual(got, want) {
				matched = true
				break
			}
		}
		if !matched {
			return scValidation("uiSchemaDefaults."+field, "参数「"+field+"」的默认值必须是可选项之一")
		}
	}
	return nil
}
```

```go
		return configView{}, err
	}
	mods, err := h.d.SettingEdit.ModifiedSettings(r.Context())
	if err != nil {
		return configView{}, err
	}
	v := configView{Key: key, Value: json.RawMessage("null")}
	if strings.TrimSpace(raw) != "" {
		v.Value = json.RawMessage(raw)
	}
	for _, m := range mods {
		if m == key {
			v.Modified = true
		}
	}
	return v, nil

func (h *configSettingsHandler) put(w nethttp.ResponseWriter, r *nethttp.Request) {
	key, ok := configKeyFrom(r)
	if !ok {
		scWriteError(w, ErrSettingsNotFound)
		return
	}
	var body struct {
		Value json.RawMessage `json:"value"`
	}
	if err := scDecodeStrict(w, r, &body); err != nil {
		scWriteError(w, err)
		return
	}
	trimmed := bytes.TrimSpace(body.Value)
	if len(trimmed) == 0 || trimmed[0] != '{' {
		scWriteError(w, scValidation("value", "配置必须是 JSON 对象"))
		return
	}
	var compact bytes.Buffer
	if err := json.Compact(&compact, trimmed); err != nil {

		return

		return
	}

		scWriteError(w, err)
		return
	}
	h.writeView(w, r, key)
}

var modelTypeLabels = map[string]string{"image": "图片", "video": "视频", "text": "文本", "audio": "音频"}

// validateConfigValue 校验一项画布配置里结构不变时仍可能出错的取值。
func validateConfigValue(key string, raw []byte, lookup func(string) (*models.ModelConfig, error)) error {
	var v map[string]any
	if err := json.Unmarshal(raw, &v); err != nil {
		return scValidation("value", "配置不是合法的 JSON")
	}
	// models 数组里的空字符串 extractModelRefs 会跳过，单独拦下（参考仓同样拒绝空模型 ID）。
	if arr, ok := v["models"].([]any); ok {
		for i, m := range arr {
			if s, _ := m.(string); strings.TrimSpace(s) == "" {
				return scValidation(fmt.Sprintf("models[%d]", i), "模型不能为空")
			}
		}
	}
	refs, err := extractModelRefs(key, raw)
	if err != nil {
		return scValidation("value", "配置不是合法的 JSON")
	}
	for _, ref := range refs {
		m, err := lookup(ref.ModelID)
		if errors.Is(err, models.ErrNotFound) {
			return scValidation(ref.Path, "模型「"+ref.ModelID+"」不存在")
		}
		if err != nil {
			return err
		}
		if m.Type != ref.WantType {
			return scValidation(ref.Path, fmt.Sprintf("「%s」不是%s模型", m.Name, modelTypeLabels[ref.WantType]))
		}
		if !m.Enabled {
			return scValidation(ref.Path, "模型「"+m.Name+"」已停用，请先在模型中心启用")
		}
	}
	switch key {
	case "gen_image_prompt_presets":
		presets, _ := v["presets"].([]any)
		for i, p := range presets {
			obj, _ := p.(map[string]any)
			val, _ := obj["value"].(map[string]any)
			name, _ := val["name"].(string)
			if prompt, _ := val["prompt"].(string); strings.TrimSpace(prompt) == "" {
				return scValidation(fmt.Sprintf("presets[%d].value.prompt", i), "预设「"+name+"」的提示词不能为空")
			}
		}
	case "canvas_multi_angle":
		return checkTemplate(v, "{angle}")
	case "canvas_light_control":
		return checkTemplate(v, "{light}")
	case "canvas_script_config":
		if err := checkNumber(v, "concurrency", "并发数", 1, 20); err != nil {
			return err
		}
		return checkNumber(v, "maxRetries", "失败重试次数", 0, 10)
	}
	return nil
}

func checkTemplate(v map[string]any, placeholder string) error {
	t, _ := v["template"].(string)
	if strings.TrimSpace(t) != "" && !strings.Contains(t, placeholder) {
		return scValidation("template", "拼接模板必须保留 "+placeholder+"（留空则使用内置模板）")
	}
	return nil
}

func checkNumber(v map[string]any, field, label string, lo, hi float64) error {
	raw, ok := v[field]
	if !ok {
		return nil
	}
	n, isNum := raw.(float64)
	if !isNum || n != float64(int(n)) || n < lo || n > hi {
		return scValidation(field, fmt.Sprintf("%s必须是 %d 到 %d 的整数", label, int(lo), int(hi)))
	}
	return nil
}
```

```go
package http

import (
	nethttp "net/http"
	"strings"

	"github.com/go-chi/chi/v5"

func init() { settingsRouteRegistrars = append(settingsRouteRegistrars, registerAgentModelSettings) }

func registerAgentModelSettings(r chi.Router, d SettingsCenterDeps) {
	if d.Agent == nil || d.Models == nil {
		return
	}
	h := &agentModelSettingsHandler{d: d}
	r.Get("/agent-models", h.list)
	r.Put("/agent-models/{id}", h.switchModel)
	r.Post("/agent-models/{id}/restore-default", h.restore)
}

type agentModelSettingsHandler struct{ d SettingsCenterDeps }

type agentCandidate struct {
	ModelID string `json:"modelId"`
	Name    string `json:"name"`
}

// candidates 是 Agent 可选的模型：模型中心里已启用的文本模型（spec A2）。
func (h *agentModelSettingsHandler) candidates() ([]agentCandidate, error) {
	list, err := h.d.Models.List(false)
	if err != nil {
		return nil, err
	}
	out := []agentCandidate{}
	for _, m := range list {
		if m.Type == "text" && m.Enabled {
			out = append(out, agentCandidate{ModelID: m.ModelID, Name: m.Name})
		}
	}
	return out, nil
}

func (h *agentModelSettingsHandler) writeList(w nethttp.ResponseWriter, r *nethttp.Request) {
	items, err := h.d.Agent.ListAgentModels(r.Context())
	if err != nil {
		scWriteError(w, err)
		return
	}
	cands, err := h.candidates()
	if err != nil {
		scWriteError(w, err)
		return
	}
	if items == nil {
		items = []AgentModelItem{}
	}
	writeJSON(w, nethttp.StatusOK, map[string]any{"data": items, "candidates": cands})
}

func (h *agentModelSettingsHandler) list(w nethttp.ResponseWriter, r *nethttp.Request) { h.writeList(w, r) }

func (h *agentModelSettingsHandler) switchModel(w nethttp.ResponseWriter, r *nethttp.Request) {
	id, err := parseSettingsID(r)
	if err != nil {
		scWriteError(w, err)
		return
	}
	var body struct {
		ModelName string `json:"modelName"`
	}
	if err := scDecodeStrict(w, r, &body); err != nil {
		scWriteError(w, err)
		return
	}
	name := strings.TrimSpace(body.ModelName)
	cands, err := h.candidates()
	if err != nil {
		scWriteError(w, err)
		return
	}
	ok := false
	for _, c := range cands {
		if c.ModelID == name {
			ok = true
		}
	}
	if !ok {
		scWriteError(w, scValidation("modelName", "只能选择模型中心里已启用的文本模型"))
		return
	}
	if err := h.d.Agent.SwitchAgentModel(r.Context(), id, name); err != nil {
		scWriteError(w, err)
		return
	}
	h.writeList(w, r)
}

func (h *agentModelSettingsHandler) restore(w nethttp.ResponseWriter, r *nethttp.Request) {
	id, err := parseSettingsID(r)
	if err != nil {
		scWriteError(w, err)
		return
	}
	if err := h.d.Agent.RestoreAgentModelDefault(r.Context(), id); err != nil {
		scWriteError(w, err)
		return
	}
	h.writeList(w, r)
}
```

- Produces：
  - `datadir.PointerFileName = "data-location.json"`（Rust 侧同名常量，Task 7）
  - `datadir.ValidateTarget(current, target string) (string, error)`（Task 2 用；错误文案直接给用户看）
  - `datadir.Migrate(from, to string) error`、`datadir.Cleanup(oldDir, newDir string) error`
  - sidecar 子命令（Task 7 的壳调用，**这是 Go 与 Rust 的唯一契约**）：
    - `sidecar migrate-data-dir --from <当前目录> --to <新目录>`：成功 stdout 打印 `MIGRATED`、退出码 0；失败退出码 1，stderr 最后一行是原因。
    - `sidecar cleanup-data-dir --old <旧目录> --new <新目录>`：成功打印 `CLEANED`。
    - 两个子命令都不读 stdin、不监听端口。

设计要点（写进代码注释）：
- **复制而不是移动**：先完整复制到新目录并校验，壳写回指针文件后，下次启动的第一步才清理旧目录（`cleanup-data-dir`）。任一步中断，原目录都是完整的。
- **数据库用 `VACUUM INTO`**：得到包含 WAL 中已提交内容的一致单文件副本（p1-research §6）。
- **断点**：开始复制前在新目录写 `.miaoju-migrating` 标记；带标记的目录视为“上次没做完的迁移”，校验放行，复制前清空。
- **清理只删有副本的条目**：旧目录里某一项在新目录存在同名项才删；指针文件永远不删（它就放在默认数据目录里）。
- **目标必须为空**：除 `.DS_Store`、`Thumbs.db`、`desktop.ini`、`data-location.json` 外不能有任何东西——所以默认目录在迁出并清理后又能被选回来。

```go
// Package datadir 实现设置页的“修改数据目录”（spec S2）。
//
// 流程：设置页校验新目录（ValidateTarget）→ 壳记下待迁移路径并重启 → 下次启动时壳先调用
// `sidecar migrate-data-dir`（Migrate：复制 + 校验，不删源）→ 壳把指针文件改成新目录 →
// 再调用 `sidecar cleanup-data-dir`（Cleanup：删掉旧目录里已有副本的条目）→ 正常启动。
// 任一步中断，原目录都是完整的；新目录里的 .miaoju-migrating 标记让下次重做。
package datadir

import (
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"runtime"
	"strings"
	"syscall"

	"github.com/james/huabu_studio/apps/api/internal/db"
)

// PointerFileName 是壳记录当前 / 待迁移数据目录的文件名，放在系统默认数据目录里，永不复制、永不删除。
const PointerFileName = "data-location.json"

const (
	markerName = ".miaoju-migrating"
	dbName     = "data.db"
	dbTmpName  = "data.db.migrating"
)

// ignorable 是判断“目录为空”时忽略的文件。
var ignorable = map[string]bool{".DS_Store": true, "Thumbs.db": true, "desktop.ini": true, PointerFileName: true}

// notCopied 是复制时跳过的顶层条目：数据库单独用 VACUUM INTO 复制，诊断样本不迁移。
var notCopied = map[string]bool{markerName: true, dbName: true, dbName + "-wal": true, dbName + "-shm": true, dbTmpName: true, "diag": true}

// ValidateTarget 校验新数据目录，返回规范化后的路径。错误文案直接展示给用户。
func ValidateTarget(current, target string) (string, error) {
	t := strings.TrimSpace(target)
	if t == "" {
		return "", errors.New("请选择新的数据目录")
	}
	// 与 db.Open 相同的限制：驱动按 DSN 解析路径，"?" 之后会被当成参数。
	if strings.Contains(t, "?") || strings.HasPrefix(t, "file:") {
		return "", fmt.Errorf("数据目录路径不能包含 \"?\"，也不能以 \"file:\" 开头：%s", t)
	}
	if !filepath.IsAbs(t) {
		return "", fmt.Errorf("请选择绝对路径：%s", t)
	}
	t = filepath.Clean(t)
	rc, rt := realPath(current), realPath(t)
	switch {
	case samePath(rc, rt):
		return "", errors.New("新目录与当前数据目录相同")
	case within(rt, rc):
		return "", errors.New("不能选择当前数据目录里面的文件夹")
	case within(rc, rt):
		return "", errors.New("不能选择当前数据目录的上级文件夹")
	}
	st, err := os.Stat(t)
	switch {
	case err == nil && !st.IsDir():
		return "", errors.New("所选路径不是文件夹")
	case err == nil:
		entries, err := os.ReadDir(t)
		if err != nil {
			return "", fmt.Errorf("无法读取所选文件夹：%w", err)
		}
		if !hasEntry(entries, markerName) {
			for _, e := range entries {
				if !ignorable[e.Name()] {
					return "", errors.New("所选文件夹不是空的，请选择空文件夹或新建一个")
				}
			}
		}
	case errors.Is(err, os.ErrNotExist) || errors.Is(err, syscall.ENOTDIR):
		// 不存在（或路径中间有同名文件，交给 checkWritable 给出准确提示）
	default:
		return "", fmt.Errorf("无法访问所选文件夹：%w", err)
	}
	if err := checkWritable(t); err != nil {
		return "", err
	}
	return t, nil
}

// Migrate 把 from 的全部数据复制到 to 并校验新数据库。不修改、不删除 from。
func Migrate(from, to string) (err error) {
	target, err := ValidateTarget(from, to)
	if err != nil {
		return err
	}
	if err = os.MkdirAll(target, 0o700); err != nil {
		return fmt.Errorf("创建新数据目录：%w", err)
	}
	if err = wipe(target); err != nil {
		return err
	}
	if err = os.WriteFile(filepath.Join(target, markerName), []byte("migrating\n"), 0o600); err != nil {
		return fmt.Errorf("写入迁移标记：%w", err)
	}
	defer func() {
		if err != nil {
			// 失败时清掉半成品；清不掉也没关系，标记让下次重做。
			if wipe(target) == nil {
				_ = os.Remove(filepath.Join(target, markerName))
				_ = os.Remove(target) // 只有空目录才会成功
			}
		}
	}()
	entries, err := os.ReadDir(from)
	if err != nil {
		return fmt.Errorf("读取原数据目录：%w", err)
	}
	for _, e := range entries {
		name := e.Name()
		if notCopied[name] || ignorable[name] {
			continue
		}
		src, dst := filepath.Join(from, name), filepath.Join(target, name)
		switch {
		case e.IsDir():
			err = copyTree(src, dst)
		case e.Type().IsRegular():
			err = copyFile(src, dst)
		}
		if err != nil {
			return fmt.Errorf("复制 %s：%w", name, err)
		}
	}
	if err = copyDatabase(from, target); err != nil {
		return err
	}
	return os.Remove(filepath.Join(target, markerName))
}

// Cleanup 删除 oldDir 里在 newDir 已有同名副本的条目（数据库的 -wal/-shm 随 data.db 一起删）。
func Cleanup(oldDir, newDir string) error {
	if !filepath.IsAbs(oldDir) || !filepath.IsAbs(newDir) {
		return errors.New("清理旧目录需要绝对路径")
	}
	if samePath(realPath(oldDir), realPath(newDir)) {
		return errors.New("新旧数据目录相同，拒绝清理")
	}
	if _, err := os.Stat(filepath.Join(newDir, dbName)); err != nil {
		return fmt.Errorf("新数据目录里没有 data.db，拒绝清理旧目录：%w", err)
	}
	entries, err := os.ReadDir(oldDir)
	if errors.Is(err, os.ErrNotExist) {
		return nil
	}
	if err != nil {
		return err
	}
	var failed []string
	for _, e := range entries {
		name := e.Name()
		if ignorable[name] {
			continue
		}
		hasCopy := name == dbName+"-wal" || name == dbName+"-shm"
		if !hasCopy {
			_, statErr := os.Lstat(filepath.Join(newDir, name))
			hasCopy = statErr == nil
		}
		if !hasCopy {
			continue
		}
		if err := os.RemoveAll(filepath.Join(oldDir, name)); err != nil {
			failed = append(failed, name)
		}
	}
	if len(failed) > 0 {
		return fmt.Errorf("以下内容未能删除：%s", strings.Join(failed, "、"))
	}
	return nil
}

// copyDatabase 用 VACUUM INTO 得到包含 WAL 已提交内容的一致副本，改名后用 quick_check 校验。
func copyDatabase(from, to string) error {
	src := filepath.Join(from, dbName)
	if _, err := os.Stat(src); errors.Is(err, os.ErrNotExist) {
		return nil
	}
	conn, err := db.Open(src)
	if err != nil {
		return fmt.Errorf("打开原数据库：%w", err)
	}
	tmp := filepath.Join(to, dbTmpName)
	_ = os.Remove(tmp)
	if _, err := conn.Exec(`VACUUM INTO ?`, tmp); err != nil {
		conn.Close()
		return fmt.Errorf("复制数据库：%w", err)
	}
	if err := conn.Close(); err != nil {
		return fmt.Errorf("关闭原数据库：%w", err)
	}
	final := filepath.Join(to, dbName)
	if err := os.Rename(tmp, final); err != nil {
		return fmt.Errorf("数据库改名：%w", err)
	}
	check, err := db.Open(final)
	if err != nil {
		return fmt.Errorf("打开新数据库：%w", err)
	}
	var res string
	qerr := check.QueryRow(`PRAGMA quick_check`).Scan(&res)
	cerr := check.Close()
	if qerr != nil {
		return fmt.Errorf("校验新数据库：%w", qerr)
	}
	if res != "ok" {
		return fmt.Errorf("新数据库校验失败：%s", res)
	}
	return cerr
}

func copyTree(src, dst string) error {
	return filepath.WalkDir(src, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		rel, err := filepath.Rel(src, p)
		if err != nil {
			return err
		}
		target := filepath.Join(dst, rel)
		switch {
		case d.IsDir():
			return os.MkdirAll(target, 0o700)
		case d.Type().IsRegular():
			return copyFile(p, target)
		default:
			return nil // 符号链接等特殊文件不复制
		}
	})
}

func copyFile(src, dst string) error {
	in, err := os.Open(src)
	if err != nil {
		return err
	}
	defer in.Close()
	st, err := in.Stat()
	if err != nil {
		return err
	}
	out, err := os.OpenFile(dst, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)
	if err != nil {
		return err
	}
	n, err := io.Copy(out, in)
	if err == nil && n != st.Size() {
		err = fmt.Errorf("复制不完整：%d/%d 字节", n, st.Size())
	}
	if err == nil {
		err = out.Sync()
	}
	if cerr := out.Close(); err == nil {
		err = cerr
	}
	return err
}

// wipe 删除 dir 下除可忽略文件和迁移标记外的全部内容。只对通过 ValidateTarget 的目录调用。
func wipe(dir string) error {
	entries, err := os.ReadDir(dir)
	if err != nil {
		return err
	}
	for _, e := range entries {
		if ignorable[e.Name()] || e.Name() == markerName {
			continue
		}
		if err := os.RemoveAll(filepath.Join(dir, e.Name())); err != nil {
			return fmt.Errorf("清理新数据目录：%w", err)
		}
	}
	return nil
}

func hasEntry(entries []os.DirEntry, name string) bool {
	for _, e := range entries {
		if e.Name() == name {
			return true
		}
	}
	return false
}

// checkWritable 在 dir 或其最近的已存在祖先目录里试写一个临时文件。
func checkWritable(dir string) error {
	p := dir
	for {
		st, err := os.Stat(p)
		if err == nil {
			if !st.IsDir() {
				return fmt.Errorf("路径中有同名文件：%s", p)
			}
			break
		}
		parent := filepath.Dir(p)
		if parent == p {
			return errors.New("所选位置不可用")
		}
		p = parent
	}
	f, err := os.CreateTemp(p, ".miaoju-write-test-*")
	if err != nil {
		return fmt.Errorf("所选位置没有写入权限：%w", err)
	}
	name := f.Name()
	f.Close()
	return os.Remove(name)
}

// realPath 解析路径中已存在部分的符号链接（macOS 的 /var → /private/var），不存在的尾部原样拼回。
func realPath(p string) string {
	p = filepath.Clean(p)
	rest := ""
	for {
		if r, err := filepath.EvalSymlinks(p); err == nil {
			return filepath.Join(r, rest)
		}
		parent := filepath.Dir(p)
		if parent == p {
			return filepath.Join(p, rest)
		}
		rest = filepath.Join(filepath.Base(p), rest)
		p = parent
	}
}

// normCase：Windows 与 macOS 默认文件系统不区分大小写。
func normCase(p string) string {
	if runtime.GOOS == "windows" || runtime.GOOS == "darwin" {
		return strings.ToLower(p)
	}
	return p
}

func samePath(a, b string) bool { return normCase(a) == normCase(b) }

// within 报告 child 是否严格位于 parent 之内。
func within(child, parent string) bool {
	rel, err := filepath.Rel(normCase(parent), normCase(child))
	if err != nil || rel == "." {
		return false
	}
	return rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator))
}
```

```go
// runSubcommand 处理壳在正常启动前调用的一次性子命令（数据目录迁移，spec S2）。
// 返回 handled=false 表示不是子命令，按正常服务模式继续。子命令不读 stdin、不监听端口。
func runSubcommand(args []string, stdout io.Writer) (bool, error) {
	if len(args) == 0 {
		return false, nil
	}
	switch args[0] {
	case "migrate-data-dir":
		fs := flag.NewFlagSet(args[0], flag.ContinueOnError)
		from := fs.String("from", "", "当前数据目录")
		to := fs.String("to", "", "新数据目录")
		if err := fs.Parse(args[1:]); err != nil {
			return true, err
		}
		if *from == "" || *to == "" {
			return true, errors.New("migrate-data-dir 需要 --from 和 --to")
		}
		if err := datadir.Migrate(*from, *to); err != nil {
			return true, err
		}
		fmt.Fprintln(stdout, "MIGRATED")
		return true, nil
	case "cleanup-data-dir":
		fs := flag.NewFlagSet(args[0], flag.ContinueOnError)
		oldDir := fs.String("old", "", "旧数据目录")
		newDir := fs.String("new", "", "新数据目录")
		if err := fs.Parse(args[1:]); err != nil {
			return true, err
		}
		if *oldDir == "" || *newDir == "" {
			return true, errors.New("cleanup-data-dir 需要 --old 和 --new")
		}
		if err := datadir.Cleanup(*oldDir, *newDir); err != nil {
			return true, err
		}
		fmt.Fprintln(stdout, "CLEANED")
		return true, nil
	}
	return false, nil
}
```

```rust
//! 数据目录的位置记录与启动前迁移（spec S2）。
//! 迁移本身由 sidecar 子命令完成（Go 侧有 SQLite 的 VACUUM INTO），这里只负责：
//! 读写指针文件、按顺序调用子命令、把结果写回指针文件、提供设置页用的命令。

use std::path::{Path, PathBuf};
use std::sync::Mutex;

use serde::{Deserialize, Serialize};
use tauri::{Manager, State};
use tauri_plugin_shell::ShellExt;

/// 与 Go `datadir.PointerFileName` 一致。
pub const POINTER_FILE: &str = "data-location.json";

#[derive(Default, Clone, Debug, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct Location {
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub data_dir: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub pending_data_dir: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub cleanup_data_dir: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub last_error: Option<String>,
}

/// 指针文件不存在 → 默认值；存在但损坏 → 报错（不能悄悄回到默认目录，用户会以为数据丢了）。
pub fn read_location(path: &Path) -> Result<Location, String> {
    match std::fs::read_to_string(path) {
        Ok(s) => serde_json::from_str(&s)
            .map_err(|e| format!("数据目录配置文件已损坏（{}）：{e}", path.display())),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(Location::default()),
        Err(e) => Err(format!("无法读取数据目录配置文件（{}）：{e}", path.display())),
    }
}

/// 先写临时文件再改名，避免写一半断电留下损坏的指针文件。
pub fn write_location(path: &Path, loc: &Location) -> Result<(), String> {
    let tmp = path.with_extension("json.tmp");
    let body = serde_json::to_string_pretty(loc).map_err(|e| e.to_string())?;
    std::fs::write(&tmp, body).map_err(|e| format!("无法写入数据目录配置：{e}"))?;
    std::fs::rename(&tmp, path).map_err(|e| format!("无法写入数据目录配置：{e}"))
}

/// 与 Go `db.Open` / `datadir.ValidateTarget` 相同的语法限制（完整校验在 sidecar 的 /data-dir/check）。
pub fn check_path_syntax(p: &str) -> Result<(), String> {
    if p.trim().is_empty() {
        return Err("请选择新的数据目录".into());
    }
    if p.contains('?') || p.starts_with("file:") {
        return Err(format!("数据目录路径不能包含 \"?\"，也不能以 \"file:\" 开头：{p}"));
    }
    if !Path::new(p).is_absolute() {
        return Err(format!("请选择绝对路径：{p}"));
    }
    Ok(())
}

pub fn current_dir(default: &Path, loc: &Location) -> PathBuf {
    match loc.data_dir.as_deref() {
        Some(d) if !d.is_empty() => PathBuf::from(d),
        _ => default.to_path_buf(),
    }
}

#[derive(Debug, PartialEq)]
pub enum Step {
    Migrate { from: PathBuf, to: PathBuf },
    Cleanup { old: PathBuf, new: PathBuf },
}

/// 启动时下一步要做什么。after_* 总会清掉对应字段，所以循环必然结束。
pub fn next_step(default: &Path, loc: &Location) -> Option<Step> {
    if let Some(to) = loc.pending_data_dir.as_deref().filter(|s| !s.is_empty()) {
        return Some(Step::Migrate { from: current_dir(default, loc), to: PathBuf::from(to) });
    }
    if let Some(old) = loc.cleanup_data_dir.as_deref().filter(|s| !s.is_empty()) {
        return Some(Step::Cleanup { old: PathBuf::from(old), new: current_dir(default, loc) });
    }
    None
}

pub fn after_migrate(loc: &Location, from: &Path, result: Result<(), String>) -> Location {
    let mut next = loc.clone();
    let to = next.pending_data_dir.take();
    match result {
        Ok(()) => {
            next.data_dir = to;
            next.cleanup_data_dir = Some(from.to_string_lossy().into_owned());
            next.last_error = None;
        }
        Err(e) => next.last_error = Some(format!("数据目录迁移失败，仍在使用原目录：{e}")),
    }
    next
}

pub fn after_cleanup(loc: &Location, result: Result<(), String>) -> Location {
    let mut next = loc.clone();
    let old = next.cleanup_data_dir.take().unwrap_or_default();
    if let Err(e) = result {
        next.last_error = Some(format!("旧数据目录 {old} 未能清理干净，可以手动删除：{e}"));
    }
    next
}

/// 自定义数据目录不存在时报错，绝不自动新建（可能是移动硬盘没插）；默认目录照常创建。
pub fn ensure_current_exists(default: &Path, loc: &Location) -> Result<PathBuf, String> {
    let cur = current_dir(default, loc);
    if cur.as_path() != default && !cur.is_dir() {
        return Err(format!(
            "数据目录不存在：{}。如果它在移动硬盘上，请连接后重新打开应用。",
            cur.display()
        ));
    }
    Ok(cur)
}

pub fn last_line(s: &str) -> Option<String> {
    s.lines().rev().map(str::trim).find(|l| !l.is_empty()).map(String::from)
}

/// 设置页需要的数据目录状态，启动时放进 Tauri 托管状态。
pub struct DataDirState {
    pub default_dir: PathBuf,
    pub current: PathBuf,
    pub pointer: PathBuf,
    pub last_error: Mutex<Option<String>>,
}

#[derive(Serialize)]
#[serde(rename_all = "camelCase")]
pub struct DataDirStatus {
    current: String,
    default_dir: String,
    last_error: Option<String>,
}

#[tauri::command]
pub fn data_dir_status(state: State<'_, DataDirState>) -> DataDirStatus {
    DataDirStatus {
        current: state.current.to_string_lossy().into_owned(),
        default_dir: state.default_dir.to_string_lossy().into_owned(),
        last_error: state.last_error.lock().unwrap().clone(),
    }
}

#[tauri::command]
pub fn dismiss_data_dir_error(state: State<'_, DataDirState>) -> Result<(), String> {
    let mut loc = read_location(&state.pointer)?;
    loc.last_error = None;
    write_location(&state.pointer, &loc)?;
    *state.last_error.lock().unwrap() = None;
    Ok(())
}

/// 调一次 sidecar 子命令并等它结束。
fn run_sidecar_once(app: &tauri::AppHandle, args: Vec<String>) -> Result<(), String> {
    let cmd = app
        .shell()
        .sidecar("sidecar")
        .map_err(|e| format!("找不到 sidecar 程序：{e}"))?
        .args(args);
    let out = tauri::async_runtime::block_on(cmd.output())
        .map_err(|e| format!("无法启动 sidecar：{e}"))?;
    if out.status.success() {
        return Ok(());
    }
    Err(last_line(&String::from_utf8_lossy(&out.stderr))
        .unwrap_or_else(|| format!("sidecar 退出码 {:?}", out.status.code())))
}

/// 启动 sidecar 之前调用：执行待办的迁移 / 清理，返回本次要用的数据目录。
/// 无论成功与否都返回 DataDirState（命令需要它）；Err 里是给用户看的原因。
pub fn prepare(app: &tauri::AppHandle) -> (DataDirState, Result<PathBuf, String>) {
    let default = match app.path().app_data_dir() {
        Ok(d) => d,
        Err(e) => {
            let state = DataDirState { default_dir: PathBuf::new(), current: PathBuf::new(), pointer: PathBuf::new(), last_error: Mutex::new(None) };
            return (state, Err(format!("无法确定数据目录：{e}")));
        }
    };
    let pointer = app
        .path()
        .app_config_dir()
        .unwrap_or_else(|_| default.clone())
        .join(POINTER_FILE);
    let result = (|| -> Result<(PathBuf, Location), String> {
        std::fs::create_dir_all(&default).map_err(|e| format!("无法创建数据目录：{e}"))?;
        if let Some(dir) = pointer.parent() {
            std::fs::create_dir_all(dir).map_err(|e| format!("无法创建配置目录：{e}"))?;
        }
        let mut loc = read_location(&pointer)?;
        while let Some(step) = next_step(&default, &loc) {
            loc = match step {
                Step::Migrate { from, to } => {
                    let r = run_sidecar_once(app, vec![
                        "migrate-data-dir".into(), "--from".into(), from.to_string_lossy().into_owned(),
                        "--to".into(), to.to_string_lossy().into_owned(),
                    ]);
                    after_migrate(&loc, &from, r)
                }
                Step::Cleanup { old, new } => {
                    let r = run_sidecar_once(app, vec![
                        "cleanup-data-dir".into(), "--old".into(), old.to_string_lossy().into_owned(),
                        "--new".into(), new.to_string_lossy().into_owned(),
                    ]);
                    after_cleanup(&loc, r)
                }
            };
            write_location(&pointer, &loc)?;
        }
        Ok((ensure_current_exists(&default, &loc)?, loc))
    })();
    match result {
        Ok((current, loc)) => {
            let state = DataDirState { default_dir: default, current: current.clone(), pointer, last_error: Mutex::new(loc.last_error) };
            (state, Ok(current))
        }
        Err(e) => {
            let state = DataDirState { default_dir: default.clone(), current: default, pointer, last_error: Mutex::new(Some(e.clone())) };
            (state, Err(e))
        }
    }
}
```

```rust
/// 设置页“更改数据目录”：记下待迁移路径，结束 sidecar 后重启应用；迁移在下次启动时进行。
#[tauri::command]
fn apply_data_dir_change(
    app: tauri::AppHandle,
    sidecar: State<'_, Sidecar>,
    dirs: State<'_, datadir::DataDirState>,
    path: String,
) -> Result<(), String> {
    datadir::check_path_syntax(&path)?;
    if Path::new(&path) == dirs.current.as_path() {
        return Err("新目录与当前数据目录相同".into());

    let mut loc = datadir::read_location(&dirs.pointer)?;
    loc.pending_data_dir = Some(path);
    datadir::write_location(&dirs.pointer, &loc)?;
    if let Some(child) = sidecar.child.lock().unwrap().take() {
        let _ = child.kill();
    }
    app.restart();
}
```

```ts
async function request<T>(method: 'GET' | 'PUT' | 'PATCH' | 'POST', path: string, body?: unknown): Promise<T> {
  const info = await getServerInfo();
  const headers: Record<string, string> = { ...authHeaders(info) };
  if (body !== undefined) headers['Content-Type'] = 'application/json';
  const resp = await fetch(buildHttpUrl(info, `/api/v1/settings${path}`), {
    method,
    headers,
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const text = await resp.text();
  let data: any = null;
  try {
    data = text ? JSON.parse(text) : null;
  } catch {
    data = null;
  }
  if (!resp.ok) {
    throw new SettingsApiError(resp.status, data?.error ?? `请求失败（HTTP ${resp.status}）`, data?.field);

  return data as T;
```

```ts
export type DraftPath = (string | number)[];

/** 不可变地替换 path 处的值：路径上的对象/数组浅拷贝，其余分支复用原引用，未知字段原样保留。 */
export function updateAt<T>(obj: T, path: DraftPath, value: unknown): T {
  if (path.length === 0) return value as T;
  const [head, ...rest] = path;
  if (Array.isArray(obj)) {
    const copy = obj.slice();
    copy[head as number] = updateAt(copy[head as number], rest, value);
    return copy as unknown as T;
  }
  const base = (obj ?? {}) as Record<string, unknown>;
  return { ...base, [head]: updateAt(base[head as string], rest, value) } as T;
}

export function deepClone<T>(v: T): T {
  return JSON.parse(JSON.stringify(v)) as T;
}
```

```ts
import { App as AntApp } from 'antd';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { errorText, getConfig, putConfig, restoreConfig, type ConfigKey, type ConfigView } from './api';

/** 五个画布配置页共用：读取、整份保存（草稿含全部原字段）、恢复默认。 */
export function useConfigEditor<T>(key: ConfigKey) {
  const qc = useQueryClient();
  const { message } = AntApp.useApp();
  const queryKey = ['settings-config', key];
  const query = useQuery({ queryKey, queryFn: () => getConfig<T>(key) });
  const onError = (e: unknown) => message.error(errorText(e));
  const save = useMutation<ConfigView<T>, Error, T>({
    mutationFn: (value) => putConfig<T>(key, value),
    onSuccess: (v) => {
      qc.setQueryData(queryKey, v);
      qc.invalidateQueries({ queryKey: ['settings-models'] }); // 模型页的“被引用”标记随之变化
      message.success('已保存');
    },
    onError,
  });
  const restore = useMutation<ConfigView<T>, Error, void>({
    mutationFn: () => restoreConfig<T>(key),
    onSuccess: (v) => {
      qc.setQueryData(queryKey, v);
      qc.invalidateQueries({ queryKey: ['settings-models'] });
      message.success('已恢复默认');
    },
    onError,
  });
  return { data: query.data, isLoading: query.isLoading, error: query.error, save, restore };
}
```

```tsx
export function modelOptions(models: ModelView[], type: string, value: string | string[] | undefined): ModelOption[] {
```

```ts
import type { ModelPatch, ModelView } from '../api';

export interface ModelFormValues {
  name: string;
  sortOrder: number;
  enabled: boolean;
  hidden: boolean;
  uiDefaults: Record<string, string | number>;
  concurrency: number;
  canvasMaxRetries: number;
  canvasRetryIntervalSec: number;
}

export const MODEL_FIELD_LABELS: Record<string, string> = {
  enabled: '启用',
  hidden: '隐藏',
  name: '显示名',
  sortOrder: '排序',
  uiSchemaDefaults: '参数默认值',
  concurrency: '并发上限',
  canvasMaxRetries: '最大重试次数',
  canvasRetryIntervalSec: '重试间隔',
};

export const TYPE_OPTIONS = [
  { value: 'all', label: '全部' },
  { value: 'image', label: '图片' },
  { value: 'video', label: '视频' },
  { value: 'audio', label: '音频' },
  { value: 'text', label: '文本' },
];

export function modelToForm(m: ModelView): ModelFormValues {
  const uiDefaults: Record<string, string | number> = {};
  for (const [k, f] of Object.entries(m.uiSchema ?? {})) if (f.default !== undefined) uiDefaults[k] = f.default;
  const canvas = m.genControl?.modules?.canvas;
  return {
    name: m.name,
    sortOrder: m.sortOrder,
    enabled: m.enabled,
    hidden: m.hidden,
    uiDefaults,
    concurrency: m.genControl?.concurrency ?? 0,
    canvasMaxRetries: canvas?.maxRetries ?? 0,
    canvasRetryIntervalSec: canvas?.retryIntervalSec ?? 0,
  };
}

/** 只放进与原值不同的字段；服务端严格拒绝补丁之外的任何字段（spec M10）。 */
export function formToPatch(m: ModelView, v: ModelFormValues): ModelPatch {
  const before = modelToForm(m);
  const p: ModelPatch = {};
  const name = v.name.trim();
  if (name !== before.name) p.name = name;
  if (v.sortOrder !== before.sortOrder) p.sortOrder = v.sortOrder;
  if (v.enabled !== before.enabled) p.enabled = v.enabled;
  if (v.hidden !== before.hidden) p.hidden = v.hidden;
  if (v.concurrency !== before.concurrency) p.concurrency = v.concurrency;
  if (v.canvasMaxRetries !== before.canvasMaxRetries) p.canvasMaxRetries = v.canvasMaxRetries;
  if (v.canvasRetryIntervalSec !== before.canvasRetryIntervalSec) p.canvasRetryIntervalSec = v.canvasRetryIntervalSec;
  const defaults: Record<string, string | number> = {};
  for (const [k, val] of Object.entries(v.uiDefaults ?? {})) if (val !== before.uiDefaults[k]) defaults[k] = val;
  if (Object.keys(defaults).length) p.uiSchemaDefaults = defaults;
  return p;
}

export function filterModels(list: ModelView[], type: string, keyword: string): ModelView[] {
  const kw = keyword.trim().toLowerCase();
  return list.filter(
    (m) => (type === 'all' || m.type === type) && (!kw || m.name.toLowerCase().includes(kw) || m.modelId.toLowerCase().includes(kw)),
  );
}
```

```ts
// 后处理与脚本配置的类型（与参考仓 canvasgen.CanvasPostprocessConfig、canvasscript.Config 一致）。
// 索引签名保证未知字段在草稿里原样保留。
export interface DesubBinding { modelId: string; label: string; subtitle?: string; isTimeLimited?: boolean; [k: string]: unknown }
export interface UpscaleBinding { modelId: string; label: string; [k: string]: unknown }
export interface PostprocessConfig {
  subtitleRemovalModels?: DesubBinding[];
  upscaleModels?: UpscaleBinding[];
  upscaleModel?: string;
  whiteModelModel?: string;
  [k: string]: unknown;
}
export interface ScriptCandidate { modelId: string; displayName: string; [k: string]: unknown }
export interface ScriptStyle { name: string; version: string; skillName: string; enabled: boolean; userTags?: string[]; [k: string]: unknown }
export interface ScriptConfig {
  modelCandidates: ScriptCandidate[];
  styles: ScriptStyle[];
  concurrency?: number;
  maxRetries?: number;
  [k: string]: unknown;
}

/** 转高清配置是新列表格式还是旧单字段格式。新列表非空时以列表为准（与参考仓 LoadCanvasPostprocessConfig 一致）。 */
export function upscaleMode(cfg: PostprocessConfig): 'list' | 'legacy' | 'none' {
  if (cfg.upscaleModels && cfg.upscaleModels.length > 0) return 'list';
  if (typeof cfg.upscaleModel === 'string') return 'legacy';
  return 'none';
}

export function scriptErrors(cfg: ScriptConfig): string[] {
  const errs: string[] = [];
  const seen = new Set<string>();
  cfg.modelCandidates.forEach((c, i) => {
    if (!c.modelId) errs.push(`第 ${i + 1} 个候选模型未选择`);
    else if (seen.has(c.modelId)) errs.push(`候选模型重复：${c.modelId}`);
    if (!String(c.displayName ?? '').trim()) errs.push(`第 ${i + 1} 个候选模型的展示名不能为空`);
    seen.add(c.modelId);
  });
  return errs;
}

export function moveItem<T>(arr: T[], from: number, to: number): T[] {
  if (to < 0 || to >= arr.length || from === to) return arr.slice();
  const copy = arr.slice();
  const [it] = copy.splice(from, 1);
  copy.splice(to, 0, it);
  return copy;
}
```

```ts
export interface PresetParamOption { key: string; name: string; prompt?: string; default?: boolean; [k: string]: unknown }
export interface PresetParam { key: string; name: string; options: PresetParamOption[]; [k: string]: unknown }
export interface PresetValue { name?: string; category?: string; placeholder?: string; prompt?: string; params?: PresetParam[]; [k: string]: unknown }
export interface GenImagePresetsConfig { models: string[]; presets: { key: string; value: PresetValue; [k: string]: unknown }[]; [k: string]: unknown }

export function groupByCategory(cfg: GenImagePresetsConfig) {
  const groups: { category: string; items: { index: number; preset: GenImagePresetsConfig['presets'][number] }[] }[] = [];
  cfg.presets.forEach((preset, index) => {
    const category = preset.value.category || '未分类';
    let g = groups.find((x) => x.category === category);
    if (!g) groups.push((g = { category, items: [] }));
    g.items.push({ index, preset });
  });
  return groups;
}

export function presetErrors(cfg: GenImagePresetsConfig): string[] {
  const errs: string[] = [];
  if (!cfg.models || cfg.models.length === 0) errs.push('至少选择一个绘图模型');
  for (const p of cfg.presets) {
    if (!String(p.value.prompt ?? '').trim()) errs.push(`「${p.value.name ?? p.key}」的提示词不能为空`);
  }
  return errs;
}
```

```ts
export interface MultiAnglePreset { key: string; name: string; rotation: number; tilt: number; zoom: string; prompt: string; [k: string]: unknown }
export interface MultiAngleConfig { models: string[]; template: string; presets: MultiAnglePreset[]; [k: string]: unknown }
export interface LightControlPreset {
  key: string; name: string; thumbnail?: string; direction?: string; brightness?: number | null; lightColor?: string; referenceImage?: string; prompt: string; [k: string]: unknown;
}
export interface LightControlConfig { models: string[]; template: string; presets: LightControlPreset[]; [k: string]: unknown }

const ZOOM_LABELS: Record<string, string> = { closeup: '特写', medium: '中景', panorama: '全景' };

/** 与 sidecar 校验一致：留空 = 用内置模板；非空必须含占位符。 */
export function templateError(template: string, placeholder: string): string | null {
  if (!template.trim() || template.includes(placeholder)) return null;
  return `拼接模板必须保留 ${placeholder}（留空则使用内置模板）`;
}

export function describeAngle(p: MultiAnglePreset): string {
  return `水平 ${p.rotation}° · 俯仰 ${p.tilt}° · ${ZOOM_LABELS[p.zoom] ?? p.zoom}`;
}

export function describeLight(p: LightControlPreset): string {
  const parts: string[] = [];
  if (p.direction) parts.push(`方向 ${p.direction}`);
  if (typeof p.brightness === 'number') parts.push(`亮度 ${p.brightness}`);
  if (p.lightColor) parts.push(`颜色 ${p.lightColor}`);
  if (p.referenceImage) parts.push('带参考图');
  return parts.length ? parts.join(' · ') : '仅附加提示词';
}
```

```ts
import type { AgentModelsView } from '../api';

const ROLE_LABELS: Record<string, string> = {
  planner: '主 Agent',
  utility: '上下文压缩',
  subagent_audio: '音频子 Agent',
  subagent_video: '视频子 Agent',
};

export function roleLabel(role: string): string {
  return ROLE_LABELS[role] ?? role;
}

export function candidateOptions(view: AgentModelsView, current: string) {
  const opts: { value: string; label: string; disabled?: boolean }[] = view.candidates.map((c) => ({ value: c.modelId, label: `${c.name}（${c.modelId}）` }));
  if (current && !opts.some((o) => o.value === current)) opts.push({ value: current, label: `${current}（已停用或不存在）`, disabled: true });
  return opts;
}
```

```tsx
import { App as AntApp, Card, Select, Space, Table, Tag, Typography } from 'antd';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { errorText, getAgentModels, restoreAgentModel, switchAgentModel, type AgentModelItem, type AgentModelsView } from '../api';
import { RestoreDefaultButton } from '../components/RestoreDefaultButton';
import { candidateOptions, roleLabel } from './agentRoles';

export function AgentModelsPage() {
  const { message } = AntApp.useApp();
  const qc = useQueryClient();
  const { data, isLoading } = useQuery({ queryKey: ['settings-agent-models'], queryFn: getAgentModels });
  const onDone = (v: AgentModelsView, msg: string) => {
    qc.setQueryData(['settings-agent-models'], v);
    qc.invalidateQueries({ queryKey: ['settings-models'] }); // 模型页“被使用”标记
    message.success(msg);
  };
  const sw = useMutation({
    mutationFn: ({ id, name }: { id: number; name: string }) => switchAgentModel(id, name),
    onSuccess: (v) => onDone(v, '已切换'),
    onError: (e) => message.error(errorText(e)),
  });
  const restore = useMutation({
    mutationFn: (id: number) => restoreAgentModel(id),
    onSuccess: (v) => onDone(v, '已恢复默认'),
    onError: (e) => message.error(errorText(e)),
  });

  return (
    <Card title="Agent 模型">
      <Typography.Paragraph type="secondary">
        Agent 对话使用的大模型。只能在模型中心里已启用的文本模型之间切换，其余参数为内置值、不可修改。
      </Typography.Paragraph>
      <Table<AgentModelItem>
        rowKey="id"
        loading={isLoading}
        pagination={false}
        dataSource={data?.data ?? []}
        columns={[
          {
            title: '用途',
            render: (_, it) => (
              <Space>
                {roleLabel(it.role)}

                options={data ? candidateOptions(data, it.modelName) : []}
                loading={sw.isPending && sw.variables?.id === it.id}
                onChange={(name) => sw.mutate({ id: it.id, name })}
              />
            ),
          },
          {
            title: '操作',
            width: 110,
            render: (_, it) => <RestoreDefaultButton onConfirm={() => restore.mutate(it.id)} disabled={!it.modified} />,
          },
        ]}
      />
    </Card>
  );
}
```

```go
func TestModelPatchToEdits(t *testing.T) {
	name, c, r, iv, so := "新名", 2, 3, 10, 5
	en := false
	edits, err := modelPatchToEdits(ModelPatch{
		Name: &name, Enabled: &en, SortOrder: &so, Concurrency: &c, CanvasMaxRetries: &r, CanvasRetryIntervalSec: &iv,
		UISchemaDefaults: map[string]json.RawMessage{"ratio": json.RawMessage(`"16:9"`)},
	})
	if err != nil {
		t.Fatal(err)
	}
	got := map[string]string{}
	for k, v := range edits {
		got[k] = string(v)
	}
	want := map[string]string{
		"name": `"新名"`, "enabled": `false`, "sort_order": `5`, "gen_control.concurrency": `2`,
		"gen_control.modules.canvas.maxRetries": `3`, "gen_control.modules.canvas.retryIntervalSec": `10`,
		"ui_schema.ratio.default": `"16:9"`,
	}
	for k, v := range want {
		if got[k] != v {
			t.Errorf("%s = %s, want %s", k, got[k], v)
		}
	}
	if len(got) != len(want) {
		t.Errorf("多余字段: %v", got)
	}
	if _, err := modelPatchToEdits(ModelPatch{UISchemaDefaults: map[string]json.RawMessage{"a.b": json.RawMessage(`1`)}}); err == nil {
		t.Fatal("参数名含非法字符应报错")
	}
}

func TestSettingEditsOnlyChangedEditablePaths(t *testing.T) {
	var cur, next any
	json.Unmarshal([]byte(`{"models":["a"],"template":"t {angle}","presets":[{"key":"fisheye","name":"鱼眼","prompt":"旧"},{"key":"top","name":"俯拍","prompt":"不变"}]}`), &cur)
	json.Unmarshal([]byte(`{"models":["a","b"],"template":"t {angle}","presets":[{"key":"fisheye","name":"改名被忽略","prompt":"新"},{"key":"top","name":"俯拍","prompt":"不变"}]}`), &next)
	edits, err := settingEdits([]string{"models", "template", "presets[*].prompt"}, cur, next)
	if err != nil {
		t.Fatal(err)
	}
	keys := []string{}
	for k := range edits {

	}
	sort.Strings(keys)

		t.Fatalf("edits=%v", keys)
```

```go
func mapPolicyErr(err error) error {
	var ve *builtin.ValidationError
	switch {
	case err == nil:
		return nil
	case errors.As(err, &ve):
		return &SettingsValidationError{Field: ve.Path, Message: ve.Msg}
	case errors.Is(err, builtin.ErrNotFound), errors.Is(err, agent.ErrBackboneNotFound):
		return ErrSettingsNotFound
	}
	return err
}

var pathIdentRe = regexp.MustCompile(`^[A-Za-z0-9_-]+$`)

// modelPatchToEdits 把补丁转成 P2a 的字段路径编辑（路径语法见 P2a path.go）。
func modelPatchToEdits(p ModelPatch) (map[string]json.RawMessage, error) {
	out := map[string]json.RawMessage{}
	put := func(path string, v any) {
		b, _ := json.Marshal(v)
		out[path] = b
	}
	if p.Name != nil {
		put("name", *p.Name)
	}
	if p.Enabled != nil {
		put("enabled", *p.Enabled)
	}
	if p.Hidden != nil {
		put("hidden", *p.Hidden)
	}
	if p.SortOrder != nil {
		put("sort_order", *p.SortOrder)
	}
	if p.Concurrency != nil {
		put("gen_control.concurrency", *p.Concurrency)
	}
	if p.CanvasMaxRetries != nil {
		put("gen_control.modules.canvas.maxRetries", *p.CanvasMaxRetries)
	}
	if p.CanvasRetryIntervalSec != nil {
		put("gen_control.modules.canvas.retryIntervalSec", *p.CanvasRetryIntervalSec)
	}
	for k, v := range p.UISchemaDefaults {
		if !pathIdentRe.MatchString(k) {
			return nil, scValidation("uiSchemaDefaults."+k, "参数名不合法")
		}
		out["ui_schema."+k+".default"] = v
	}
	return out, nil
}

func overrideToPatchField(path string) string {

		return "uiSchemaDefaults"

		return "concurrency"
	case path == "gen_control.modules.canvas.maxRetries":
		return "canvasMaxRetries"
	case path == "gen_control.modules.canvas.retryIntervalSec":
		return "canvasRetryIntervalSec"
	}
	return path
}

// settingEdits 在 next 上展开每个可改模式的具体路径，返回与 cur 相比值有变化的那些。
// 数组段按元素的 "key" 属性寻址（P2a 路径语法），新旧文档都按 key 取值，顺序变化不算修改。
func settingEdits(patterns []string, cur, next any) (map[string]json.RawMessage, error) {
	out := map[string]json.RawMessage{}
	for _, pat := range patterns {
		for _, path := range expandPaths(next, strings.Split(pat, "."), "") {
			nv, _ := valueAt(next, strings.Split(path, "."))
			ov, had := valueAt(cur, strings.Split(path, "."))
			if had && reflect.DeepEqual(nv, ov) {
				continue
			}
			b, err := json.Marshal(nv)
			if err != nil {
				return nil, err
			}
			out[path] = b
		}
	}
	return out, nil
}

// expandPaths 把模式（如 presets[*].prompt）在 doc 上展开成具体路径（presets[fisheye].prompt）。
func expandPaths(doc any, segs []string, prefix string) []string {
	if len(segs) == 0 {
		return []string{prefix}
	}
	obj, ok := doc.(map[string]any)
	if !ok {
		return nil
	}
	seg := segs[0]
	join := func(s string) string {
		if prefix == "" {
			return s
		}
		return prefix + "." + s
	}
	name, keyed := strings.CutSuffix(seg, "[*]")
	if !keyed {
		if _, exists := obj[seg]; !exists {
			return nil
		}
		return expandPaths(obj[seg], segs[1:], join(seg))
	}
	arr, _ := obj[name].([]any)
	var out []string
	for _, el := range arr {
		m, _ := el.(map[string]any)
		k, _ := m["key"].(string)
		if !pathIdentRe.MatchString(k) {
			continue
		}
		out = append(out, expandPaths(m, segs[1:], join(name+"["+k+"]"))...)
	}
	return out
}

// valueAt 按具体路径取值；name[key] 段在数组里找 key 属性相等的元素。
func valueAt(doc any, segs []string) (any, bool) {
	cur := doc
	for _, seg := range segs {
		obj, ok := cur.(map[string]any)
		if !ok {
			return nil, false
		}
		if i := strings.IndexByte(seg, '['); i >= 0 && strings.HasSuffix(seg, "]") {
			name, key := seg[:i], seg[i+1:len(seg)-1]
			arr, _ := obj[name].([]any)
			found := false
			for _, el := range arr {
				if m, ok := el.(map[string]any); ok && m["key"] == key {
					cur, found = m, true
					break
				}
			}
			if !found {
				return nil, false
			}
			continue
		}
		v, ok := obj[seg]
		if !ok {
			return nil, false
		}
		cur = v
	}
	return cur, true
}

func (a *backboneAgentModels) ListAgentModels(context.Context) ([]AgentModelItem, error) {
	rows, err := a.list()
	if err != nil {
		return nil, err
	}
	out := make([]AgentModelItem, 0, len(rows))
	for _, r := range rows {
		d, has := a.defaults(r.ID)
		out = append(out, AgentModelItem{ID: r.ID, Role: r.Role, Alias: r.Alias, ModelName: r.ModelName, Modified: has && d != r.ModelName})
	}
	sort.Slice(out, func(i, j int) bool { return out[i].ID < out[j].ID })
	return out, nil
}
```
