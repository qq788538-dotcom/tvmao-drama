## 1. 安装与首次打开

从 [Releases](../../../releases) 下载对应系统的安装包。

### macOS

1. Apple 芯片（M1 及以后）下载文件名带 `aarch64` 的 dmg，Intel 芯片下载带 `x64` 的。不确定的话点屏幕左上角苹果菜单 →「关于本机」查看。
2. 打开 dmg，把「喵剧AI」拖进「应用程序」。
3. 第一次打开会被系统拦截（应用没有购买苹果开发者证书）。打开「系统设置 → 隐私与安全性」，在最下方点「仍要打开」，输入开机密码确认。
4. 如果提示「已损坏，无法打开」，在「终端」里执行：

   ```sh
   sudo xattr -dr com.apple.quarantine /Applications/喵剧AI.app
   ```

要求 macOS 14 或更高版本。

### Windows

1. 下载 zip，右键「全部解压缩」，打开解压后的文件夹双击 `miaoju.exe`。不要在压缩包里直接运行，也不要只拷走 `miaoju.exe`，它依赖同目录下的 `sidecar.exe` 等文件。
2. 出现「Windows 已保护你的电脑」时，点「更多信息 → 仍要运行」。
3. 提示缺少 WebView2 时，点「确定」打开微软下载页安装。Windows 11 和较新的 Windows 10 已经自带。
4. 杀毒软件拦截 `sidecar.exe` 时请加入信任，它是喵剧AI 的本地服务，只监听本机 `127.0.0.1`。

要求 Windows 10 / 11 64 位。

## 2. 接入模型

喵剧AI 不自带模型服务，需要你接入一个兼容 [New API](https://www.qqdao.com/) 协议的模型网关。

1. 点画布右上角的「设置」，进入「模型中心」。
2. 在「默认上游」里填写：
   - **上游地址**：网关的根地址，例如 `https://example.com`。不用带 `/v1`，填了也会自动去掉。
   - **API Key**：网关给你的密钥。
3. 保存后，所有没有单独配置上游的模型都会通过这个地址调用。

### 给单个模型配置独立上游

在模型列表里点某个模型的「配置」，把「连接」从「使用全局」改成「单独配置」，填写该模型专用的上游地址和 API Key（两项必须同时填写）。适合某个模型只在另一家网关上有渠道的情况。

### 模型可以改什么

每个模型可以修改：是否启用、是否隐藏、显示名称、排序、参数默认值（如比例、分辨率、时长）、并发上限和最大重试次数。请求模板等技术字段只读。改错了可以点「恢复默认」。

> API Key 只保存在本机数据目录的 `data.db` 中，界面上只显示掩码，不会写入日志。

## 3. 项目管理

- 启动时自动打开上一次的项目；没有的话打开最近修改的项目；一个项目都没有时自动新建「未命名项目」。
- 点画布左上角「所有项目」进入项目列表，可以新建、重命名、删除项目，以及设置项目封面。
- 每个项目就是一张画布，画布内容随编辑自动保存。

## 4. 画布基础操作

| 操作 | macOS | Windows |
|---|---|---|
| 移动画布 | 触控板双指滚动；鼠标按住空白处拖动；或按住 Space 拖动 | 同左 |
| 缩放 | 触控板双指捏合；⌘ + 滚轮；⌘ + / ⌘ − | Ctrl + 滚轮；Ctrl + / Ctrl − |
| 适应画布 | ⌘ 0 | Ctrl 0 |
| 撤销 / 重做 | ⌘ Z / ⌘ ⇧ Z | Ctrl Z / Ctrl Shift Z |
| 复制选中节点 | ⌘ D | Ctrl D |
| 删除选中节点 | Delete | Delete |

- **添加节点**：右键画布空白处 →「添加节点」或「上传」。也可以直接把图片、视频、音频文件拖进画布。
- **连线**：从一个节点的输出端口拖到另一个节点的输入端口。上游节点的内容会作为下游生成的输入（参考图、首尾帧、参考视频等）。
- **自动整理**：选中两个以上节点，点左侧工具栏的「自动整理」，节点会对齐排列、去掉堆叠。
- **小地图**：右下角显示整张画布的缩略图，点击或拖动可以快速定位。

## 5. 节点

### 输入

| 节点 | 说明 |
|---|---|
| 上传 | 图片、音频、视频。上传后可以在节点上直接预览和使用对应工具 |
| 文字节点 | 编写提示词或剧本，支持 Markdown，可以用 `@` 引用连入的素材 |

### 生成

| 节点 | 说明 |
|---|---|
| AI 绘图 | 选择图片模型，写提示词，可接入参考图；支持比例、分辨率等参数和绘图预设 |
| AI 视频 | 选择视频模型，支持文生视频、图生视频、首尾帧、参考视频等，具体取决于模型 |
| AI 音频 | 配音、音效生成 |
| 脚本 | 剧本拆分镜，再批量生成视频，见 [第 7 节](#7-脚本节点与-3d-导演台) |
| 3D 导演台 | 3D 摆位预演，截图作为分镜参考 |

生成结果直接显示在节点上。一个节点可以多次生成，历史结果都能翻看和回填。

### 输出

| 节点 | 说明 |
|---|---|
| 保存到本地 | 把连入的图片或视频保存到你选择的文件夹 |

## 6. 图片、视频、音频工具

选中一个带媒体的节点，节点下方会出现工具条。

**图片**：宫格切分（如九宫格拆成 9 张）、标注、旋转镜像、打光、多角度、全景、放大查看、下载。

**视频**：

| 工具 | 说明 |
|---|---|
| 剪辑 | 截取一段，生成新的视频节点 |
| 裁剪 | 调整画面区域 |
| 智能续写 | 从结尾继续生成 |
| 片段重拍 | 重新生成其中一段 |
| 高清 / 白模 / 智能去字幕 | 后处理，结果生成为新节点 |
| 音频分离 | 拆出无声视频和音频 |

**抽帧**：上传的视频节点上可以「自动抽帧（2fps）」或「智能抽帧」，勾选需要的帧后点「发送到画布」，生成图片节点作为参考图。

**音频**：截取、变速（加速 / 减速）、波形预览。

剪辑、裁剪、抽帧等操作在本机完成，不消耗模型调用。

## 7. 脚本节点与 3D 导演台

### 脚本节点

1. 添加「脚本」节点，粘贴剧本或小说片段。
2. 选择风格（如真人短剧、3D 动画、解说分镜等），点生成。大模型会按风格模板把文本拆成分镜表，每一镜包含画面描述和提示词。
3. 确认分镜后，可以批量为每一镜生成视频。

### 3D 导演台

在 3D 场景中摆放人偶、调整姿势和机位，适合在生成前预演镜头构图。截图会作为图片输出，接到 AI 绘图或 AI 视频节点上作为参考。

## 8. Agent 对话

点顶栏的 Agent 按钮打开对话面板。Agent 能看到当前画布的内容，可以：

- 回答关于画布的问题，帮你写提示词、改剧本；
- 直接在画布上新建节点、连线、修改参数、发起生成；
- 调用内置技能（Skill）和子 Agent 完成多步任务。

在输入框里用 `@` 可以引用画布上的节点，让 Agent 针对具体内容操作。Agent 使用内置的大语言模型，和其他模型一样通过你配置的上游调用。

## 9. 生成历史、素材库与 AI 角色库

- **生成历史**：左侧工具栏打开，按时间列出所有生成结果。可以多选批量下载为 ZIP，或把结果回填到画布。
- **素材库**：左侧工具栏打开，用文件夹整理常用素材。右键媒体节点选「保存到素材库」，在素材库里点击即可应用到画布。
- **AI 角色库**：在素材库面板里打开，可以把角色形象直接引用到 Seedance 视频生成中。开源版不附带角色数据，角色库默认为空；自行构建时放入数据包的方法见 [seed/README.md](../seed/README.md)。

## 10. 命令行工具与 AI 编程助手

喵剧AI 附带一个命令行工具 `miaoju`，让终端或 Claude Code、Codex 等 AI 编程助手直接操作画布：建节点、接线、运行生成、做合规校验，改动会实时出现在打开的画布上。使用时喵剧AI 必须保持打开。

1. 打开「设置 → 命令行工具」，点「安装」。应用会把 `miaoju` 加入 PATH，并为已安装的 Claude Code / Codex 装好配套 Skill。也可以切到「让 AI 助手安装」，把那段话发给 AI 助手让它自己装。
2. 重新打开终端，运行 `miaoju project list -o table` 验证。
3. Codex 用户还需要在 `~/.codex/config.toml` 中放行本机网络，配置见设置页的「Codex 用户须知」。
4. 在 Claude Code、Codex 里新开会话，直接说需求，例如「用喵剧在当前项目里建一个图片节点，并接到视频生成节点上」。

两种工具分别怎么配置、推荐的工作方式和场景示例，见 [CLI 接入 AI 编程助手](ai-coding-tools.md)。命令的完整说明见 [CLI 手册](../cli/skill/SKILL.md)。

## 11. 设置

点画布右上角「设置」打开：

| 页面 | 内容 |
|---|---|
| 模型中心 | 默认上游、每个模型的独立上游与可调参数 |
| 命令行工具 | 安装 `miaoju` CLI 和 AI 助手 Skill，见 [第 10 节](#10-命令行工具与-ai-编程助手) |
| 对象存储 | 可选，配置你自己的 OSS / TOS 存储桶 |
| 配置 | 数据目录、应用与本地服务版本 |
| 环境诊断 | 一键检查本地服务连接和音视频编解码能力，结果可复制用于反馈问题 |

### 对象存储（可选）

部分视频模型需要通过公网链接读取参考视频、音频。在「设置 → 对象存储」里配置你自己的阿里云 OSS 或火山引擎 TOS 后，参考素材会上传到你的存储桶，并以 24 小时有效的私有链接交给模型。建议给存储桶设置生命周期规则（如 7 天自动删除）以控制费用。

## 12. 数据、备份与升级

### 数据目录

| 系统 | 默认位置 |
|---|---|
| macOS | `~/Library/Application Support/com.miaoju.desktop` |
| Windows | `%APPDATA%\com.miaoju.desktop` |

目录里包括数据库 `data.db`（项目、设置、API Key）和媒体文件。可以在「设置 → 配置 → 数据目录」更改位置，应用会把现有数据迁移过去后重启。

### 备份

退出喵剧AI 后，整体复制数据目录即可备份。注意其中包含明文 API Key，不要分享给他人。

### 升级

- macOS：把新版拖进「应用程序」并选择「替换」。
- Windows：关闭应用，删掉旧文件夹，解压新版本。

数据保存在数据目录里，升级不会丢失。内置模型会随新版本更新，你改过的字段会保留。

## 常见问题

**生成失败，提示上游错误或鉴权失败**
检查「模型中心」里的上游地址和 API Key 是否正确，以及网关是否提供该模型的渠道。

**模型列表里显示某个功能「未配置」**
该功能依赖的模型在你的网关上不可用，或已被隐藏。到「模型中心」确认模型已启用。

**Seedance 提示素材未通过合规校验**
Seedance 2.0 要求参考素材先通过合规校验。右键素材节点选「Seedance 合规校验」，通过后再生成。

**打开后停在失败页，提示本地服务无法启动**
如果提示上一个窗口仍在关闭，稍等几秒点「重试」。如果是自定义数据目录不可用（如外接硬盘没插），可以点「改用默认数据目录」。Windows 上请确认没有在压缩包里直接运行，并且杀毒软件没有拦截 `sidecar.exe`。

**视频处理或抽帧失败**
打开「设置 → 环境诊断」，点「运行连接与编解码检查」，把结果复制下来提 Issue。

**如何反馈问题**
在 [Issues](../../../issues) 里新建问题，附上系统版本、应用版本（「设置 → 配置」可见）和环境诊断结果。
