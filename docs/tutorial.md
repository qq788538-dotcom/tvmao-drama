## 开始之前

需要准备两样东西：

1. **安装好的喵剧AI**。下载和首次打开的放行方法见 [使用指南 0.1 节](user-guide.md#01-安装与首次打开)。
2. **一个模型网关的地址和 API Key**。喵剧AI 不自带模型服务，需要一个兼容 [New API](https://www.qqdao.com/) 协议的网关。

打开应用后会自动进入一张「未命名项目」画布。先点右上角「设置 → 模型中心」，在「默认上游」里填上网关地址（例如 `https://example.com`，不用带 `/v1`）和 API Key，保存。之后所有模型都会走这个地址。

> 生成会消耗你在网关上的额度。建节点、连线、剪辑、裁剪、抽帧这些操作都在本机完成，不花钱；只有点「生成」才会调用模型。

## 练习 1：第一张图

目标：用一句提示词生成一张图，熟悉画布和节点。

1. 在画布空白处右键，选「添加节点 → AI 绘图」。
2. 在节点里选择一个图片模型（例如 Nano-Banana-2 或豆包 Seedream 5.0）。
3. 写提示词，例如：`雨后的老城区街道，霓虹灯倒映在积水里，电影感，冷色调`。
4. 选一个比例（短剧竖屏常用 9:16），点「生成」。
5. 结果出现在节点上。不满意就再点一次生成，节点会保留每一次的结果，可以来回翻看，选中你要的那一张。

顺手熟悉几个画布操作：

- 双指滚动或按住空白处拖动来移动画布，⌘/Ctrl + 滚轮缩放，⌘/Ctrl 0 适应画布。
- ⌘/Ctrl Z 撤销，⌘/Ctrl D 复制选中节点。
- 右下角的小地图可以快速跳到画布的其他区域。

完整快捷键见 [使用指南第 8 节](user-guide.md#8-快捷键操作)。

## 练习 2：图生视频

目标：把练习 1 的图片变成一段 5 秒的视频。

1. 右键空白处，添加「AI 视频」节点。
2. 从图片节点右侧的输出端口拖一根线，接到视频节点的输入端口。这张图就成了视频的首帧参考。
3. 在视频节点里选一个视频模型（例如豆包 Seedance 系列），写运动描述，例如：`镜头缓慢向前推进，雨滴落下，霓虹灯闪烁`。
4. 设置时长和比例，点「生成」。视频生成通常比图片慢，节点上会显示进度。

小技巧：

- **多张参考图**：可以同时接入多张图片（如角色图和场景图），在提示词里用 `@` 说明每张图的作用。
- **参考视频**：部分模型可以接入一段视频作为动作或运镜参考。模型支持哪些输入，以节点上显示的选项为准。
- 用 **Seedance 2.0** 时，参考素材要先通过合规校验：右键素材节点选「Seedance 合规校验」，通过后再生成，否则会直接失败。

## 练习 3：带参考图生成同一个角色

目标：让同一个角色出现在不同镜头里，保持形象一致。

1. 把角色的参考图直接拖进画布（或右键「上传」），会生成一个图片输入节点。
2. 添加一个「AI 绘图」节点，把角色图连进去。
3. 写提示词，例如「图中的角色站在雨夜街头，回头看向镜头」。连了多张参考图时，可以在提示词里用 `@` 引用具体是哪张图，并写清每张图的作用（角色、场景、服装），模型更不容易混淆。
4. 生成后，再复制几个绘图节点（⌘/Ctrl D），分别改提示词，做出同一角色的不同镜头。

想先做一张角色设定图（三视图、表情表），可以先用文字节点写好角色设定，再接到绘图节点上。

## 练习 4：剧本拆分镜，批量出视频

目标：把一段剧本自动拆成分镜，并为每一镜生成视频。这是喵剧AI 最省时间的功能。

1. 双击画布空白处添加「脚本」节点，点「打开脚本节点 →」，把剧本或小说片段粘贴进去。比如：

   ```text
   夜，老城区。林晓撑着伞走进巷子，身后的脚步声越来越近。
   她猛地回头，巷口空无一人，只有一盏忽明忽暗的路灯。
   ```

2. 选一个风格（如「真人短剧风格」「3D动漫风格」）和每镜最长时长，点「生成分镜脚本」。大模型会按风格模板把文本拆成分镜表，每一镜有简述、时长和提示词。
3. 逐镜检查，提示词不满意可以直接修改，然后点「下一步：准备资产」。
4. 为角色、场景、物品准备参考图：可以 AI 生成、从画布选择，或者用练习 3 做好的角色图。资产图会接到各个镜头上，保证角色前后一致。
5. 右键脚本节点选「批量生成视频」，勾选镜头、选好视频模型，点「确认并创建视频生成器组」。每一镜会建好一个连好参考图的 AI 视频节点。
6. 这一步不会自动开始生成。检查一遍后，逐个点生成。

生成后可以切到「故事板视图」，按镜头顺序浏览整段内容。

## 练习 5：剪辑、续写和后处理

目标：把生成的视频修整到能用。

选中一个视频节点，节点下方会出现工具条：

| 想做什么 | 用哪个工具 |
|---|---|
| 只要中间几秒 | 剪辑：截取一段，生成新节点 |
| 画面构图要调整 | 裁剪 |
| 视频太短，想往后接着演 | 智能续写：从结尾继续生成 |
| 中间某一段崩了 | 片段重拍：只重新生成那一段 |
| 清晰度不够 | 高清 |
| 想去掉画面里的字幕 | 智能去字幕 |
| 想拆出声音单独处理 | 音频分离 |

所有处理结果都会生成为新节点，原视频不受影响，随时可以回头重来。

**从视频里挑帧**：上传的视频节点上有「自动抽帧（2fps）」和「智能抽帧」两个按钮。抽完后勾选需要的帧，点「发送到画布」，它们会变成图片节点，可以接到绘图或视频节点上当参考。适合从参考片里取构图，或者取上一镜的画面作为下一镜的首帧，让两镜衔接更自然。

## 练习 6：配音和音频

1. 添加「AI 音频」节点，选择配音模型（如微软 TTS 或豆包音频生成），写台词，生成。
2. 选中音频节点，用工具条做截取、变速，并通过波形预览对齐节奏。
3. 支持音频输入的视频模型可以把音频接进视频节点，用来驱动口型或节奏，具体看模型的输入选项。

## 练习 7：用 3D 导演台定机位

文字很难精确描述「人物在画面左三分之一、低机位仰拍」这类构图，3D 导演台就是用来解决这个问题的。

1. 添加「3D 导演台」节点，在 3D 场景里摆放人偶，调整姿势。
2. 移动镜头，找到你想要的机位和景别。
3. 截图。截图会作为图片输出，接到 AI 绘图或 AI 视频节点上作为构图参考。

## 练习 8：让 Agent 帮你搭画布

内置 Agent 能看到当前画布，可以替你建节点、连线、改参数、发起生成。

1. 点顶栏的 Agent 按钮打开对话面板。
2. 试试这些说法：
   - 「帮我把这段剧本写成 6 个镜头的分镜，每个镜头建一个 AI 视频节点，比例 9:16」
   - 「@角色图 用这张图做参考，生成角色的正面、侧面、背面三视图」
   - 「这几个视频节点的提示词太平淡了，帮我加上运镜描述」
3. Agent 改动画布前后，你都可以直接在画布上调整它建的节点。

Agent 内置了导演、编剧类技能，复杂的任务会拆成多步完成。它使用的大语言模型也走你在模型中心配置的上游。

想在终端里、或者用 Claude Code、Codex 批量操作画布（比如读一个剧本文件自动建几十个节点），用命令行工具更合适，见 [CLI 接入 AI 编程助手](ai-coding-tools.md)。

## 练习 9：整理素材、导出成片素材

- **保存到本地**：添加「保存到本地」节点，把要导出的图片或视频连进去，选择文件夹即可。
- **生成历史**：左侧工具栏打开，能看到所有生成过的结果。多选后可以批量下载为 ZIP，也可以把旧结果回填到画布。
- **素材库**：右键常用的角色图、场景图，选「保存到素材库」，用文件夹分类。以后在任何项目里点一下就能放到画布上。

喵剧AI 目前负责素材生产，最终成片的剪辑、调色、字幕建议导出后放进剪映、Premiere、达芬奇等剪辑软件完成。

## 常用组合速查

| 想做的事 | 节点怎么连 |
|---|---|
| 文生图 | AI 绘图 |
| 图生视频 | 图片 → AI 视频 |
| 角色一致的多镜头 | 角色参考图 → 多个 AI 绘图 → 各自接 AI 视频 |
| 剧本批量出片 | 脚本节点 → 分镜 → 准备资产 → 批量创建视频节点 |
| 镜头衔接 | 上一镜视频 → 智能续写；或抽帧取画面 → 下一镜 AI 视频 |
| 构图预演 | 3D 导演台截图 → AI 绘图 / AI 视频 |
| 配音 | AI 音频 →（可选）接入视频模型 |

遇到问题先看 [使用指南的常见问题](user-guide.md#常见问题)，还解决不了就到 [Issues](../../../issues) 反馈，附上「设置 → 环境诊断」的结果。
