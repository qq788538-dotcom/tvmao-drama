# 自由画布快捷键

本表是画布交互的唯一清单。画布内的提示入口在右下角提示条行头的键盘图标
（`editor/ShortcutsHint.tsx`，对标 Lovart 的快捷键弹层），**面板数据与本表
同源，改任一侧记得同步另一侧**。注意 Mac 与 Windows 的修饰键名称不同：
Mac 的 ⌘ Cmd 对应 Windows 的 Ctrl，⌥ Option 对应 Alt——提示面板按用户
操作系统显示对应的按键名。

实现位置：手势分流与缩放数学在 `editor/utils/viewGestures.ts`（含单测），
事件接线在 `editor/CanvasEditor.tsx`，全局手势拦截（捏合缩放 + 左右滑导航）在
`src/shared/gestureGuard.ts`。

## 缩放

| 操作 | Mac | Windows | 说明 |
|---|---|---|---|
| 放大 | ⌘ + `+` | Ctrl + `+` | 以视口中心为锚点，步进 1.2× |
| 缩小 | ⌘ + `-` | Ctrl + `-` | 同上 |
| 适应画布 | ⌘ + `0` | Ctrl + `0` | 缩放平移到所有节点刚好可见，上限 100% |
| 触控板捏合 | 双指捏合/张开 | 双指捏合/张开 | 以两指位置为锚点 |
| 鼠标滚轮缩放 | ⌘ + 滚轮 | Ctrl + 滚轮 | 以指针位置为锚点 |
| 工具栏按钮 | +/− 按钮 | +/− 按钮 | 步进 1.2× |

缩放范围统一 20%–250%（`MIN_ZOOM`/`MAX_ZOOM`）。

## 移动画布

| 操作 | Mac | Windows | 说明 |
|---|---|---|---|
| 键盘抓手 | Space + 拖动 | Space + 拖动 | 按住空格临时变抓手，不丢当前选中 |
| 触控板 | 双指滚动 | 双指滚动 | 上下左右皆可 |
| 鼠标 | 按住空白处拖动（左/中键） | 同左 | 落在节点上是拖节点，空白处才是平移 |

## 其他

| 操作 | Mac | Windows |
|---|---|---|
| 撤销 | ⌘ + Z | Ctrl + Z |
| 重做 | ⌘ + ⇧ + Z | Ctrl + Shift + Z |
| 复制选中 | ⌘ + D | Ctrl + D |
| 删除 | Delete / Backspace | Delete / Backspace |

## 有意不做的（对标 Lovart 时用户圈掉的）

移动工具 `V`、抓手工具 `H`、整理画布 `⌥⇧F`。

## 与浏览器缩放的边界

- 触控板双指捏合**全站**不再缩放网页（web 见 gestureGuard，admin 有自己的一份
  pinchGuard 副本）；画布内捏合被接管为画布缩放。
- 触控板双指左右滑在**整个用户端**不再触发浏览器前进/后退：横向为主的 wheel，
  若没有任何祖先容器还能吃掉这段横向滚动，就 preventDefault（页面里合法的横向
  滚动照常工作）；再加 `overscroll-behavior-x: none` 兜底。画布内该手势即平移。
- **真按着键盘 Ctrl + 滚轮**的浏览器整页缩放在画布外保留。区分依据：捏合会被
  浏览器伪装成 `ctrlKey=true` 的 wheel 事件，唯一可靠信号是键盘 Ctrl 的物理
  按下状态（gestureGuard 全局跟踪）。
- 画布页内 ⌘/Ctrl + `+`/`-`/`0` 被画布接管，浏览器的整页缩放快捷键在画布页
  不可用（其他页面不受影响）——Lovart 同款取舍。
